# След — спецификация v1 (после фильтра, GO*)

## Название
След (рабочее).

## Пара-источник
идти_VERB × несчастие_NOUN (word2vec RusVectores, этап 1 — Σ8, топ волны 2: №1=2,
№4=2 («беда ходит по пятам»), №5=2, №8=2). Повтор глагола «идти» (занят слотом
«Погоня») разрешён по прецеденту перепарки («усвоить × крыса» → тот же глагол с
носителем-законом): пары не совпадают, законы полярны — там таинственность УБЕГАЕТ
от шагов (непробиваемый порог, спуг), тут беда ИДЁТ ПО шагам (приварена к следу).

## Правки фильтра (две, внесены в спеку)
1. Снято противоречие инварианта: «позиция = N шагов назад» несовместима с «стоит —
   догоняет». Спека: след = очередь твоих последних клеток; беда повторяет клетку
   глубины min(N, длина очереди); когда ты стоишь, очередь не растёт, а она шагает
   сама (0.5 с/шаг) и зазор тает; зазор 0 = удар. Инвариант №9 в устойчивой форме:
   «она ходит только по твоему следу и свернуть сама не может».
2. Анти-лень (№14) структурой, без таймеров: победа = мишень поражена И (беда
   запечатана в дверь-сток ИЛИ ты на камне-убежище) — парковка на камне ничего
   не выигрывает; каждый уровень спроектирован так, что прямая линия губит хрупкое
   или отрезает путь (мосты необратимы).

## Правило (одно предложение)
Беда-попутчик ходит след в след — каждый твой шаг она повторяет N шагов позади,
свернуть сама не может, а когда ты стоишь, она догоняет и бьёт; всё, куда она
приходит, гибнет или запечатывается навсегда, так что вся игра — куда ты её
приведёшь и какой единой линией.

## Глаголы игрока
- **Шаг** (WASD/стрелки; клик по соседней клетке; удержание = серия шагов
  0.3 с/клетка). Стоять = не шагать. Направление каждого следующего шага — вся игра.
- Второго действия нет: беда неотделима, неотменяема и не ускоряема — бросить,
  отогнать, скомандовать, обогнать нельзя.

## Токены
- **Клетка** — сетка 24×14 (40 px); шаг = клетка; вся логика по клеткам.
- **След** — очередь твоих пройденных клеток, рисуется пунктиром.
- **Зазор N = 4** шага следа (одинаков на всех уровнях: инвариант формулы). Пока ты
  шагаешь — её шаг синохронен твоему и зазор держится; первые шаги уровня она идёт
  вплотную (зазор растёт 1→4 по мере накопления следа).
- **Её шаг при стоянии** — 0.5 с/клетка по следу к тебе: 4 стоячих такта ≈ 2 с до удара.
- **Хрупкое**: грядка (гибнет при её приходе — потеря) и мост (рушится, когда она
  сходит с него, — клетка непроходима для всех навсегда).
- **Охраняемое** (дом старца, L3): гибнет при её приходе — провал уровня.
- **Мишень**: бандиты, ворон, гнездо гарпии — обезоруживаются/гибнут при её приходе
  (условие победы); **дверь-портал** — единственный «сток»: её приход запечатывает
  дверь навсегда, беда исчезает из мира (единственный законный способ отделаться).
- **Камень-убежище**: пока ты на нём, она замерла (где стояла) и не шагает вовсе;
  сошёл — продолжает.
- **Потери** (счётчик гиблого хрупкого) и **par** уровня — минимум потерь на победной
  линии (линия план-бота, проверить перебором при сборке, как в «Отводе»).

## Правила (вся матрица v1)
| Событие | Правило |
|---------|---------|
| Твой шаг | след +1; она делает свой шаг по следу (зазор = N держится) |
| Ты стоишь | каждые 0.5 с она шагает сама; зазор 0 — удар, провал уровня |
| Ты шагнул в её клетку / она пришла в твою | удар, провал («вернуться по следу» = пойти ей навстречу) |
| Ты на камне | она замерла; сойти — она продолжит |
| Её приход в клетку с врагом | враг обезоружен (мишень) |
| Её приход на грядку | грядка гибнет (потеря, −звезда) |
| Её приход на охраняемое | провал уровня |
| Её приход в дверь | дверь запечатана навсегда, беда исчезает (сток) |
| Она сошла с моста | мост рушится; клетка непроходима для всех навсегда |
| Победа уровня | мишень поражена И (беда запечатана ИЛИ ты стоишь на камне) |

## Петли (7-профиль: тип / эффект / вложение / отдача / скорость / дальность / долговечность)
- **P1 «линия маршрута»**: маршрут планируется как ОДНА линия (туда к мишени + петля
  на камень), потому что она прожжёт её всю: +/конструктивное/высокое (вся карта)/
  отложенная (весь уровень)/медленная/уровень/уровень — главный бюджет уровней.
- **P2 «петля возврата»**: после удара по мишени вернуться на камень новой дугой — не
  по своему следу (назад = ей в лицо) и мимо грядок: +/конструктивное/среднее/
  немедленная (каждый шаг)/короткая/уровень/уровень.
- **P3 «челнок по мёртвому следу»**: старая часть следа (позади неё) ходибельна
  заново — легальный переход через сгоревшие зоны: +/конструктивное/низкое/
  немедленная/короткая/уровень/забег.
- **N1 «догон стоянием»**: пауза дольше ~2 с — она бьёт: −/destructive/нулевое/
  мгновенная (2 с)/короткая/уровень/уровень.
- **N2 «жадная срезка»**: прямая через хрупкое/охраняемое: она приходит ПОЗЖЕ тебя —
  срезка платит с задержкой N шагов, не сразу: −/destructive/высокое/отложенная/
  короткая/уровень/уровень — главный источник потерь.
- **N3 «отрезанный путь»** (мосты): сжёг мост — сам закрыл петлю возврата: −,
  но конструируемое/высокое/отложенная/средняя/уровень/уровень.
- **Против доминирующих стратегий**: «веду в лоб по прямой» — хрупкое на прямых
  (L2–L5), хорда через старца = провал (L3), мосты-необратимость (L4); «паркуюсь
  на камне и жду» — победа требует поражённой мишени (0 побед по построению);
  «хожу кругами и думаю» — легально (пазл), но мосты делают мышление необратимым
  (L4–L5); «челнок по старому следу» — легальная грамотная техника: беда туда
  не вернётся.

## Цель и проигрыш
- **Цель**: пять задач-маршрутов, победа по правилу из матрицы.
- **Провал**: догнала или пересёк её клетку; охраняемое погибло (L3). Рестарт
  мгновенный, уровни 60–90 с.
- **Звёзды по par потерь**: 3★ = потерь = par; 2★ = ≤ par+1; 1★ = победа.
  par: L1–L4 = 0; L5 = 1 (линия без потерь на L5 невозможна — хорда
  «гарпия → дверь» проходит по грядке кольца).

## Вопрос прототипа (один)
Рождает ли закон «беда ходит только твоим следом» планирование маршрута как единой
линии — доставка её ходом к мишени, нитка-обход хрупкого, петля возврата на камень,
порядок сжигания мостов, — или игрок ведёт её в лоб, жертвуя всё, и умирает стоя?
Прототип обязан содержать: зазор N с догоном при стоянии, хрупкое на прямых линиях,
необратимые мосты, дверь-сток и обязательный финал на камне — иначе вопрос решён
заранее в пользу «ведёт в лоб».

## Уровни (5, обучение одним намёком)
- **L1 «Попутчик»** — прямая поляна; мишень: костёр с 2 бандитами подряд; хрупкого
  нет; камень у костра; старт НЕ на камне. Учит: она повторяет твой шаг; стоишь —
  догоняет (первый догон безопасно увидеть). par=0. План: ~12 шагов прямо, удар по
  костру, дуга на камень. Прямолинейный бот проходит — норма обучения.
- **L2 «Грядки»** — огород: 6 грядок, ворон-разоритель за ними, 2 камня. Прямая от
  входа к ворону пересекает 3 грядки. Учит: планируй линию заранее — она пройдёт по
  ней же; срезка платит с задержкой. par=0; прямолинейный бот теряет 3 грядки (1★).
- **L3 «Два костра»** — два лагеря в противоположных углах, между ними дом старца
  (охраняемое) и 4 грядки. Задача: разоружить оба лагеря и встать на камень. Учит:
  порядок мишеней и петля; хорда через старца = провал. par=0.
- **L4 «Мосты»** — река поперёк карты, 5 мостов; гнездо гарпии на острове; 4 грядки
  на берегу; камень на берегу. Учит: необратимость — вся линия сжигается её ходом;
  сжёг лишний мост — петли возврата нет. par=0; прямолинейный бот сжигает 2 моста
  и отрезает камень (0 побед).
- **L5 «Печать»** — дверь-портал в центре, гарпия вплотную к двери, 8 грядок кольцом
  вокруг, 3 камня по краям. Экзамен: разоружи гарпию её ходом, запечатай дверь,
  выйди через кольцо мимо грядок. par=1.

## Стартовые константы (числа для HTML, править при балансировке)
Сетка 24×14 клеток по 40 px (поле 960×560, HUD 80, всего 960×640), один экран, без
камеры. Шаг игрока 0.3 с/клетка (удержание — серия). Зазор N=4 шагов следа на всех
уровнях; её стоячий такт 0.5 с (окно смерти от стояния ≈ 2 с). Камень замораживает
её; дверь — сток (печать + беда исчезает); мост рушится при её сходе (клетка
непроходима); грядка гибнет при её приходе; охраняемое = провал. Звёзды: 3★ = par
потерь, 2★ = ≤ par+1, 1★ = победа; par: 0, 0, 0, 0, 1. Уровни — данные в CONFIG
(карты клеток: стены/грядки/мосты/враги/охраняемое/дверь/камни/старт/мишень +
план-линия LEVELS[n].plan); вся логика клеточная, боты — до визуальной сборки.

## Риски баланса
- **«Ведёт в лоб»** — главный страх эскиза: если прямые линии чисты, игра = ходьба.
  Противоядия спекой: L2–L5 хрупкое на прямых, L3 хорда = старец, L4 мосты. Первая
  проверка прототипа: прямолинейный бот обязан терять ≥1★ условие на L2–L5; если
  проходит чисто — добавлять хрупкое на хорды, не вводить правил.
- **«Её путь не читается»** — след пунктиром, её следующий шаг — стрелкой на клетке
  следа. Если не читается — стрелку на 2 клетки вперёд, правила не менять.
- **«Догон слишком жёсткий»** — окно 2 с до удара; если игроки гибнут в раздумьях —
  такт 0.6 с (окно 2.4 с); N и синохронность не трогать — это формула пары.
- **«Назад по следу неочевидно»** — её клетка подсвечена, след позади неё гаснет;
  проверка ботом «назад-по-следу» обязана давать смерть в 100 % забегов.
- **«Мосты фрустрируют»** — мосты светлее травы (видно заранее), разрушение за её
  сходом с анимацией 0.3 с, рестарт мгновенный. Если L4 нерешаем «на глаз» —
  второй камень на острове, карты правил не трогают.
- **«Стояние-фарм»** — невозможен: время не считается (пазл), звёзды только
  потерями, парковка на камне = 0 побед (проверка ботом-парковщиком).
- Все константы вверху файла прототипа в один объект CONFIG; уровни — данные.

## Что НЕ входит в v1 (осознанно вырезано)
- **Темп игрока** (бег/ползком из эскиза) — ось скорости меняет пространственный
  зазор и требует своей механики; один шаг 0.3 с. Кандидат v2.
- **Живой мир** (враги ходят, NPC бродят) — мир статичен, беда единственный агент;
  движущиеся мишени — кандидат v2.
- **Несколько бед, «подтолкнуть», «отпустить дальше N»** — запрещены формулой
  (неотрываемость и неизменность зазора).
- Мета-мир между уровнями (гибель мира навсегда), процедурные карты, тач/свайп,
  арт/аудио, сохранения.

## Новизна (проверка вебом 2026-11-15, 4 запроса)
Прямого аналога «попутчик-беда, повторяющая твой след с зазором N шаг в шаг,
догоняющая при стоянии и губящая всё по маршруту» не найдено. Ближайшие соседи и чем
отличаемся: Prince of Persia: The Lost Crown (Sacred Archives) и семейство эхо-пазлов
(Shadow Move: Echo Puzzle, Cursor*10, Chronotron, Braid) — клон/эхо ПОВТОРЯЕТ твои
движения как помощник или препятствие для самого игрока, но ничего не губит, не
вооружается маршрутом и не догоняет при стоянии; Spelunky (призрак по таймеру) и
догонялки-классика — угроза привязана к ТАЙМЕРУ и охотится за тобой, а не шагом в
шаг по твоему следу, мир от неё не меняется; кайтинг как тактика (Battle Brothers —
наведение монстров на чужие лагеря, aggro-кайтинг MMO) — вольное наведение ИИ без
закона следа; змейка/Tron — своя растущая туша/стена, а не отдельный попутчик,
губящий мир. Занятые слоты: **«Погоня»** (идти × таинственность) — полярный закон:
там цель УБЕГАЕТ от шагов (порог D ≥ 90 непробиваем, отступ-приметы, спуг от темпа),
тут беда СЛЕДУЕТ шагам вплотную по твоей же траектории; общая ось «шаги игрока» —
да, общих правил нет ни одного. **«Отвод»** — беда ВНЕШНЯЯ, летит по расписанию,
отводится кликом; тут беда приварена к твоим ногам, и ты её вектор, а не адресат.
«Мираж» — потеря от владения вещью; «Крен» — вес в комнатах. Комбинация новизну
держит.

## Критерии приёмки (боты)
- **Экспорт `window.FOOTSTEPS`** для headless-тестов: `{ CONFIG, LEVELS, step(dir),
  wait(t), restart(level), state() }`; `step` возвращает `{ok, reason}`; `state()` —
  сериализуемый объект `{ level, you, curse, gap, trail, crops[], bridges[],
  enemies[], guarded, door, stones[], losses, steps, over, won, stars }`. Все боты —
  через API по клеткам, без пикселей, до визуальной сборки (урок LOG о достижимости).
- **План-бот** (линия уровня из LEVELS[n].plan) — победа с par потерь, 10/10 на
  каждом уровне; уровни детерминированы.
- **Стояк-бот** (не шагает никогда) — догон и провал ≤ 2.5 с в 100 % забегов L1–L5
  (закон «стоять = догоняет»).
- **Прямолинейный бот** (BFS к мишени, хрупкое игнорирует) — L2: ≥ 3 потерь; L3:
  ≥ 2 потерь или провал у старца; L4: 0 побед (отрезал камень мостами) — иначе
  карты не держат анти-лоб и перекомпоновать хрупкое на хорды.
- **Парковочный бот** (прямо на камень и стоит) — 0 побед за 300 с на всех уровнях
  (победа требует поражённой мишени).
- **«Назад-по-следу»** (шагает по собственному следу назад) — смерть в 100 % забегов.
- **Рандом-бот** (равновероятный шаг из допустимых) — < 50 % побед на каждом уровне
  (≥ 200 партий).

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Заголовок страницы —
вопрос прототипа. Состояние читается без текста: след — пунктир, её следующий шаг —
стрелка, грядки/мосты/камни/дверь — иконки клеток, потери — счётчик против par,
зазор — длина хвоста за ней. HUD одной строкой: уровень, потери X/par, шаги. Итог
уровня одной строкой (потери, звёзды, шагов) — ответ на вопрос прототипа.
Управление: WASD/стрелки и клик по соседней клетке. window.FOOTSTEPS — приёмка
ботами до визуальной сборки.
