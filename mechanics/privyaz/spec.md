# Привязь — спецификация v1 (после фильтра, GO* 16/16 — потолок пары)

## Название
Привязь (рабочее; слот `privyaz`, хук `window.PRIVYAZ`).

## Пара-источник
привязать_VERB × сочувствие_NOUN (этап 1 — Σ8, потолок пары **16**: №1 = 2, №4 = 2 —
мост «привязанность», «узами связан», «сердцем прикипел» — чувство мыслится узлом,
№5 = 2 — рука вяжет и развязывает, сочувствие тянет само и больше человека — как
долг/толпа, №8 = 2 по формуле — связь: узел фиксирует две сущности, не словарное
изготовление; №3/№6/№7 пройдены, стоп-лист чист; эскиз .data/privyaz-draft.md).
Законы: «привязка привносит фиксацию — узел держит сам, пока не развязан:
перекинуть привязь нельзя, только развязать и вязать заново» / «сочувствие
сохраняет тягу — привязанное тянет носителя к якорю непрерывно, не слабея с
расстоянием». Формула: **можно привязать сочувствие к якорю, но тогда носителя
потянет к якорю само, и узел не отпустит, пока не развяжешь**. Конфликт: фиксация
хочет покоя — тяга гонит.

## Правки фильтра (шесть)
1. **Прибытие и жизнь узла после него (№9/№10).** Эскизное «тяга тащит дальше
   нужного» на решётке невозможно: жадный шаг строго уменьшает манхэттен до якоря —
   у якоря тяге некуда идти. Заземлено: на якоре узла тяга насыщена — носитель
   стоит, узел живёт и ДЕРЖИТ порцию до развязки. Отсюда ритм «довёл — отпустил»:
   развязать у якоря хочется, чтобы порция вернулась в пул и поехала к следующему —
   узел-память без развязки = запертая валюта (T3 строится на этом).
2. **Формула жадного шага (№9, детерминизм).** «Чем дальше, тем настойчивее» —
   непрерывная величина, враг par и ботов. Заземлено как НЕНАСЫЩАЕМОСТЬ: тяга
   постоянна и не слабеет с расстоянием (1 клетка за такт, шаг только в соседнюю по
   стороне клетку со СТРОГО меньшим манхэттеном до якоря узла; кандидатов два —
   уменьшай ось с бо́льшим остатком, при равенстве остатков — вертикальную;
   соседей с меньшим расстоянием нет — стоит). Шаг монотонен → петель нет, длина
   прогулки = манхэттен, всё решается на бумаге. Шаг в опасную клетку (огонь/вода)
   = гибель носителя: тяга НЕ ищет путь — она честно-наивна, читается стрелкой.
3. **Три сущности задач (№15).** Эскизная «перепривязка под срок — сэкономив шаги»
   была числом, не сутью. Разведено: (a) ОБХОД-ГЕОМЕТРИЯ — одна вязка как вектор:
   выбери якорь, чья наивная линия тяги огибает огонь сам по геометрии манхэттена;
   (b) ПЕРЕВЯЗКА-ХИРУРГИЯ — развязка замораживает носителя (без узла не ходит
   никто), перепривязка меняет вектор: обход огненного гребня двумя-тремя векторами
   под сроком, момент заморозки = главный навык; (c) ПЕРЕВОЗКА ПОРЦИИ — пул меньше
   жителей: довёл-развязал-перевязал, тайминг двух прогулок против срока K.
4. **Валюта звёзд — клики (№14).** Эскиз звал «такты против par», но такты съедаются
   прогулками (детерминированными), а перевязка оставалась бы бесплатной —
   бесконечный микроруль. par считается в КЛИКАХ (вязка + развязка; отменённый
   выбор бесплатен), такты — только порог победы K: не доставил к K — провал.
5. **Двусторонний спрос заземлён (№10).** Развязать хочется по четырём причинам:
   (а) линия тяги смотрит в опасную клетку — снять до смертельного шага;
   (b) порция срочнее другому жителю (пул конечен); (c) узел у якоря запер порцию —
   ритм «довёл — отпустил»; (d) приписанный якорь больше не тот, к которому тянет
   узел, — вектор надо сменить. Вязать хочется: доставить к сроку и вытащить из
   опасной зоны (без узла житель не уйдёт из горящей клетки сам никогда).
6. **Диагносты формализованы (№14).** Пассив (0 кликов) — никто не двигается, 0
   побед; «привязал и забыл» (вязка к приписанному якорю, никогда не развязывает) —
   на T1 победа (вводный), на T2+ гибель в огне или срыв срока; «камп» (один узел
   навсегда) — запирает пул, второй житель не доставлен (T3+); рандом — T2–T5 <50%
   (T1 — норма вводного уровня, прецедент send-tone/lattice).

## Правило (одно предложение)
Жители стоят как вкопанные — без узла не шагает никто, — а ты платой из конечного
пула сочувствия вяжешь узел «житель → якорь»: привязанное чувство само тянет
носителя жадным шагом к якорю, клетка за такт, не слабея и не ища пути — если на
линии тяги огонь, носитель шагнёт в него и сгорит вместе с порцией навсегда, —
развязка возвращает порцию в пул и замораживает носителя на месте, перекинуть узел
нельзя, только развязать и вязать заново, доставь всех к своим якорям до срока K,
тратя клики против par.

## Глаголы игрока
- **Клик по несвязанному жителю** — выбор (подсветка; якоря с превью-стрелками).
- **Клик по якорю при выборе** — ВЯЗКА: платится порция из пула, рождается узел.
- **Клик по связанному жителю (узлу)** — РАЗВЯЗКА: порция возвращается в пул, тяга
  гаснет, носитель замирает. Единственные два результатаивные жеста.
- Клик мимо / по другому жителю при выборе — отмена выбора (бесплатно). Второго
  глагола нет: аватара, ходьбы, клавиатуры нет; R — уровень заново.
- Наведение — превью: стрелка следующего шага тяги на каждом связанном, свечением
  помечена опасная клетка, в которую линия тяги смотрит, «дойдёт на такте k» —
  читаемость, не действие.

## Токены
- **Жители** (2–3 на уровень): живые, сами не ходят никогда; каждый приписан
  своему якорю (цвет-глиф пары). Двое проходят сквозь друг друга (столкновений нет:
  взаимодействия только узлы, опасности, якоря).
- **Якоря** (по жителям + 0–1 обманка на поздних уровнях): неподвижные места-клетки;
  зачёт доставки = стоять на СВОЁМ приписанном (узел при этом связан или уже
  развязан — неважно).
- **Узел** — пара (житель → якорь): ровно один на жителя; бинарный (дозировки нет);
  платит одну порцию; рисуется пунктирной нитью цвета пары.
- **Пул P** (1–3 на уровень) — порции сочувствия, сердечки HUD. Инвариант:
  пул + узлы + сгорело = P каждый такт; порции неделимы; развязка возвращает
  целую порцию; сгоревшая — серое сердце с крестом, невозвратно.
- **Опасные клетки** (огонь/вода): шаг тяги в них = гибель носителя с его порцией,
  немедленный провал уровня. Единственные препятствия поля (стен нет — обход делается
  геометрией вектора, не стенками).
- **Срок K** — число тактов; победа проверяется на конце такта K.
- **Клики** — вязки + развязки, валюта звёзд против par.

## Правила поля (порядок такта зафиксирован — не менять при сборке)
1. **Клики игрока** (вязка / развязка / отмена выбора).
2. **Шаги тяги** — связанные жители по порядку номеров клеток (сверху-слева):
   шаг в соседнюю по стороне клетку со строго меньшим манхэттеном до якоря узла
   (два кандидата — ось с бо́льшим остатком, при равенстве — вертикальная;
   кандидатов нет — стоит). У якоря узла — стоит (тяга насыщена).
3. **Гибели** — шагнувший в опасную клетку сгорает с порцией (burned +1);
   провал немедленный.
4. **Счёт** — такт +1; на конце такта K: все жители на своих якорях → победа,
   иначе провал «срок ушёл».
- **Инварианты (ассерты в ботах):** пул + Σузлов + сгорело = P; burned монотонна;
  несвязанный житель не шагает никогда; шаг связанного строго уменьшает манхэттен
  (осцилляций нет по построению); узел ровно один на жителя и снимается только
  рукой; два одинаковых прогона — одинаковый итог (RNG нет).

## Петли
- **P1 вязка → тяга → довёл — отпустил**: узел — двигатель с бензином из пула;
  прибытие НЕ гасит узел — порция заперта, пока не развяжешь; пул из одной порции
  прокатывает всю партию серией, но серийность ест такты срока.
  +/конструктивная/среднее/отложенная/полполя/вся партия.
- **P2 вектор-хирургия**: развязка = стоп-кадр, перепривязка = новый вектор; обход
  огня — не поиск пути, а смена притяжения в нужной клетке поворота.
  +/конструктивная/высокое/немедленная/локальная/уровень/короткая.
- **N1 привязал и забыл**: наивная тяга не читает огонь — всякая вязка мимо
  проверенной линии тяги — минное поле; смертельная клетка светится в превью ЗАРАНЕЕ.
  −/destructive/высокое/немедленная/локальная/клетка/мгновенная.
- **N2 запертый пул**: узел, забытый у якоря, держит порцию — когда она срочнее,
  заминка стоит прогулки второго жителя.
  −/destructive/среднее/отложенная/полполя/партия.
- **Структура против доминирующих стратегий**: «ничего не делать» — без узла не
  шагает никто (0 доставленных); «привязал и забыл» — огонь и сроки (T2+);
  «один узел навсегда» — второй житель не доставлен, пул заперт (T3+);
  «вязать всех подряд» — пула не хватает (T3+), лишние вязки — клики против par;
  «перевязывай каждый такт» — клики против par (правка 4).

## Цель и проигрыш
- **Цель**: на конце такта K каждый житель стоит на своём приписанном якоре.
- **Звёзды**: 3 — победа и клики ≤ par; 2 — ≤ par + 2; 1 — победа.
- **Проигрыш**: любой житель сгорел (немедленно, с порцией); срок K истёк с
  недоставленными. Рестарт R мгновенный. Партия 5 уровней ≈ 8–12 минут.

## Вопрос прототипа (один)
Рождает ли закон «узел держит порцию, пока не развязан, а чувство тянет носителя
сам — наивно, клетка за такт, сквозь огонь» настоящее планирование — чтение линии
тяги против опасностей, момент развязки-заморозки, выбор рулевых якорей, жонглёрство
порцией под сроком, — или игрок вяжет наугад и угадывает? Прототип обязан содержать:
наивный жадный шаг с фиксированными тайбрейками, гибель в опасной клетке со сгоранием
порции, развязку с возвратом порции и заморозкой, запрет перекидки узла, пул меньше
жителей на T3+, счёт кликов против par — иначе вопрос решён заранее в пользу «темы».

## Риски баланса
- **«Обвод непонятен»** — главный риск: игрок не видит, куда ведёт наивная тяга
  через три такта. Противоядия: стрелка следующего шага + свечение смертельной
  клетки + превью-траектория при выборе якоря (до клика). Если теряется — НЕ текст:
  глиф траектории крупнее.
- **«Тяга-в-огонь обидна»** — свечение в превью заранее и рестарт мгновенный;
  гибель = учит правило T2, не читерство игры.
- **«Жонглёрство муторно»** — развязка+вязка = 2 клика на передачу порции; если
  темп вязнет — данные: поднять пул на T3 до 2 и ужать срок K (уровень), не правила.
- **«Развязка-заморозка эксплуатируется»** (замереть перед огнём навсегда) — такты
  конечны: срок K с недоставленными = провал; заминка = срыв срока (уровни это
  обеспечивают).
- **«Рандом выигрывает»** — T2+ вернее 50% быть не может (смертельные линии и
  сроки); проверять ≥ 20 000 партий headless; T1 — вводное исключение (прецедент
  send-tone/lattice).
- **«par в кликах душит хирургию»** — если план-бот не укладывается, пересчитать
  par на скелете, не ослаблять цену перевязки.
- Все константы вверху прототипа в один объект CONFIG; уровни — данные.

## Что НЕ входит в v1 (осознанно вырезано)
- **Стены/скалы** (неопасные препятствия) — обход только геометрией вектора;
  стены — v2 (дают «тени» манхэттена, усложняют чтение).
- **Распространение огня, подвижные опасности** — v2: ломают «превью заранее».
- **Несколько узлов на жителе, порции разного «веса»** — противоречат инварианту
  и закону глагола (перекинуть нельзя).
- **Якоря-мобы, жители-пастухи, второй пул** — v2.
- Реальное время, WASD/тач, сохранения, арт/аудио — нет; клики и такты.

## Новизна (проверка вебом 2026-11-23)
Прямого аналога правила «привязанное узлом чувство само тянет носителя к якорю
наивным жадным шагом, порция консервативна (пул-узлы-сгорело) и сгорает с погибшим
носителем» не найдено. Проверенные запросы: «emotion attachment pulls character to
goal puzzle game indie», «tether mechanic NPC automatically walks toward point
puzzle game lemmings guide», «empathy game mechanic spend limited resource rescue
characters danger» (плюс sympathy-tether / magnet-beacon — обрывались rate-limit,
негатив чистый). Ближайшие соседи и чем отличаемся: **Lemmings-семейство** (NPC идут
сами по собственному импульсу, игрок вешает навыки; здесь без узла НЕ шагает никто —
движение рождается только привязкой, и оно векторное к якорю, не «куда смотрю»).
**Приманки-приманки стелса (Mark of the Ninja, свистки/шум MGSV)** — ближайшая
семья: стимул ведёт NPC точкой; но там приманка = предмет/звук, бесплатна и
повторяема, NPC ищет ПУТЬ; здесь привязь — чувство за конечную порцию, тяга наивна
(в огонь), порция сгорает с носителем невозвратно, узел держит валюту до развязки.
**Rope-physics tether (Cut the Rope, Tether, Unravel, поводки WoW)** — верёвка
физическая, тянет ИГРОК или поводок следует за хозяином; здесь тяга автономна,
постоянной силы, без упругости и провиса, и объект тяги — чувство, не канат.
**Thomas Was Alone / эмоциональные паззлы** — привязанность игрока к персонажам как
НАРРАТИВ, не правило; формы не притягиваются чувствами. **This War of Mine
«Sympathy»** — шкала настроения от поступков, без пространственной тяги, без
консервации, без узлов. **Магнитные паззлы (Teslagrad-семья)** — притяжение —
инструмент движения самого игрока, без валюты, узлов и гибели носителя. Разводы по
своим слотам: **Межа** (stake-steppe; прикреплять×степь, старая ось 0.569 — главная):
там кол вбивается в КЛЕТКУ-МЕСТО навсегда и мертвит её для степи (инвариант —
снапшот глубины); здесь узел держит ЧУВСТВО и порождает ДВИЖЕНИЕ носителя (инвариант
— консервация порций); полярность обратимости: кол несъёмен — узел развязываем, но
цена у нас не в несъёмности, а в сгорании с носителем. **На поводу** (selfbind,
отдаться×договорённость): там отдаёшься САМ, стяг тянет ОБОИХ подписантов к
коллапсу, исполнение сжигает договор; здесь вяжешь чувство ТРЕТЬЕГО (жителя), тяга
односторонняя, узел не коллапсирует — снимается рукой, порция возвращается.
**Аммиачный строй** (lattice): там связь ПРИКАЛЫВАЕТ (пиннинг: связанная молекула не
двигается никогда) и рвётся сама по порогу натяжения; здесь узел — НАОБОРОТ, двигатель:
он порождает шаги, не рвётся никогда и снимается только рукой. **Затяжной** (drawout):
там петля останавливает/растягивает ВРЕМЯ срока с вечной тугой-памятью; здесь узел
не трогает время — тянет ТЕЛО в пространстве, и развязка чиста (память только одна —
сгоревшая порция). **Верёвка ветров** (windrope): там верёвка ПЛЕТЁТСЯ из ловленых
волокон и служит ДОРОГОЙ под груз (проза «привязать к крюку» — под-действие чужой
механики, слот глагола свободен); здесь привязь невидима-чувственна: без волокон,
провиса и прочности, тяга не зависит от длины и несёт тело, а не груз.
**Самотёк** (samotek): полярная операция — там отпускаешь подпорку, сущность ползёт
КУДА ХОЧЕТ; здесь привязываешь — сущность ползёт К ЯКОРЮ. **Шов** (suture): там
«якорь» — камень, гасящий ширину щели в ноль навсегда (фиксация в покой); здесь
якорь — цель, К которой тянет, и вся суть — движение. **Сплетение** (weave) —
взаимная сеть переплетений; здесь звёзды узлов «житель→якорь», сеть не сплетается.
**Проходной двор** (courtyard) — подозрение идёт по дверям само и обвиняет при
остановке; здесь живые носители, конечный пул и невозвратная потеря. Пара
«привязать × сочувствие» среди слотов не занята (rg по mechanics/*/spec.md,
MECHANICS.md, archive: только проза под-действий). Комбинация «узел = порция
конечного пула ∧ тяга чувства автономна и наивна ∧ развязка возвращает порцию ∧
гибель носителя сжигает её навсегда ∧ перекидка запрещена» новизну держит.

## Критерии приёмки (боты)
Экспорт **window.PRIVYAZ** (state, tie(residentId, anchorId), untie(residentId),
tick(), loadLevel(i), restart()) для headless-тестов; `state()` сериализуем:
`{level, tick, K, pool, burned, residents:[{id, x, y, anchorId, bound, anchorOfNode,
alive, delivered}], nodes, clicks, over, won, lostReason: 'death'|'deadline',
stars}`; клики только через API, без пикселей.
- **Ассерты** (каждый такт): пул + Σузлов + burned = P; burned монотонна; порции
  неделимы; несвязанный не шагает; шаг связанного строго уменьшает манхэттен до
  якоря узла; узел ровно один на жителя; развязка возвращает целую порцию; два
  одинаковых прогона — одинаковый итог.
- **План-бот** (BFS живых состояний на скелете до HTML — сетка ≤ 10×7, K ≤ 26;
  он же подтверждает par) — побеждает T1–T5, клики ≤ par.
- **Диагностический «пассив»** (0 кликов): 0 побед на всех уровнях — никто не
  шагает. Обязателен (№14).
- **Диагностический «привязал и забыл»** (каждого жителя вяжет к приписанному
  якорю при первой возможности, никогда не развязывает): T1 побеждает (вводный);
  T2+ — сгоревшая порция (огонь на линии тяги) или срыв срока. Обязателен (№11).
- **Диагностический «камп»** (ровно один узел за партию): T1–T2 может пройти
  (вводные), T3+ 0 побед — второй житель не доставлен, пул заперт. Обязателен (№14).
- **Диагностический «спамовник»** (перевязывает каждый такт к ближайшему якорю):
  0 побед на T2+ (клики >> par и срывы сроков); на T1 — некритично.
- **Случайный бот** (равновероятный легальный жест, ≥ 20 000 партий headless,
  seed фиксирован): < 50% побед на T2–T5 (T1 — вводное исключение, норма выше).
- Правка констант/раскладов перепроверяется всеми ботами заново.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Заголовок страницы —
вопрос прототипа. HUD одной строкой: такт k/K, пул (сердечки, сгоревшие — серые),
клики против par. Сцена: сетка поля, жители с цветом приписки, якоря с тем же
цветом, пунктирные нити узлов, стрелки следующего шага тяги, свечение смертельных
клеток под линией тяги, огонь/вода глифами. Управление: клик по жителю → клик по
якорю (вязка), клик по узлу (развязка), R — заново. Итог уровня одной строкой
(доставлено x/y, сгорело, клики vs par, такты, причина провала) — ответ на вопрос
прототипа и лог ботов (план/пассив/привязал-и-забыл/камп/спамовник/случайный).
