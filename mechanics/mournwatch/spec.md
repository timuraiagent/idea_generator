# Причитальня — спецификация v1 (после фильтра, GO* 15/16, потолок пары)

## Название
Причитальня (рабочее; слот mournwatch, хук `window.MOURNWATCH`).

## Пара-источник
оплакивать_VERB × вахта_NOUN (word2vec RusVectores, sim −0.1731 по model.txt, волна 49;
этап 1 — Σ7, потолок пары 15: №1 = 2, №4 = 1, №5 = 2, №8 = 2; жёсткие №3/6/7 пройдены).
Законы: «оплакивание привносит провод — оплаканная вахта уходит из сезона НАВСЕГДА, её
слот больше не заполнится, и общий строй редеет с каждым ритуалом» / «вахта сохраняет
сменность — вахты встают сами, по расписанию, и непоплаканная остаётся призраком на
посту: место занято, а пост не держит». Конфликт: провод хочет отпустить (редить строй),
сменность хочет заполнить (держать линию). Формула: **можно оплакать кончившуюся вахту,
но тогда она уйдёт из сезона навсегда — а непоплаканная встанет призраком на посту и
пропустит беду**. Мост (№4 = 1): «оплакивать молодость / уходящую эпоху» — служба
мыслится оплакиваемой, готовой пары «оплакать вахту» в языке нет. Рука и закон
(№5 = 2): ритуал — рукой (клик-такт); беды и смена приходят сами по расписанию,
больше человека. №8 пересмотрен по формуле (флаг из handoff сэмплера): оплакивание —
не ручка, не накопление и не общий импульс; по формуле это **провод-перенос** —
переводит сущность из строя в вечность, у действия есть адресат (призрак), цена
(такт руки) и необратимый след (ушедшие). Стоп-лист чист.

## Правки фильтра (шесть; закон сменности — главная)
1. **Смена встаёт сама — из конечного резерва (№9/№12/№13, главная правка).** Сырой
   эскиз обещал «в следующий такт встанет живая вахта из расписания», не сказав,
   откуда она берётся и кто выбирает пост. Правка: расписание = очередь РЕКРУТОВ с
   тактами прибытия (двор); освободившийся пост занимает ПЕРВЫЙ ждущий в начале
   следующего такта (порядок постов — по номерам). Игрок пост не выбирает никогда:
   выбор поста = выбор цели плача — один глагол сохранён. Резерв конечен: с T2
   рекрутов меньше, чем кончающих срок вахт (R < G) — триаж обязателен.
2. **Фаза призрака обязательна; плач = сдвиг фазы цепи (№9/№10).** Плакать можно
   только над СТОЯЩИМ призраком (с такта после конца срока); преемник держит с
   такта вступления до вступление + срок. Отсюда: (a) минимальная дыра каждой
   смены = такт призрака — конец срока всегда стоит один такт беды; (b) конец
   следующего срока = вступление + L: РАННИЙ плач тянет конец следующего срока
   раньше (второй призрак может попасть точно в бурю — так горевальщик-asap
   проваливает T2), ПОЗДНИЙ — позже (мимо бури, но дыра длиннее). Рулить фазой
   цепи моментом плача — вторая половина игры.
3. **Ритуал занимает такт руки — глобальная дыра (№11, главная правка).** В такт
   плача смотритель в ритуале: часовые без смотра, и беда этого такта проходит
   ЛЮБОЙ пост, даже с живой вахтой. Календарь бед виден с первого такта — окно
   выбирается расчётом, не реакцией. Этим же получило механизм эскизное «сплошной
   шторм: ритуал нельзя прерывать» (задача 3): плотный дождь бед = голод чистых
   тактов.
4. **Инвариант в счётной форме (№9).** ШТАТ сезона = живые на постах + призраки на
   постах + двор = P + прибывшие − ушедшие; плач — двойная перестановка
   (призрак → ушедшие навсегда, двор → живые) и −1 штату: с каждым ритуалом строй
   редеет — «финальная буря встретит неполным строем» стало счётным. Каждая вахта
   проходит ровно одну фазу призрака; конец срока = вступление + L. Всё — ассерты
   в ботах.
5. **Буря и бюджет провала (№10/№14).** Финальная буря = беда по списку постов в
   такт T; провал = ВТОРОЕ крушение за сезон (первое — бюджет жертвы). Плач без
   ждущего рекрута законен и честен: призрак уходит навсегда, пост пустеет до
   конца сезона (ловушка для спама, не скрытая казнь). Звёзды — по плачам против
   par.
6. **Три сущности задач и эталон на скелете (№15/№14).** Задачи различены
   ограничителем: (a) ОКНО-МОМЕНТ — один призрак, узкое окно до беды (тайминг);
   (b) ТРИАЖ РЕЗЕРВА — рекрутов меньше призраков, решает КОГО заменить и кого
   оставить дырой (выбор жертвы, не тайминг); (c) ПРОПУСКНАЯ РУКИ — призраков
   много, чистых тактов мало (решает ПОСЛЕДОВАТЕЛЬНОСТЬ); четвёртая линия —
   ФАЗОВОЕ РУЛЕВОЕ (ранний плач открывает окно переплача). par = минимум плачей
   победной линии: {1, 3, 6, 5, 9} посчитаны BFS живых состояний скелета до HTML
   (T5 — 713 709 состояний, секунды); диагносты обязаны проваливать T2–T5 —
   проверено прогоном.

## Правило (одно предложение)
Сезон — лента тактов с расписанием бед и рекрутов, известным с первого такта, и ты —
одна рука смотрителя: кончившая срок вахта остаётся призраком на посту — место занято,
беда на дыру проходит, — клик по призраку причитает над ней ВЕСЬ такт (в такт плача
беда проходит любую пост — твоя линия без смотра), в конце такта призрак уходит из
сезона навсегда и штат редеет, а в начале следующего первый ждущий рекрут двора
занимает пост сам, — но рекрутов меньше, чем кончающих срок, и каждый провод
переставляет фазу всей последующей цепи поста: доживи до финальной бури не более чем
с одним крушением, выбирая КОГО оплакать, КОГДА и КОГО встретить дырой.

## Глаголы игрока
- **Клик по призраку = ПЛАЧ** (единственный глагол): занимает весь такт руки;
  в конце такта призрак уходит навсегда (ушедшие +1); в начале следующего такта
  первый ждущий рекрут двора занимает пост сам. Плакать можно только над стоящим
  призраком (с такта после конца срока). Без ждущего рекрута плач законен, но пост
  пустеет навсегда.
- **Ждать** (пас такта): легальный ритм — смена и беды идут сами.
- Наведение — превью: кольцо остатка срока живой вахты, беда поста на ленте, кто и
  когда придёт из двора, сумеречная полоса «беда такта плача пройдёт здесь и здесь» —
  читаемость, не действие. Аватара и ходьбы нет.

## Токены
- **Посты** (2–5 на уровень): счёт слева направо; у каждого ровно один держатель:
  живая вахта, призрак или пусто.
- **Живая вахта**: флажок + кольцо остатка срока (L тактов от вступления); конец
  срока = вступление + L.
- **Призрак**: серая фигура с трещиной на посту — место ЗАНЯТО (преемник не войдёт),
  беду НЕ ДЕРЖИТ (беда на призраке = крушение).
- **Двор**: очередь ждущих рекрутов + даты следующих прибытий (лента-календарь
  внизу, весь сезон виден с первого такта).
- **Беды**: (пост, такт) на ленте; беда такта: живой держит — отражено; призрак/
  пусто — крушение; такт плача — крушение ВЕЗДЕ.
- **Финальная буря**: беда по списку постов в такт T (метки на постах с первого
  такта).
- **Крушения**: счётчик; второе — немедленный провал.
- **Штат**: живые + призраки + двор = P + прибывшие − ушедшие (HUD одной строкой).
- **Плачи**: счёт против par (звёзды).

## Правила поля (математика)
- Порядок резолва такта (зафиксирован, не менять при сборке — боты и par завязаны):
  (1) прибытие рекрутов по расписанию во двор; (2) вступление: пустые посты по
  порядку номеров занимают ждущих (держат с этого такта, срок L); (3) ритуал-флаг;
  (4) беды такта (ритуал → крушение всюду; живой → отражено; призрак/пусто →
  крушение); (5) концы сроков (живая с концом = t → призрак с СЛЕДУЮЩЕГО такта);
  (6) завершение плача (призрак цели → ушедшие навсегда, пост пуст). RNG нет.
- **Инварианты (№9, ассерты в ботах)**: живые + призраки + двор = P + прибывшие −
  ушедшие каждый такт; каждая вахта — ровно одна фаза призрака; конец срока =
  вступление + L; плач только по призраку, один за такт; вступление только на
  пустой пост и только из двора.
- **Двусторонний спрос (№10)**: плакать хочется — призрак дыра (беда пройдёт) и
  держит преемника; плакать не хочется — плач сжигает рекрута 1:1 из конечного
  резерва, такт плача — дыра на всём поле, ранний плач съезжает фазой (конец
  следующего срока приедет раньше — возможно, в бурю). Одна величина (момент
  плача) работает в обе стороны.
- **par** — минимум плачей победной линии (≤ 1 крушения), BFS живых состояний
  скелета до HTML; параллельный эталон par0 — то же с бюджетом 0 крушений.

## Линзы (Адамс/Дорманс)
- **Тип механики (гл. 1)**: инновация в ДИСКРЕТНОЙ части — фаза призрака, расписание
  бед/рекрутов, счёт резерва; непрерывного ноль (сетка тактов, темп константа 1.0 с).
- **Паттерн-скелет**: «сменный лагерь с проводом» — worker placement с одним
  рабочим (рука), которого пускают только на ПРОВОД (не на посты), поверх
  неотвратимого календаря; плач — stopping mechanism по гл. 7: каждый ритуал
  снижает строй навсегда (−1 штату), доминирующую стратегию «оплакивай всех»
  ломает конечный резерв, «не оплакивай никого» — календарь бед на дыры.
- **Какие действия механика делает выигрышными (гл. 12)**: выбор МОМЕНТА плача
  (окно между бедами + фаза цепи), выбор ПРИЗРАКА (куда встанет рекрут —
  маршрутизация резерва), выбор ЖЕРТВЫ (какой пост встречает беду/бурю дырой).
  Все — дискретные решения на 1–3 такта вперёд плюс один долгий план резерва на
  сезон.

## Петли (7-профиль: тип / эффект / вложение / отдача / скорость / дальность / долговечность)
- **P1 призрак → дыра → плач → смена**: конец срока ставит призрака; беда на дыре =
  крушение; плач в окне — преемник держит до следующего конца срока. Обслуживаемая /
  закрывает дыру / 1 такт руки + 1 рекрут / пост держит L тактов / 1 такт до
  вступления / один пост / до следующего конца срока.
- **P2 фазовое рулевое**: момент плача ставит конец следующего срока (= вступление +
  L): ранний плач открывает окно переплача до бури, поздний уводит конец за бурю —
  но дыра длиннее. Плановая / двигает фазу цепи / тот же плач / окна переплача /
  L тактов / вся оставшаяся цепь поста / до конца сезона.
- **P3 резерв-триаж**: R конечен; каждый плач −1 рекрут и −1 штат — чем больше
  проводов, тем голоднее буря. Экономическая / обедняет будущие замены / растёт с
  каждым плачем / выбор жертвы вместо замены / мгновенная / весь сезон / сезон.
- **N1 глобальная дыра ритуала**: беда в такт плача проходит всюду — окно плача
  само становится ресурсом; плотный дождь бед душит пропускную руки. Анти-жадность /
  наказывает плач впопыхах / 1 такт / потерянное окно / мгновенная / всё поле / такт.
- **N2 строй тает**: живые + призраки + двор падают на 1 с каждым плачом — буря
  встречает неполным строем даже при полной дисциплине. Накопительная (наоборот) /
  редит линию / 1 рекрут за плач / меньше запасных замен / — / все посты / сезон.
- **Против доминирующих стратегий (структурой, не числами)**: «молчун» — календарь
  бед бьёт по дырам (2 крушения); «горевальщик-asap» — резерв сгорает и фазы
  съезжают в бурю (T2 построен от противного: ранний плач по п2 ставит его второй
  призрак ровно на бурю); «затяжник» — окна закрываются, рука одна у бури; «скупец»
  — буря не покрыта. Проверено диагностами на скелете.

## Цель и проигрыш
- **Цель**: дожить до конца сезона T с ≤ 1 крушением (финальная буря — беда такта T).
- **Звёзды**: 3 — победа и плачей ≤ par; 2 — победа и плачей ≤ par + 2; 1 — победа.
- **Провал**: второе крушение (немедленно). Рестарт уровня (~1 мин).
- На T2 безаварийная линия НЕ существует (R = 3 < четырёх концов срока) — жертву
  выбираешь сам; на T4/T5 безаварийная линия стоит +1 плач против par — выбор
  «плачь против крушения» честный.

## Вопрос прототипа (один)
Рождает ли закон «плач отпускает навсегда и стоит рекрута 1:1, а непоплаканная вахта —
дыра на посту» настоящее планирование — момент против глобальной дыры ритуала, фазовое
руление цепями постов, триаж конечного резерва, очерёдность одной руки, — или игрок
тычет призраков по одному без размена? Прототип обязан содержать: обязательную фазу
призрака, автоматическое вступление смены из конечного двора, глобальную дыру такта
плача, финальную бурю по списку постов, счёт крушений (второе = провал) и par — иначе

5, 9}; звёзды: 3 = победа и ≤ par, 2 = ≤ par + 2, 1 = победа.

## Риски баланса
- **«Тыканье по призракам проходит»** — если на T2+ побеждает любой порядок плачей,
  тугими данными (R, плотность бед, список бури), не правилами: BFS-прогон при
  сборке обязан показывать провал asap/затяжника/скупца.
- **«Буря непокрыта / покрыта всегда»** — следить, чтобы поздних прибытий
  (a ∈ [T−L+1, T−2]) хватало на |буря| − 1 постов: это потолок покрытия; при сборке
  пересчитать BFS.
- **«Глобальная дыра не видна»** — сумеречная полоса над полем в такт плача + при
  наведении на призрака превью «беда такта плача пройдёт здесь» с подсветкой бед
  этого такта. Если теряется — не текст, усиливать глиф.
- **«Призрак не читается как дыра»** — призрак полупрозрачный, трещина на посту,
  глиф «беда пройдёт» при наведении; живая — факел/флажок.
- **«Плач без рекрута»** — пост пустеет навсегда: при пустом дворе глиф на призраке
  «двор пуст — пост опустеет навсегда»; закон честный, но должен быть видим ДО клика.
- **par и линии** — подтверждены BFS на скелете (порядок такта из «Правил поля»,
  T5 = 713 709 состояний, секунды); при сборке HTML пересчитать тем же порядком —
  если диагност проваливает не на тех уровнях, двигать данные уровней.
- **Читаемость фазы** — кольцо остатка срока + «конец срока: такт N» на ленте
  календаря; фазовый сдвиг после плача пересчитывается на ленте сразу (превью).

## Что НЕ входит в v1 (осознанно вырезано)
- **Аватар смотрителя и ходьба** — рука абстрактна, посты в ряд.
- **Ручная расстановка рекрутов** (второй глагол) — выбор поста только через цель
  плача; кандидат v2 с отдельной проверкой №12.
- **Разные сроки/типы вахт (короткие, дозорные), болезни часовых, HP** — шкал нет:
  держит/не держит.
- **Случайные беды** — календарь виден с первого такта; RNG нет.
- **Аудио причитаний** — визуальная волна плача; звук — v2.
- Сохранения, мобильные жесты, арт.

## Родство (проверка фильтра, строгая)
- **Посещение (haunt)** — слог сажается В ЗОНУ и тает, освещая её; стая слепа, игрок
  нем. Здесь призрак — СУЩНОСТЬ с обязанностью на посту, плач не тает, а ПРОВОДИТ
  навсегда; зон и стаи нет.
- **Прощание (farewell)** — жесты-слагаемые сгорают как топливо пути, сумма взвешена
  пассажиром. Здесь плач — не топливо и не взвешивается: провод 1:1 с рекрутом,
  открывающий пост.
- **Оставленный лик (parting-face)** — лик снимается с СЕБЯ и остаётся дозором и
  ключом в клетке. Здесь призрак — ЧУЖАЯ кончившая вахта, держит дыру; ни окликов,
  ни ключей.
- **Кукушка (cuckoo)** — яйцо-долг подкидывается в ЧУЖИЕ гнёзда и гасится чужим
  приёмом. Здесь подкидывания нет: замена приходит САМА из очереди, а уходит
  навсегда оплаканный.
- **Карает денёк (condemn-day)** — печать на БУДУЩНЕМ дне, день бьёт той же мерой,
  отбыт засчитывается. Здесь приговора будущему нет: беды бьют только по дырам.
- **Молчком (molchkom)** — молчание выравнивается по горницам и немит хор. Здесь
  молчание — бесплатный пас, а плач — действие с ценой.
- **Ночь (night)** — тьма-наклейка с сохранением, стражи спят в темноте. Здесь
  наклеек нет: призрак не спит — он стоит.
- **Подкараул (ebbwatch)** — окно отлива и доставка до амбара. Здесь окон воды нет:
  расписание бед и замена из двора.
- **Постой (billeting)** — лента кампании и утяжеление каждого следующего постоя.
  Здесь цена плача постоянна (1 рекрут 1:1), а редеет ШТАТ, не лента.
- **Трон на фазе (phase-throne)** — сидение пинует фазу на кольце, пробка из твоих
  же знамён. Родство по «фазовому рулению» (здесь рулит момент плача — сдвиг концов
  сроков), но кольца, сиденья и пина нет.
- **Летопись (chronicle)** — капризы вписываются навсегда и исполняются ночами.
  Здесь вписывается УХОД, а исполняет смена.
- **Август (august)** — ленту грызут куском, дела проваливаются без тебя. Здесь
  лента бед не грызётся — фон; режешь не время, а строй.
- **Напомнит (remind)** — стуки зрелых оброков, казна. Здесь беды не зреют — они в
  календаре с первого такта.
- **Очередь (queue)** — карточка-призрак следующего входа. Там призрак — превью,
  здесь — сущность.
- **Оттиск смерти (death-stamp)** — цепь копий и притяжение тьмы; здесь ни копий,
  ни притяжения.

## Новизна (проверка вебом 2026-11-23, 4 англ. запроса)
Прямого аналога правила «ритуал отпускает кончившую смену из сезона навсегда и стоит
замены 1:1 из конечного резерва, а непоплаканная остаётся на посту дырой, такт ритуала
оставляет всю линию без смотра» не найдено. Ближайшие соседи и чем отличаемся:
**Ghost Trick: Phantom Detective** — духи с незавершёнными делами решаются
вселением в предметы и переписыванием последних 4 минут, адвенчурные паззлы; нет
смен, дыр, резерва и триажа. **Spiritfarer** — отпускание духов через Вечную дверь —
цель и эмоция кооп-менеджмента: отпускание ничего не стоит, пост не открывает и ни
против кого не тикает; здесь отпускание — ход с ценой и двухсторонним спросом.
**Игры планирования смен (Schedge, Shift Scheduling Game Университета Мичигана)** —
абстрактные задачи на ростер без закона провода, призрака и крушений; здесь смена —
сущность с фазой призрака, а расписание — фон конфликта. **Оборона постов
(tower defense, This War of Mine)** — защитники на местах, но нет конца срока,
фазы призрака и провода навсегда. **Give Up the Ghost (itch.io)** — чеклист
транcмерных паззлов на тему «упокоить духов», правила не о том. **Graveyard Shift
(SmartGames)** — гекс-планирование шагов. Пара «оплакивать × вахта» и слот
mournwatch свободны (rg по mechanics/, prototypes/, MECHANICS.md). Комбинация
«фаза призрака ∧ автоматическое вступление из конечного резерва ∧ провод 1:1 с
редеющим строем ∧ глобальная дыра такта ритуала ∧ фазовое руление моментом
плача» новизну держит.

## Критерии приёмки (боты)
Экспорт **window.MOURNWATCH** (state, click(postId), tick()/advance(), loadLevel(i),
staff() → {живые, призраки, двор, ушедшие, прибывшие}, wrecks(), mournings()) для
headless-тестов. Порядок такта — из «Правил поля».
- **План-бот** (BFS живых состояний; par и эталонные линии — из раздела «Уровни»,
  пересчитать на скелете HTML тем же порядком такта): побеждает T1–T5, плачей ≤ par.
- **Диагност «горевальщик»** (оплакивает первый призрак немедленно, каждый такт):
  T1 побеждает (вводный), T2–T5 провал — резерв сгорел, фазы съехали в бурю.
  Побеждает T2+ — данные уровней неверны (тугее R и беды, не правила).
- **Диагност «затяжник»** (плачет в последний такт перед следующей бедой поста,
  бурю — в последний возможный): T1 побеждает, T2–T5 провал — окна закрыты,
  рука одна у бури, ритуал ловит беду в свой такт.
- **Диагност «скупец»** (плачет только когда беда ≤ 2 тактов от дыры, бурю не
  готовит): T1 побеждает, T2–T5 провал — буря встречает ≥ 2 дыры.
- **Случайный бот**: T2–T5 ≤ 2 побед из 40 (на скелете: 2, 0, 0, 0); на T1 побеждает
  часто — вводный, допустимо.
- **Ассерты (№9)**: каждый такт живые + призраки + двор = P + прибывшие − ушедшие;
  каждая вахта — ровно одна фаза призрака; плач только по призраку и один за такт;
  конец срока = вступление + L; вступление только из двора и на пустой пост.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Заголовок страницы —
вопрос прототипа. HUD одной строкой: такт k/T, крушения x/2, плачи против par,
двор + следующее прибытие, штат. Сцена: посты в ряд (живая — флажок и кольцо
остатка срока; призрак — серая фигура с трещиной; пусто — гнездо), лента-календарь
бед и прибытий на весь сезон, метки финальной бури, сумеречная полоса такта плача.
Управление: клик по призраку; наведение — превью (беда поста, кто придёт, что
пройдёт в такт плача). Итог уровня одной строкой (крушения, плачи vs par, такт) —
ответ на вопрос прототипа и лог ботов (план/горевальщик/затяжник/скупец/случайный).
