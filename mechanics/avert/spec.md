# Отвод — спецификация v1 (после фильтра, GO*)

## Название
Отвод (рабочее).

## Пара-источник
отводить_VERB × реалия_NOUN (word2vec RusVectores, sim −0.107, архетип «перенос» 0.321,
сэмпл pairs_new_rules.json; этап 1 — Σ8, топ партии).

## Правило (одно предложение)
Беда летит в твой дом по видимому расписанию: кликни по ней в окне подлёта и кликни по соседу —
она сбудется у него, но терпение соседа не бесконечно: переполнившийся отражает беду по цепочке
к следующему, а замкнувшийся круг возвращает её к тебе с силой вдвое.

## Глаголы игрока (ядро = ОДНО действие: клик)
- **Клик по реалии** (в окне подлёта — последние 4 с её полёта, кольцо у калитки): выбор,
  подсветка; повторный клик — отмена выбора без штрафа.
- **Клик по соседу** (A/B/C): переадресация — терпение соседа −1, кулдаун 4 с стартует с этого
  клика. Автопоиск адресата из эскиза заменён вторым кликом (правка фильтра, №12: игрок
  решает «кому»; один глагол сохранён, как автополёт у «Кукушки»). Мир сам адресует только
  отражения проводника.
Наведение показывает исход заранее (кому уйдёт цепь, кто заплатит слотом) — читаемость,
не отдельное действие. Прогноз-полоса на 15 с вперёд — план; окно подлёта — исполнение.

## Токены
- **Реалия**: иконка (гроза, ревизия, голод, ярость), сила 1–3 (пипсы), момент прибытия
  (видна в прогнозе за 15 с). Расписание дня фиксировано — игрок не создаёт и не отменяет
  беды, только меняет адресатов.
- **Дом**: прочность 3 (три палки). Урон дошедшей реалии = её сила. Прочность 1 — разрушение
  №1 (крыша), 0 — разрушение №2, проигрыш («дом разрушен дважды»).
- **Сосед (3)**: дом на дуге вокруг твоего, терпение 2 принятых переадресованных за забег
  (два паза над крышей). Полный = **проводник** (иконка-цепь): отражает дальше по часовой.
- **Кулдаун отвода 4 с** — единственный ресурс исполнения; кольцо вокруг дома.
- **Окно подлёта 4 с** — единственный ресурс момента: реалию можно кликнуть, только когда
  она у калитки (иначе кулдаун никогда не кусается и решение вырождается в «отвести всё
  заранее»).
- **Отражённая**: летит по цепи A→B→C→дом; первый сосед со свободным пазом принимает
  (его терпение −1, БЕЗ кулдауна игрока); круг замкнулся — возврат к тебе с силой ×2,
  отвести её нельзя.

## Правила переадресации (вся матрица v1)
| Событие | Правило |
|---------|---------|
| Клик по реалии вне окна подлёта | ничего (реалия покачивается; окно видно дугой) |
| Клик по реалии в окне | выбор; повторный клик — отмена |
| Клик по соседу при выбранной реалии | переадресация: паз соседа −1, кулдаун 4 с |
| Цель полна | отражение по цепи: первый свободный принимает без твоего кулдауна |
| Все трое полны | мгновенный возврат ×2 в дом, не отводится |
| Реалия дошла без отвода | удар: прочность −сила; 1 = разрушение №1, 0 = проигрыш |
| Конец дня (расписание исчерпано) | победа при прочности ≥ 1 |

## Петли (7-профиль: тип / эффект / вложение / отдача / скорость / дальность / долговечность)
- **P1 «слоты — щит, который ты тратишь»**: каждое перенаправление жжёт чужое терпение —
  твой будущий запас. − / высокое (распределение по времени) / отложенная / полдня /
  забег / забег — главный бюджет уровней (L3–L5).
- **P2 «отведи мелкую — освободи кулдаун под крупную»**: такт исполнения; в тройках у
  калитки решает, кого принести в жертву. − / среднее / немедленная / 4 с / волна / уровень
  (L2, L5).
- **P3 «проводник как транспорт»**: отвод в полного = бесплатная доставка цепью, но точка
  входа решает, кто заплатит слотом. + / низкое / немедленная / волна / забег / забег.
- **N1 «×2-обратка»**: замкнувшийся круг — ошибка усиливает сама себя, и бьёт по самому
  игроку (закон действует и на него). − destructive / низкое / немедленная / волна /
  забег / забег.
- **N2 «истощение»**: терпение не восстанавливается до конца забега — чем дальше, тем
  дороже каждая переадресация. − / высокое / перманентная / забег / забег / забег.

## Цель и проигрыш
- **Цель**: провести день — расписание исчерпано, дом цел (прочность ≥ 1). Пять уровней =
  пять дней пути каравана; L5 — «восьмидневный переход» (8 реалий = 8 дней, счётчик в HUD).
- **Проигрыш**: прочность 0 → рестарт уровня (уровень 40–60 с, рестарт мгновенный).
- **Звёзды по par** (анти-спам, не штрафы; par = минимум переадресаций победной линии,
  полный перебор): 3★ — переадресаций ≤ par; 2★ — ≤ par+1; 1★ — победа хоть как.
  par: L1=3, L2=4, L3=6, L4=6, L5=6.

## Вопрос прототипа (один)
Рождает ли переадресация с окном подлёта и конечным терпением настоящий разбор — какую,
кому и когда, жри мелочь и береги слоты под крупное, — или панику у калитки? Прототип
обязан содержать: тройку-кластер с разрывом меньше кулдауна (L2), уровень, где штук больше,
чем слотов (L3), и крупный хвост после искушения слить раннюю мелочь в соседей (L4) —
иначе вопрос решён заранее в пользу «темы».

## Критерии приёмки (боты)
- **Экспорт `window.AVERT`** для headless-тестов: `{ CONFIG, LEVELS, redirect(realiaId,
  neighborId), cancel(), restart(), state() }`; `state()` — сериализуемый объект
  `{ level, hp, destructions, slots, cooldown, forecast[], redirects, over, won, stars }`;
  `redirect` возвращает `{ok, reason}`. Все боты — через API, без пикселей, до визуальной
  сборки (урок LOG о достижимости).
- **План-бот** (par-линия уровня, ниже) — 10/10 на каждом уровне; уровни детерминированы.
- **Рандом-бот** (в момент a−1 с: если кулдаун свободен — монетка 50/50 «отвести случайному
  соседу / съесть»; заблокирован — ест): **<50% побед на каждом уровне**. Замер на
  расписаниях спеки (100k симуляций): L1 31.2%, L2 6.3%, L3 4.0%, L4 1.2%, L5 1.6%;
  прототипу достаточно ≥200 партий на уровень.
- **Бот-жралка** (не отводит никогда): 0 побед на всех уровнях (сила расписания 7–17 против
  щита «3 прочности + 6 слотов») — лень «не применять» наказана всегда.
- **Бот-свалка** (всё первому соседу, полный — всё равно в первого): побеждает L1–L2
  (это норма обучения), **гибнет на L3–L5** (7-я и дальше реалии возвращаются ×2) —
  «свалить в угол» наказано структурой.
- **Минимум = par**: par посчитан полным перебором решений и целей по константам ниже.

## Уровни (5, обучение одним намёком; решения и проценты ботов проверены полным перебором)
Запись: реалия «момент прибытия : сила». Клик возможен в окне [прибытие−4, прибытие).

- **L1 «Первая беда»** — день 36 с, реалии 8:2, 16:2, 24:2, 32:1 (сила 7). Учит: клик-реалия →
  клик-сосед; сила видна пипсами. par=3; линия 3★: 8→A, 16→B, 24→C, мелкую 32 — съесть
  (прочность 2, разрушений нет). Рандом-бот 31.2%. Свалка выживает — на L1 всё безопасно.
- **L2 «Тройка у калитки»** — день 40 с, реалии 10:2, 12:2, 14:1, 24:2, 34:3 (сила 10).
  Учит: кулдаун; в тройке с разрывом 2 с спасаешь две — клики в 6-ю и 10-ю секунды
  (разрыв ровно кулдаун), мелкую 14 не успеть — жрётся. par=4; линия: 10→A, 12→B, 24→C,
  34→B, съесть 14 (прочность 2). Рандом-бот 6.3%.
- **L3 «Полные руки»** — день 48 с, реалии 6:2, 12:2, 18:2, 26:3, 32:3, 38:2, 44:2 (сила 16).
  Учит: штук больше, чем слотов (7 против 6) — считай терпение. par=6; линия: съесть 6:2,
  остальные — по пазу каждому соседу (слоты кончаются ровно к финишу, прочность 1 —
  разрушение №1 по закону «беда не исчезает»). Рандом-бот 4.0%. Свалка гибнет: 7-я реалия
  возвращается ×2 = 4 урона.
- **L4 «Расплата»** — день 56 с, реалии 6:1, 12:1, 18:2, 24:1, 32:3, 38:3, 44:3, 50:2
  (сила 16). Учит: жри мелочь первой половины — слоты понадобятся крупному хвосту
  (P1). par=6; линия: съесть 6:1 и 12:1, шесть крупных — по пазу (прочность 1).
  Рандом-бот 1.2%. Свалка гибнет: переполнив соседей мелочью, ловит хвост ×2 = 6 урона.
- **L5 «Восемь дней»** — день 52 с, реалии 6:2, 8:1, 16:3, 22:2, 30:3, 32:1, 40:3, 47:2
  (сила 17); каждая реалия = день пути, HUD «день N/8». Экзамен: пары (6,8) и (30,32)
  спасаются только ранними кликами, но слотов на всех не хватает — выбери, ЧТО съесть.
  par=6; линия: 6→A, съесть 8, 16→B, 22→C, 30→A, съесть 32, 40→B, 47→C (прочность 1;
  линия без разрушений на L5 невозможна — 17 силы не помещаются в 6 слотов и 2 единицы
  брони). Рандом-бот 1.6%.

## Стартовые константы (числа для HTML, править при балансировке)
Один экран 960×640: твой дом внизу центра, соседи A/B/C по дуге сверху (разные крыши,
без текста), прогноз-полоса 15 с во всю ширину сверху (иконка + пипсы силы + метка
прибытия), реалии летят сверху к твоей калитке. Окно подлёта 4 с — пульсирующее кольцо
у калитки; кулдаун 4 с — кольцо вокруг дома; терпение — два паза над каждым соседом;
выбранная реалия — нить к курсору. Прочность 3 палки (трещина при 1). HUD одной строкой:
день (на L5 «день N/8»), прочность, переадресации X/par, звёзды. Расписания — данные
(arrival/force per level), всё в CONFIG вверху файла.

## Риски баланса
- **«Отвести всё заранее»** — если кликнуть реалию до окна подлёта, кулдаун перестаёт
  кусаться и игра вырождается в сортировку без момента. Противоядие: окно 4 с как
  константа-предохранитель; клик вне окна — только покачивание. Первая проверка: ранний
  клик не резервирует цель.
- **«Спасай пары ранним кликом» становится обязательной** — противоядие: тройки с разрывом
  2 с физически не спасаются (L2), а на L5 спасение пары сжигает слот, который нужен
  крупной — расписание само ставит цену. Проверить на L5, что линия «спас всё» гибнет.
- **Разрушение №1 на par-линиях L3–L5** — закон «беда не исчезает», а не жестокость:
  сила расписания больше, чем щит. Если тестеры читают как несправедливость — прочность 4
  на L3+ с пересчётом par полным перебором (не таймер, не случайность).
- **Читаемость цепи** — при прицеливании в полного соседа показывать стрелки цепи и
  подсвечивать конечного принимающего; если не читается — подсветка раньше, правила не менять.
- **Спам-паника у калитки** — кулдаун 4 с + окна: отведя мелкую раньше крупной в той же
  тройке, теряешь крупную. Проверка: спам-бот (отводит первую попавшуюся) обязан проигрывать
  L2 и L5.
- Все константы вверху прототипа в один объект CONFIG; уровни — данные.

## Что НЕ входит в v1 (осознанно вырезано)
- **Реалии, изначально идущие к соседям** («реалии идут к адресатам» в эскизе) — мир-каскад
  без игрока ломает одно действие и читаемость; v1: все беды летят к твоему дому. Кандидат v2
  (одна «чужая» реалия на L5, если день покажется пустым).
- **Выбор направления отражения и встречные переадресации соседей** — цепь по часовой
  детерминирована и видна заранее; ветвление — кандидат v2.
- **«Отвести в пустоту»** (отмена беды) — запрещено законом пары: беда никогда не исчезает.
- Прогресс терпения между днями (сброс за забег — константа), несколько домов игрока,
  генерация уровней, арт/аудио, мобильное управление.

## Новизна (проверка вебом 2026-11-14, 4 запроса)
Прямого аналога «расписание бед + переадресация кликом + терпение-цепь с ×2-обраткой»
не найдено. Ближайшие соседи и чем отличаемся: **hot potato / Pass the Bomb** (Roblox,
Minecraft-минигры, партийные) — бомбу НОСЯТ и передают из рук в руки, она одна, без
расписания, терпения и цепей; **Stop Disasters** (UNDRR) — защита себя от беды, а не
смена адресата; **Neighbours from Hell / Neighbors: Suburban Warfare** — причинение
беды соседу, а не перенаправление входящей; **редиректы урона в карточных играх**
(MtG, Pariah) — стационарный эффект карты без расписания и маршрута. Занятые слоты:
**«Кукушка»** — СВОЁ яйцо-долг носишь и подсаживаешь в окна хозяев; **«Слухогон»** —
СВОЮ посылку несёшь и мутируешь по табличкам; здесь беда ВНЕШНЯЯ и летит по расписанию
К ТЕБЕ — ты её не носишь, одним кликом отказываешься от доставки, а мир сам ретранслирует.
Отличающее поведение: не груз, а отказ от удара; не прячешься, а выбираешь, кто заплатит;
кара — замкнувшийся круг ×2, а не чужой ход.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Управление: только клики
(реалия → сосед; повторный клик — отмена). Состояние читается без текста: сила — пипсы,
терпение — пазы, окно — кольцо у калитки, кулдаун — кольцо у дома, проводник — иконка-цепь,
разрушения — трещины и провал крыши. HUD одной строкой; итог уровня одной строкой
(переадресаций против par, прочность, разрушения) — ответ на вопрос прототипа. Заголовок
страницы = вопрос прототипа. window.AVERT для headless-ботов — приёмка до визуальной
сборки.
