# Перелицовка — спецификация v1 (после фильтра, GO* 16/16, потолок пары)

## Название
Перелицовка (рабочее; слот reface).

## Пара-источник
перелицевать_VERB × приглашение_NOUN (word2vec RusVectores, волна 56→перепарка: sim
−0.116; этап 1 — Σ8, потолок пары 16: №1 = 2, №4 = 2 — мост «перелицевать
программу/политику», дипломатическая перелицовка писем, №5 = 2 — рука перелицовывает,
приглашение живёт само — ждёт вручения, истекает, обязывает обоих, №8 = 2 — перенос
по формуле: обязательство перетекает на нового адресата). Законы: «перелицевание
привносит выворачивание лицевой стороны: звать можно теперь другого — старое имя уходит
наизнанку» / «приглашение сохраняет адресность — пригласить можно только кого-то:
не вручённое приглашение не существует». Формула: **можно перелицевать приглашение, но
тогда старое имя проступит на новом лице — бумага тоньше желания**. Стоп-лист чист.
Оси: max 0.246 к перетряхивать (проверено моделью 2026-11-23) — чисто.

## Правки фильтра (шесть; одной ревизией — сырой эскиз не задал вручение, счёт
## скандалов и окна)
1. **Слоты-визиты и закон вручения (№9, детерминизм для ботов и par).** Эскиз сказал
   «вручить» без механизма. Заземлено: гости сидят по МЕСТАМ круга; карточка лежит НА
   МЕСТЕ своего лица; у каждого гостя ОДИН слот-визит (лента тактов видна заранее).
   В слот место гостя проверяется: ровно одна чистая карточка — ВРУЧЕНА, гость уходит
   довольным (место пустеет); до слота место транзитное — карточки лежат, гость не
   смотрит; пропустивший слот гость остаётся и со своего такта проверяет КАЖДЫЙ такт
   (место «заряжено» — транзит через него рискует дублем). Порядок такта: клики игрока
   (свободны между тактами) → визит-проверки → истечения → счёт. Не менять при сборке.
2. **Изнанка-стек с верхом (№9, «вывернуто, а не переписано»).** Перелицовка НЕ
   стирает старое имя — оно уходит в СТЕК изнанки (push); стек не pops никогда —
   содержимое на месте, знак сменился. Виден только ВЕРХ стека (последний прежний
   адресат) — просвет-штрихи на лице. Улика при вручении: верх — имя ЕЩЁ
   ПРИСУТСТВУЮЩЕГО гостя → скандал. Утопить улику можно только маршрутом ЧЕРЕЗ
   ушедшего: его имя ложится на верх и при вручении безопасно.
3. **Скандал-счётчик — право на один (№10/№11/№14, «дважды просвет» из эскиза).**
   Скандал = обида гостя: (а) ДУБЛЬ — в проверку на месте ≥2 неотвергнутых: гость
   берёт «лучшую» (чистая > улика; при равенстве мин. срок, затем мин. износ, затем
   лежавшая раньше), прочие ОТВЕРГАЕТ (персональная маркировка — этому гостю карточка
   не вручается больше никогда); (б) УЛИКА — одна карточка, но верх стека присутствующий;
   (в) ИЗНОС ≥4 — переклейка видна с порога. Первый скандал переживаем (карточку
   можно увести и вручить дефицитному), второй — гость хлопнул дверью: провал
   немедленный. par-решения всех уровней обходятся без скандалов; дубль-сортировка —
   сознательный инструмент передачи срочной карточки ценой права.
4. **Сгорание срока (закон №6 «не вручённое не существует»).** У каждой карточки
   ЛИЧНЫЙ срок (кольцо-таймер на карточке); перелицовкой не двигается. Невручённая к
   концу своего срока карточка сгорает публично — её гость без приглашения, вечер не
   спасти: провал фиксируется на K-резолве (игрок видит обречённость заранее). Внутри
   такта визит проверяется ДО истечения — вручение впритык (срок = слоту) легально.
5. **Клик = перелицовка вперёд по кругу (№12, второй глагол запрещён).** Клик по
   карточке: лицо переписывается на СЛЕДУЮЩЕГО по кругу, прежнее лицо — в стек,
   износ +1. Разворота нет, обратно изнанку лицом не сделать. Клик по карточке
   на месте ушедшего и по сгоревшей пуст (цены нет). Клики свободны между тактами —
   вся цепь маршрута загружается одним окном; давление делают сроки и слоты.
6. **Три ситуации разведены (№15).** (a) ДОЖАТЬ СРОК — срочную профицитную успеть к
   слоту дефицита коридором, а когда срок короче пути — отдать ДУБЛЕМ-сортировкой
   (гость берёт самую срочную чистую, отвергнутая своя едет дальше); (b) КОРИДОР
   ОКОН — hops через места будущих гостей так, чтобы к каждому слоту на месте была
   ровно одна; (c) КЛАДБИЩЕ-ТРАНЗИТ И ВЕРХ — чтение стеков: маршрут через ушедших
   топит улику под безопасный верх ценой износа и узких окон.

## Правило (одно предложение)
Приглашения лежат лицом вверх на местах своих адресатов, каждое тикает к своему сроку,
а гости подходят к столу по ленте слотов и берут карточку с своего места — но клик по
карточке перелицовывает зов на следующего по кругу: старое имя уходит наизнанку, где
копится непостираемым стеком, и верх его просвечивает — улика на живом госте, переклейка
с четырёх перелицовок видна с порога, дубль на месте гость разбирает сам, беря лучшую и
отвергая прочие, — так что весь протокол: доведи каждый зов до дефицитного места по
окнам чужих слотов, топи чужие имена через ушедших и не дай ни одной бумажке сгореть.

## Глаголы игрока
- **Клик по карточке** (единственный глагол): перелицовка — лицо → следующему по
  кругу, прежнее лицо push в стек, износ +1. Разворота нет; клик по сгоревшей пуст.
- Наведение — превью: верх стека просветом, слои износа, кольцо срока, следующий
  по кругу, слот гостя-места — читаемость, не действие. Аватара и ходьбы нет.
- **R** — уровень заново (всё детерминировано).

## Токены
- **Место** (4–6 по кругу): гость + подложка для карточек. Три температуры: до слота —
  транзитное (гость не смотрит), слот — проверка, после пропущенного слота — заряженное
  (проверка каждый такт), после вручения — кладбище (пусто, лицо на ушедшего обречено,
  транзит свободен).
- **Карточка**: лицо (имя-адресат) + стек изнанки (непостираемый, виден верхом) +
  износ (= число перелицовок, лимит бумаги 3) + личный срок (кольцо) + маркировки
  отвержений (крестик гостя).
- **Гость**: слот-визит на ленте тактов; довольный уходит (сервирован), ждущий
  проверяет ежетактно, обиженный — скандал в счётчике.
- **Скандал-счётчик**: право на один; второй = хлопок дверью = провал немедленно.
- **Лента слотов**: визиты всех гостей по тактам — видна с первого кадра (как скрипт
  «Посланного тона», как ведомость входов «Подкидыша»).
- **K** — конец вечера: резолв — все гости сервированы и ни одна карточка не сгорела.
- **Клики** — валюта звёзд против par.

## Инварианты (№9)
- Карточки не создаются и не копируются рукой; сгорание — только законом срока; стек
  каждой карточки только растёт и никогда не стирается («перелицованное не переписано,
  а вывернуто»); лицо+стек = полная история адресации; износ = длина стека.
- Перелицовка не меняет срок и не двигает карточку с места (место = место лица).
- Состояние — чистая функция (последовательность кликов по тактам); слоты и сроки —
  константы уровня; случайностей нет. Следствие: par доказуем полным перебором живых
  состояний на скелете до HTML (карточки × стеки-верха × износы × маркировки × такт).

## Двусторонний спрос (№10)
- **Перелицовки** хочется больше (спасти сгорающее, развести дубль, добросить в
  дефицит) и меньше (каждая — износ к порогу «видно с порога» и новая улика на верхе).
- **Срок** хочется тянуть (успеть коридором) и не тянет никогда — он константа
  бумажки; успеть хочется до, а вручаться хочется чисто — пути «быстро» и «чисто»
  расходятся.
- **Дубль** хочется устроить (сортировка отдаёт гостю самую срочную — передача без
  кликов) и бояться (скандал из права и отвергнутая карточка едет дальше).

## Петли
- **P1 перелицовка → стек**: каждый клик пишет будущее вручение — верх решит, скандал
  или берут; маршрут и есть решение.
- **P2 слот → окно**: до слота место транзитно, после — заряжено; hops планируются по
  ленте слотов, как стрелки адресаций в «Посланном тоне».
- **P3 кладбище-транзит**: ушедший открывает место — через него возят улики, ставя его
  имя на верх; кладбище — и спасение, и мина (лицо на ушедшего — сгорание).
- **N1 дубль-сортировка**: гость берёт самую срочную чистую — отвергнутая своя едет
  дальше к дефициту; скандал из права потрачен осознанно.
- **N2 сгорание впритык**: визит проверяется до истечения — срок = слоту легален;
  один лишний такт на маршруте — бумажки нет.
- **Структура против доминирующих стратегий**: «ничего не делать» — дубль в первый
  же сдвоенный слот и сгорание профицита (T2–T5); «перелицовывать всё подряд» —
  износ ≥4 и застревания лицом к ушедшим; «свалить в угол» (гонеть всё на последнее
  место) — сгорания на кладбище; «копить» — копить нечего: клик не ресурс, его цена —
  бумага и улика (№13).

## Цель и проигрыш
- **Цель**: к K все гости сервированы (каждый унёс по одной карточке с своим лицом).
- **Звёзды**: 3 — победа ∧ 0 скандалов ∧ клики ≤ par; 2 — победа ∧ (клики ≤ par+1 ∨
  ровно 1 пережитый скандал); 1 — победа.
- **Проигрыш**: второй скандал (хлопок дверью — немедленно) или K-резолв при
  несервированном госте / сгоревшей карточке. Рестарт уровня (~1 мин).

## Вопрос прототипа (один)
Рождает ли закон «старое имя не стирается, а уходит наизнанку и просвечивает верхом»
настоящее планирование — маршруты по окнам слотов, топление улик через ушедших,
передачу срочной дублем-сортировкой, чтение стеков — или игрок перелицовывает наугад
и угадывает? Прототип обязан содержать: ленту слотов с гостями-местами, непостираемые
стеки с видимым верхом, личные сроки с сгоранием, дубль-сортировку с персональными
отвержениями, счёт кликов против par — иначе вопрос решён заранее в пользу «темы».

## Уровни (5, обучение одним намёком; решения сведены на бумаге по константам)

- **T1 «Первая изнанка»** — круг A,B,C; слоты A:2, B:4, C:6; K=8. Карточки: кA(9),
  кB(9), кA2(лицо A, срок 5); дефицит C. Решение: до t1 два клика: кA2: A→B→C
  (стек [A,B], износ 2); t6 C берёт (верх B ушёл t4). par 2. Учит: клик = перенос
  на следующего; изнанка копится; верх читают. Пассив: кA2 сгорает t5 → провал.
- **T2 «Окна»** — круг A,B,C,D; слоты A:1, B:3, C:5, D:7; K=10. Карточки: кA(9),
  кB(9), кC(9), кA2(лицо A, срок 9); дефицит D. Решение: до t1 три клика: кA2:
  A→B→C→D (износ 3 — на пределе бумаги); t7 D берёт (верх C ушёл t5). par 3.
  Учит: вся цепь загружается в окне до чужих слотов. Пассив: дубль на B t3 (скандал 1,
  кA2 отвергнута) → кA2 сгорает лицом к ушедшему, D без бумажки → провал на K.
- **T3 «Кладбище»** — круг A,B,C,D; слоты A:1, B:2, C:3, D:4; K=6. Карточки: кA(6),
  кB(6), кC(6), кB2(лицо B, срок 5); дефицит D. Решение: до t2 два клика: кB2:
  B→C→D (стек [B,C], износ 2); t4 D берёт (верх C ушёл t3, срок впритык). par 2.
  Учит: верх надо ТОПИТЬ заранее — ушедший сосед делает вручение чистым. Ловушка
  полшага: только B→C → дубль на C t3 → кB2 отвергнута → сгорает t5 → провал.
- **T4 «Впритык»** — круг A,B,C,D; слоты A:1, C:2, D:3, B:5; K=7. Карточки: кA(6),
  кA2(лицо A, срок 3), кC(6), кB(6); дефицит D. Решение: до t1 три клика: кA2:
  A→B→C→D (стек [A,B,C], износ 3); t3 D берёт — срок 3 горит в тот же такт ПОСЛЕ
  визита: впритык легален. par 3. Учит: бумага держит ровно три перелицовки; срок =
  слоту успевает. Пассив: дубль на A t1 (A берёт срочную кA2 дублем-сортировкой,
  кA отвергнута) → кA не довезена → сгорает t6, D без бумажки → провал на K.
- **T5 «Экзамен»** — круг A,B,C,D,E; слоты A:1, B:2, C:3, D:5, E:6; K=7. Карточки:
  кA(7), кB(6), кB2(лицо B, срок 5), кC(5), кC2(лицо C, срок 6); дефициты D, E.
  Решение: до t1 ЧЕТЫРЕ клика (два маршрута разом): кB2: B→C→D (стек [B,C], износ 2);
  кC2: C→D→E (стек [C,D], износ 2); t5 D берёт кB2 (верх C ушёл t3, срок впритык),
  t6 E берёт кC2 (верх D ушёл t5, срок впритык). par 4. Учит: оба маршрута в одном
  стартовом окне; два стека на верх. Пассив: дубль на B t2 (скандал 1) → дубль на
  C t3 (скандал 2) — хлопок дверью, провал немедленно.
- Все par — ГИПОТЕЗЫ: подтвердить полным перебором живых состояний на скелете до HTML.

## Стартовые константы (числа для HTML, править при балансировке)
Один экран 960×640; уровень — данные (круг мест, слоты гостей, карточки: лицо/стек/
срок, дефициты, K, par). Лимит бумаги: износ ≤3 (4-я перелицовка = переклейка видна).
Такт 0.9 с (визит-проверка 0.3 с); лента слотов сверху, маркер текущего такта; места
по кругу, карточка = прямоугольник с лицом, просветом верха изнанки и слоями потёртости;
кольцо срока вокруг карточки, мигание на последнем такте; крестик отвержения. par:
{2, 3, 2, 3, 4} гипотезы; звёзды: 3 = победа+0 скандалов+≤par, 2 = ≤par+1 или 1
скандал, 1 = победа. Всё — в одном объекте CONFIG; уровни — данные.

## Риски баланса
- **«Стек непрозрачен»** — главный риск: игрок не видит, чьё имя окажется верхом к
  вручению. Противоядия: просвет-штрихи верха на лице карточки, при наведении —
  весь стек + имя следующего по кругу. Если теряется — НЕ текст: крупнее глиф верха.
- **«Дубль-сортировка мутна»** — гость берёт «лучшую»: правило одной строкой в
  подсказке наведения (какая возьмётся, какая отвергнется). Если не читается —
  глиф руки над берущейся, не менять закон.
- **«Сгорание обидно впритык»** — мигание кольца на последнем такте и порядок
  «визит → истечение» показаны на T4 одним намёком; если тестеры горят — срок T4
  поднять до 4 (уровень, не правила).
- **«Перелицовка наперегонки с тактом»** — клики свободны между тактами; если игрок
  путается в окнах — подсветить в ленте слотов такты-дедлайны каждого маршрута.
- **«Рандом выигрывает»** — проверить ≥20 000 прогонов на T2–T5; если >50 % — сжать
  окна слотов данными уровней, не трогать законы.
- **№13-щит**: «приглашение → ресурс» — ресурс запасают и тратят дозой; тут карточка
  адресна и консервативна, не тратится вовсе, а сгорает по своему сроку, не по воле
  руки. «перелицевать → использовать» — использование не оставляет изнанки-истории и
  не переносит зов на конкретного соседа по кругу. Правила меняются.

## Что НЕ входит в v1 (осознанно вырезано)
- **Разворот перелицовки** (вывернуть обратно, pop стека) — против инварианта
  «не переписано»; изнанка не становится лицом никогда.
- **Клики по гостям** (выбор направления перелицовки) — перелицовка идёт строго
  вперёд по кругу; выбор направления = дозировка пространства, кандидат v2.
- **Пересадка гостя, второй хозяин вечера, карточки-близнецы без дефицитов** — v2.
- **Скрытые лица** (карточки лицом вниз) — кандидат v2: слепое вручение убивает
  чтение стеков.
- Реалтайм и таймеры — пошаговый такт; давление делают сроки и слоты. Тач,
  сохранения, арт/аудио — вне v1.

## Родство (проверка фильтра, строгая)
- **«Отвод»** (avert, отводить × реалия): там беда ЛЕТИТ по расписанию и
  переадресуется кликом в окне подлёта, с кулдауном и терпением соседей; тут ничто
  не летит — карточка стоит на месте, а перелицовка переписывает АДРЕСАТ по кругу и
  копит нестираемую изнанку-улику; вручение — по слотам гостей, не перехват.
- **«Подкидыш»** (foundling, проскользнуть × рецепт): там лист САМ ходит по графу
  щелей и приписывается производству, вымещая прежнего; тут карточка не ходит вовсе —
  только рука перелицовывает, и нет приписки-закона места: есть вручение по слоту.
- **«Приписной»** (force-address, прописывать × богатырь): там перепрописка — АКТ
  РУКИ, обнуляющий пик: история сотрётся и начнётся заново; тут перелицовка НЕ
  стирает — старое имя уходит наизнанку и ПРОСТУПАЕТ уликой. Сила по адресу против
  зова с изнанкой.
- **«На поводу»** (selfbind, отдаться × договоренность): там обязательство = ЛИНИЯ,
  стягивающая подписантов к исполнению; тут обязательство = адрес на бумаге без
  всякой тяги — перестановка, не физика.
- **«Судный день»** (condemn-day, карать × денёк): там тоже «мера сохраняется»
  (приговор не меняет день), но меняется УЧЁТ игрока; тут содержание тоже сохраняется,
  но оно не учёт, а ВИДИМАЯ улика — проступает обратно, и меняется не прожитие, а
  адресат вручения.
- **«Послать тон»** (send-tone, посылать × интонация): там токен-окраска сам
  перескакивает по адресациям реплик, отправитель глохнет; тут перескок только
  рукой, карточка хранит ИСТОРИЮ адресатов, вручение по слотам, улика и скандал.
- **«Ведомость»** (closed-list, смыкаться × список): там кольцо само исполняет
  строки; тут ничего не исполняется само — слот-проверка и сгорание срока.
- **«Подпись»** (signature, подписывать × погода): там подпись заказывает завтра;
  тут изнанка хранит вчера — инверсия времени бумаги.
- Слот reface и пара «перелицевать × приглашение» свободны (rg MECHANICS.md +
  mechanics/ + .data — пусто).

## Критерии приёмки (боты)
Экспорт **window.REFACE** (`{CONFIG, LEVELS, loadLevel(i), click(cardId), tick(),
state(), guests(), par()}`) для headless-тестов. `click(cardId)` → `{ok, reason}`:
`'burnt'` (сгорела), `'ok'`; отказ не меняет состояние. `tick()` — один такт
(визит-проверки → истечения) синхронно. `state()` — сериализуемый `{level, tick,
seats:[{guest, slot, served|waiting|gone}], cards:[{id, face, stack[], wear, term,
rejectedBy[], burnt, seat}], scandals, clicks, won, lost, stars}`.
- **План-бот** (эталонные решения из «Уровней»): 5/5 побед, клики = par, 3★ везде.
  Обязательный.
- **Пассив-бот** (0 кликов): провал на всех уровнях — T1 сгорание кA2 t5; T2 дубль
  t3 + сгорание кA2, D не сервирован; T3 кB отвергнута дублем t2 → сгорание; T4 D не
  сервирован + сгорание кA; T5 второй скандал t3 — хлопок дверью немедленно.
  Обязательный (№14 «не применять»).
- **Спам-бот** (каждый такт перелицовывает самую свежую карточку): износ ≥4 и
  застревания лицом к ушедшим → сгорания/скандалы → провал на всех уровнях.
  Обязательный (№14).
- **Диагност «в угол»** (все hops гонит на последнее место круга): карточки
  застревают лицом к неслотившемуся или сгорают на кладбище → провал T2–T5.
  Обязательный (№14 «свалить в угол»).
- **Рандом-бот** (случайные легальные клики; 20 000 прогонов, seed 7): T2–T5 побед
  < 50 % (T1 — норма иногда).
- **Инварианты во всех прогонах**: стеки только растут; износ = длина стека; клик не
  меняет сроки и место; сгорание только законом срока; состояние — чистая функция
  клик-лога; одинаковые последовательности кликов — одинаковые состояния.
- Любая правка констант/раскладов — перепрогон всех ботов и переподтверждение par
  перебором до HTML.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Заголовок страницы —
вопрос прототипа. Управление: мышь — клик по карточке (перелицовка вперёд по кругу),
R — заново. Состояние читается без текста: лента слотов с маркером такта, места
круга с температурами (транзит/слот/заряжено/кладбище), карточки с лицом, просветом
верха изнанки, слоями потёртости, кольцом срока, крестиками отвержений. HUD одной
строкой: такт k/K · сервировано x/y · скандалы 0/1 · клики против par. Итог уровня
одной строкой (сервировано, клики vs par, скандалы) — ответ на вопрос прототипа и
лог ботов (план/пассив/спам/в-угол/рандом).
