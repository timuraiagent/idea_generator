# Клин — спецификация v1 (после фильтра, GO* 15/16 — потолок пары: №4 = 1)

## Название
Клин (рабочее; слот unwedge).

## Пара-источник
раскрыть_VERB × клин_NOUN (этап 1 — Σ7 из 8: №1 = 2, №4 = 1 — мост «вбить клин (между
своими)», «клин клином вышибают», «расклинить», но «раскрыть клин» не заморожено,
№5 = 2 — раскрытие рукой, клин — вставленный раздор: давит сам и держит больше
человека — распёртый стык держит груз, который вручную не удержать, №8 = 2 — поле).
Законы: «раскрытие привносит распор — начав открываться, клин не вынимается: раскрытое
держится только пока он внутри» / «клин сохраняет давление — распирая щель тут, он
отдаёт натиск в соседние стыки: сумма раскрытий постоянна». Формула: **можно раскрыть
клин — всадить его в стык и распереть проём, но тогда его натиск уйдёт в соседние
стыки: раскрыв тут, сжал там, и вынуть его уже нельзя — только схлопыванием**. Стоп-лист
чист (№2 = 0).

## Правки фильтра (пять; сырой эскиз держал №9 декларацией и не наказывал пассив)
1. **Одна валюта и строгая арифметика (№9).** В эскизе «натиск» и «раскрытие» — две
   сущности без правил перевода; сумма «постоянна» на словах. Правка: распор — целые
   ЕДИНИЦЫ на стыках, Σ = C на уровень, кап 2 на стык; стык ОТКРЫТ ⇔ распор ≥ 1
   (ширина проёма = единицы; клин как отдельный маркер вырезан — открытие и есть
   распертость, а закон «не вынимается без схлопывания» остался правилом вынимания).
   ВБИТЬ: стык забирает по 1 единице у каждого соседа-стыка с ≥ 1 (поджатые → 0
   захлопываются). ВЫНУТЬ: все k единиц стыка уходят ВОЛНОЙ схлопывания — BFS по графу
   стыков, каждая садится в ближайший стык с < 2; сам стык закрывается в 0. Ни один
   глагол не создаёт и не убивает распор; боты assert'ят Σ каждый тик.
2. **Часы и поражение (№14).** В эскизе провалы названы, но часов нет — «ничего не
   делать» не наказано. Правка: вода ползёт по расписанию уровня (каждые W тактов
   фронт +1 стык по ОТКРЫТЫМ стыкам; коснулась груза или сухого отсека — провал) и
   тик-лимит K (не доставил груз — провал). Стартовая раскладка держит распор прямо
   на дверях воды: пассив = потоп, сам уровень начинает под давлением.
3. **Груз-автомат и «раздавлен поджатым» (№11/№12).** В эскизе «провести груз» без
   исполнителя и без цены закрытий. Правка: груз сам идёт 1 стык/такт по кратчайшему
   открытому пути к выходу (пути нет — стоит), у игрока второго глагола нет; закрытие
   стыка с грузом внутри = провал «раздавлен поджатым стыком» — твоё ВБИТЬ рядом
   может высосать последнюю единицу из-под груза: закон бьёт по тебе твоим же
   открытием.
4. **Волна — снаряд через пробку (№15-3).** Цепной отпуск в эскизе заявлен, но
   механизм дальности не назван: без капа волна всегда стелется кругом и дальний
   стык недостижим. Правка: полные стыки (2/2) волну НЕ принимают — единицы летят
   мимо них дальше; насыпь коридор-пробку 2/2, выни хвост — волна прокатится по
   насыпанному и распахнёт дальний стык БЕЗ клина («клин клином вышибают»). Твоя же
   волна не различает свои цели и двери воды: распахнула фронт — потоп (№11).
5. **Тупики-стоки (№10, парковка).** «Отведя сжатие в тупиковый стык» без определения
   тупика. Правка: тупик = стык у грунта/края, через него нет сквозного хода — ни
   грузу, ни воде дальше; законная стоянка распора, но каждый тупик один, и соседи
   его платят: где стоянка, там и цена. Спрос «открыть/закрыть» разведён уровнями:
   коридор грузу (открыть), двери воды (закрыть), стык с грузом внутри (не трогать) —
   все три дерутся за одну сумму.

## Правило (одно предложение)
Распор один на весь фундамент, Σ = C: клик по закрытому стыку ВБИВАЕТ клин — стык
сосёт по единице из соседних стыков (поджатые захлопываются) и распахивает проём,
клик по открытому ВЫНИМАЕТ — проём схлопывается, а вся его распорка уходит волной по
стыкам в ближайшие неполные (полные 2/2 прокатывают волну дальше — насыпь пробку, и
дальний стык распахнётся без клика); груз сам идёт по открытым стыкам к выходу, вода
сама ползёт по открытым стыкам по расписанию — открой коридор, сомкни за спиной,
закрой её двери и доставь груз, не раздавив его захлопнутым стыком, тратя клики
против par.

## Глаголы игрока
- **Клик по стыку** (единственный глагол; закрытый = ВБИТЬ, открытый = ВЫНУТЬ).
  Дозировки нет: единицы атомарны, мера клика фиксирована (по 1 с соседа; вся сумма
  волной). Исполненный клик считается против par; клик с нулевым сбором (все соседи
  пусты) исполнен и посчитан — превью показывает это заранее.
- **Наведение-превью** (читаемость, не действие): откуда придут и куда уйдут единицы
  (стрелки с числами), какие стыки захлопнутся в 0 (красная метка; красный ореол —
  если там груз), куда докатится волна вынимания (пунктир BFS + будущие места единиц).
- Тела игрока нет: груз и вода ходят сами, игрок только перекраивает распор.

## Токены
- **Доска** — сетка клеток; уровень задаёт типы: ПЛИТА / СТЫК / ГРУНТ. Стыки — щели
  между плитами: по ним ходят груз и вода. Соседи стыка S = стыки, прилегающие к его
  плитам (распор передаётся ЧЕРЕЗ ПЛИТУ — геометрия решает, кому платить).
- **Распор** — целые единицы на стыках, Σ = C (8–14), кап 2 на стык; открыт ⇔ ≥ 1.
  HUD-счётчик «распор C/C» — боты assert'ят каждый тик.
- **Волна схлопывания** — release k единиц: BFS от стыка в фиксированном порядке
  направлений; каждая единица садится в ближайший стык с < 2 (полные прокатывают);
  стык-источник → 0. Проходные стыки мигают, остаются только места посадки.
- **Груз** (1 на уровень) — ящик в стыке; 1 стык/такт по кратчайшему открытому пути
  к выходу (тай-брейк направлений фиксирован), пути нет — стоит. В стыке с грузом
  распор не может уйти в 0 без провала.
- **Вода** — источник (клетка) + расписание W: каждые W тактов весь фронт +1 стык по
  открытым стыкам разом (комком, не ручьём). Закрытый стык воду держит. Вода, вошедшая
  в стык с грузом или в клетку сухого отсека, — провал.
- **Тупики** — стыки с меткой (прилегают к грунту/краю): сквозного хода нет, законная
  стоянка распора; уровни держат их вне досягаемости воды.
- **Выход** — люк-клетка; сухой отсек — клетки вокруг выхода, которые вода не должна
  коснуться (на T1–T2 может отсутствовать).
- **Такт** — 0.7 с: клики_resolve → груз шаг → вода по расписанию → проверки провала.
  Партия = K тактов уровня (кончились — провал).

## Правила (вся матрица v1)
| Событие | Правило |
|---------|---------|
| Клик по закрытому стыку | ВБИТЬ: +1 единица с каждого соседа-стыка с ≥ 1 (сбор 0 = потраченный клик) |
| Клик по открытому стыку | ВЫНУТЬ: все k единиц — волной BFS в ближайшие стыки с < 2; стык → 0 |
| Стык закрылся в 0 с грузом внутри | провал «раздавлен поджатым стыком» |
| Груз жив | каждый такт: шаг 1 стык по кратчайшему открытому пути к выходу; нет пути — стоит |
| Вода, каждые W тактов | весь фронт +1 стык по открытым стыкам разом |
| Вода вошла в стык с грузом / в сухой отсек | провал «потоп» |
| Такты кончились (K) | провал «фундамент не подвёл груз» |
| Груз дошёл до выхода | победа |
| Σ распора | = C всегда, через любые клики и волны (assert ботов) |

## Петли
- **P1 «вбить — соседи гаснут»**: каждое открытие перекраивает чужие двери; коридор
  строится за счёт закрытий, и геометрия плит решает, КОМУ платить. Решение — с какой
  стороны подвести распор (через какой сосед-тупик), а не «сколько открыть».
- **P2 «молния» (открыть–пропустить–сомкнуть)**: открытый коридор = течь; за грузом
  стыки ВЫНИМАЮТСЯ, волна уходит в боковые тупики, вода отсечена сзади. Ритм под такт
  груза: сомкнул раньше — раздавил, позже — впустил воду.
- **P3 «пробка-выстрел»**: полные 2/2 прокатывают волну дальше — распор из тупиков
  насыпается в коридор-пробку, и одно вынимание хвоста распахивает дальний стык без
  клика: дальнобойность собирается, а не покупается.
- **N1 твоя волна открывает чужие двери (№11)**: BFS летит в ближайшие неполные —
  вынимание может распахнуть фронт воды; каждая снятая пробка бьёт по твоей же схеме.
- **N2 поджатый стык под грузом (№11)**: ВБИТЬ рядом высасывает последнюю единицу
  из стыка с грузом — груз раздавлен твоим же открытием коридора.
- **N3 распор лежит на дверях воды**: стартовая раскладка держит единицы на дверях к
  воде; закрыть = перекачать в тупик, но каждое ВБИТЬ открывает новый стык — новый
  потенциальный путь воде. Двери не выключаются, они переезжают.
- **Структура против доминирующих стратегий**: «ничего не делать» — вода ползёт по
  стартовым дверям, тик-лимит K; «открыть всё сразу» — Σ не даёт, каждая дверь = путь
  воде; «спам вбить» — поджатия под грузом, паразитные открытия, пар; «спам вынуть» —
  волны распахивают поле и кормят воду, пар; «свалить весь распор в тупики» — коридора
  нет, K кончается, а вынуть обратно = волна мимо цели (снова пар).

## Цель и проигрыш
- **Цель**: довести груз до выхода сухим.
- **Звёзды**: 3 — доставлен, воды ни разу не было в сухом отсеке, клики ≤ par;
  2 — доставлен и клики ≤ par + 2; 1 — доставлен.
- **Проигрыш**: (а) стык захлопнулся с грузом внутри; (б) вода коснулась груза или
  сухого отсека; (в) K тактов кончились. Рестарт уровня (~1 мин), кнопка всегда.

## Вопрос прототипа (один)
Рождает ли закон «распор один: открытие здесь = закрытие там, снятие = волна через
пробку» настоящее планирование — с какой стороны подводить распор, когда смыкать за
грузом, куда послать волну, — или игрок тычет стыки наугад? Прототип обязан содержать:
строгую сумму с assert'ом, превью сбора/волны/поджатий, часы воды и тик-лимит, груз-
автомат и счёт кликов против par — иначе вопрос решён заранее в пользу «темы».

## Уровни (5, обучение одним намёком)
- **T1 «Первый клин»** — без воды. Груз стоит в стыке за закрытым проёмом; у соседа-
  тупика 2 единицы. Учит: ВБИТЬ = соседи поджались, проём распахнулся, груз сам пошёл.
  par 1. Провал почти невозможен.
- **T2 «Двери»** — вода за дверью: на дверных стыках лежит стартовый распор (вода
  дойдёт за 3 такта), груз ждёт короткого коридора. Учит: закрыть открытый = ВБИТЬ со
  стороны тупика (перекачать единицы из двери в сток), не открыв воду новых путей.
  par 2–3.
- **T3 «Молния»** — коридор вдоль канала воды, часть стыков открыта стартово, вода
  близко. Учит: ритм «открыть впереди — сомкнуть позади»: волна выниманий уходит в
  боковые тупики, вода отсечена сзади; сомкнул раньше — раздавил. par 3–4.
- **T4 «Пробка»** — выходной стык далеко, единиц рядом нет; тупики и запас позволяют
  насыпать коридор 2/2. Учит: пробке-выстрелу — насыпь, выни хвост, волна распахнёт
  дальний; параллельно давит вода. par 4–5.
- **T5 «Экзамен»** — двери воды, молния, пробка и второй источник воды (W = 4) в одном
  фундаменте; распор стартует на дверях второго источника. Экзамен: перекройка +
  ритм + выстрел + парковка в одном плане. par 6–7 (подтвердить перебором).

## Стартовые константы (числа для HTML, править при балансировке)
Один экран 960×640; клетка 32 px (сетка 30×20); уровень — данные (типы клеток,
стартовые единицы, источник воды, W, K, старт груза, выход, сухой отсек, тупики,
par, solution-цепочка (такт, стык) для бота). Такт 0.7 с; вода W = 3 (T5: + второй
источник W = 4); груз 1 стык/такт; кап распора 2; Σ = 8–14 на уровень; K = 40–70
тактов. par: {1, 2, 3, 4, 6} гипотеза; звёзды: 3 = доставлен + ≤ par, 2 = ≤ par + 2,
1 = доставлен. Всё — в одном объекте CONFIG; уровни — данные; превью BFS при наведении;
без аудио — всё рисуется: ширина щели = единицы, стрелки сбора с числами, красные
метки закрывающихся в 0, пунктир волны, синий фронт воды со счётчиком «до шага»,
метки тупиков, счётчик «распор C/C».

## Риски баланса
- **«Волна непрозрачна»** — главный риск: игрок не видит, куда разлетятся единицы.
  Противоядия: пунктир BFS + будущие места посадки до клика. Если теряется — НЕ текст:
  усилить ghost-подсветку и замедлить анимацию волны (0.4 с).
- **«Закрыл и раздавил нечаянно»** — красные метки на стыках, которые уйдут в 0, и
  ореол на грузе, если под ним; при провале — реплей стрелкой высосанной единицы.
- **«Перекачка в тупик доминирует»** — тупиков всегда меньше, чем нужно мест; с T3
  уровни заставляют распор жить в коридоре (молния). Если нет — резать тупики
  (уровень, не правила).
- **«Вода непонятна»** — синий фронт + счётчик тактов до шага; вода растёт комом —
  показать рост заливкой, не ручьём.
- **«Груз застрял навсегда»** — тик-лимит K и рестарт кнопкой всегда; застрявший груз
  — решение не найдено, не баг.
- **«Сумма течёт»** — если HUD «распор C/C» когда-нибудь не сходится, это баг сборки,
  не правило; assert ботов ловит до сборки.
- Все константы вверху прототипа в один объект CONFIG; уровни — данные.

## Что НЕ входит в v1 (осознанно вырезано)
- **Падающие плиты и удар «плита бьёт по пути»** отдельной механикой — опасность
  закрытия только через груз и воду; вырезано сознательно (цена сборки, не потеря
  закона).
- **Диагональная передача распора и переменная мера клика** — единицы атомарны,
  дозировок нет (№12).
- **Несколько грузов, несколько источников сверх T5, вода, поджимающая закрытые
  стыки, подвижные плиты** — v2.
- Генерация уровней, тач, сохранения, арт/аудио (плиты, щели, стрелки, волна, фронт).

## Новизна (проверка вебом 2026-11-22, 4 запроса)
Прямого аналога правила «распор один на все стыки: вбивание собирает его из соседей
(соседи захлопываются), вынимание возможно только схлопыванием с волной по графу
стыков, полные стыки прокатывают волну дальше, открытие — одновременно дверь грузу и
течь воде» не найдено. Ближайшие соседи и чем отличаемся: **«Ball under pressure»
(Dilemma Games)** — деревянная ловкость: палочки запирают шар, без правил переноса и
без консервации; **Fluid Pressure Puzzle / игры на закон Паскаля** — давление
передаётся равномерно жидкостью, дозировка и налив, нет суммы раскрытий, волн снятия
и часов; **100 doors / toggle-паззлы** — переключение дверей без инварианта: открытие
ничего не стоит соседям; **sliding-block / пятнашки (Huarong Road)** — ближайшая
семья: пустая клетка консервативна, но это ОДИН токен, двигаемый обменом, без
геометрии плит, волн, груза и воды; **Water sort / Flow Free** — сортировка и
прокладка без консервации openings. Сверка с занятыми слотами (№16): **Разгон**
(рассеяться × заинтересованность) — сумма тоже одна, но это НЕПРЕРЫВНОЕ течение к
первому яркому: аттракторы по расписанию, клик только разгоняет, игрок лепит яркость;
тут распор стоит НА МЕСТЕ, пока его не перекачаешь, движение только кликами по
геометрии плит, снятие = волна, а яркости/фаз нет — одни двери и часы. **Отдаление**
(найти × отдаление) — распорка там НАЙДЕННЫЙ ПРЕДМЕТ конечной величины: тратится
целиком вставкой, сумма не консервирована, мира не перекраивает; тут распор — масса
на графе стыков, вечная и перекачиваемая, снятие обязательно с волной. **Отведи**
(отводить × реалия) — беда = один токен с терпением и отражением по цепочке, летит по
КЛИКУ-адресации; тут распор не токен, а консервативная масса, идущая только геометрией
соседства, отражений и терпений нет. **Раздвинь** (расширять × нерешительность) —
простор и удлиняющаяся пауза, один растягиваемый проём; тут проёмов много и их сумма
жёсткая — открытие одного жмёт другие. **Ложь-замок** (соврать × закрытие) — замок из
непротиворечивой лжи; тут закрытие = отсутствие распора, а не соответствие. **Вскрыть**
(вскрыть × владетель) — вскрытие вскрывает носителя-иерарха, не переносит бюджет
проёмов. **Устой** (выбрать × устой) — выбранный устой дальше выбирает сам; тут
ничего не выбирает за игрока — только геометрия и сумма. Пара «раскрыть × клин» среди
слотов не занята. Комбинация «консервативный распор на стыках ∧ вбить = сбор с соседей
∧ вынуть = обязательная волна с прокатом через полные ∧ груз-автомат против воды по
расписанию» новизну держит.

## Критерии приёмки (боты)
Экспорт **window.UNWEDGE** (CONFIG, LEVELS, state(), sum(), click(jointId), tick(),
loadLevel(i), restart(level), log) для headless-тестов без рендера. state() →
{ t, level, joints:[{id, units, open}], cargo:{jointId, atExit}, water:{front,
nextIn}, clicks, par, won, lost, reason }. Резолв детерминированный пошаговый
(такт 0.7 с; тай-брейки фиксированы), уровни — данные; боты решают без пикселей.
Приёмка: все 5 уровней каждым ботом; в каждом прогоне на каждом тике
assert sum() === C (инвариант №9).
- **Бот «проводник»** (исполняет solution-цепочку уровня: (такт, стык); par подтвердить
  полным перебором живых состояний скелета до HTML): доводит груз на T1–T5, клики
  ≤ par, ≥ 9/10 прогонов.
- **Диагностический «стоячий»** (0 кликов): 0 побед на всех уровнях; на T2+ вода
  доходит до груза/отсека — пассив наказан расписанием (№14).
- **Диагностический «вбиватель»** (жадно ВБИВАЕТ первый по порядку закрытый стык):
  0 побед на T2+ — открывает паразитные двери воде и поджимает стыки под грузом.
- **Диагностический «волновик»** (ВЫНИМАЕТ первый по порядку открытый стык при
  возможности): 0 побед на T2+ — волны распахивают поле и кормят воду, пар мимо.
- **Случайный бот**: < 50 % побед на T2–T5 (T1 — норма иногда открыть).

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Заголовок страницы —
вопрос прототипа. HUD одной строкой: такт k/K, «распор C/C», вода через n, клики
против par. Сцена: плиты (светлые плиты со швами), стыки-щели (ширина = распор,
цифры единиц), груз-ящик, синий фронт воды со счётчиком, метки тупиков, люк-выход,
превью при наведении (стрелки сбора с числами, красные метки закрывающихся в 0,
пунктир волны с местами посадки). Управление: клик по стыку. Итог уровня одной
строкой (доставлен, клики vs par, такты, причина провала) — ответ на вопрос
прототипа и лог ботов (проводник/стоячий/вбиватель/волновик/случайный).
