# Проходной двор — спецификация v1 (после фильтра, GO* 16/16)

## Название
Проходной двор (рабочее; слот `courtyard`).

## Пара-источник
проходить_VERB × подозрение_NOUN (Этап 1: №3–8 Σ8 — потолок пары 16; №4 = 2 — мост
«мысль проходит красной нитью», №5 = 2 — подозрение живёт само и больше человека,
№8 = 2 — перенос). Законы: «проход привносит «насквозь» — пока подозрение идёт, оно
никого не обвиняет: прошедшее ни на ком не осталось» / «подозрение сохраняет
адресность — подозревать можно только кого-то: не остановившись, оно не существует».
Формула: **можно пропустить подозрение сквозь дом, но тогда оно коснётся каждого,
кого вело мимо, и остановится там, где кончился проход**.

## Правки фильтра (четыре; №14 закрывает четвёртая, №10+№11 — третья)
1. **Инвариант счётный, а не только закон глагола (№9).** В эскизе «инвариант:
   подозрение шагает само» — это закон глагола, не инвариант состояния. Правка:
   подозрение в доме РОВНО ОДНО и всегда в одной из фаз — `walk` (идёт), `pointed`
   (остановилось, указало), а покинуть дом может только двумя путями: выведено на
   улицу (дело закрыто) или арестом обвинённого (дело закрыто адресом). Игрок не
   создаёт, не гасит и не выбирает адресата — только перекрывает проходы; после
   ареста на своём караулка впускает то же подозрение у входа снова (оно не
   утолилось — его природа искать, на ком остановиться).
2. **Правило выбора пути детерминировано (достройка, читаемость + боты).** Эскизное
   «идёт по открытому маршруту» не определяет развилку. Правка — «ищет глухое»: из
   открытых выходов подозрение выбирает комнату с МЕНЬШИМ числом открытых дверей
   (его природа — искать, где остановиться); улица — самый глухой «носитель» (0
   дверей); при равенстве — сосед, ближайший по часовой от направления, которым оно
   вошло. Наведение на дверь показывает ghost-стрелку следующего поворота.
3. **Страж-арест и окно срыва (№10 + №11 одним изменением).** В эскизе стражи «идут
   тем же маршрутом» без роли и окна. Правка: стражи ходят ТОЛЬКО по открытым
   дверям — та же открытость, что маршрут подозрению: открыл дверь для подозрения —
   открыл её и для ареста; закрыл — закрыл для обоих. Указание = маячок над
   комнатой + страж в пути от поста; до его прихода указание можно СОРВАТЬ
   (открыть выход — подозрение уходит, маячок гаснет) или, наоборот, ДЕРЖАТЬ
   маршрут открытым, чтобы арест состоялся. Арест на тебе — провал немедленно;
   арест на своих — счётчик 0/2, второй — провал. Комната игрока на графе.
4. **Тень (№14).** В эскизе «замкнуть в цикле — крутится бесконечно» — вечная
   бесплатная парковка, а «не трогать двери» ничем не наказано. Правка: каждый
   проход подозрения через комнату кладёт +1 ТЕНИ её жильцу, тень не спадает;
   комната с тенью ≥ 3 ПРИТЯГИВАЕТ подозрение — оно входит и останавливается в ней
   (указание), как в тупике. Стартовые конфигурации всех уровней ведут подозрение
   дефолтным маршрутом в тупик к своему — пассив-бот наказан по построению; «закрыть
   всё подряд» — само-указание на текущего (тупик построен твоими же кликами); спам-
   кольцо — тень доезжает до порога и кольцо само останавливает подозрение.

## Правило (одно предложение)
Подозрение шагает по дому само и ищет, где остановиться, — на развилках оно сворачивает
в самую глухую сторону, пока идёт, никто не обвинён, а игрок не выбирает ни адресата,
ни точку: он только открывает и закрывает двери, и та же открытость служит стражам,
идущим арестовать того, на ком подозрение остановилось, — так что каждая дверь
одновременно маршрут, стена, ловушка и алиби.

## Глаголы игрока
- **Перекрыть/открыть** (клик по двери, тоггл): единственный глагол решения. Клик по
  двери, которой СЕЙЧАС проходит подозрение или страж, не срабатывает (дверь занята —
  полотно дрожит): свалить его посреди проёма нельзя.
- **Не-клик** — тоже решение: подозрение идёт, часы стража тикают, тень копится.
- Аватара, WASD и ходьбы нет (прецедент «Подпись»/«Предположим»); игрок — жилец,
  чья комната есть на графе дома, но тела в коридорах у него нет.

## Токены
- **Подозрение — ИНВАРИАНТ (№9)**: ровно одно на дом; фазы `walk` / `pointed`;
  уходит только наружу (дело закрыто) или арестом (дело закрыто адресом); после
  ареста на своём — ре-энтри от караулки через 3 с. Рисуется бледным сгустком с
  хвостом-следом по пройденным комнатам («прошло мимо — никого не тронуло»).
- **Комнаты-жильцы** (4–8 на уровень): `you` (твоя), `friend` (свои, 1–3), `enemy`
  (1), `none` (проходные). Арест уводит жильца.
- **Двери** (5–12): полотна между комнатами и на улицу; открыта/закрыта; занятость
  на время прохода; клик = тоггл.
- **Тень** (на жильце): +1 за каждый вход подозрения в комнату, не спадает, до
  конца уровня; порог 3 — комната притягивает остановку. Рисуется затемнением
  комнаты и мелкими зарубками.
- **Указание**: подозрение встало в комнате без открытых выходов (или в комнате с
  тенью ≥ 3) — маячок-фонарь над комнатой, страж вызван; единственный вид «существования»
  обвинения (адресность — закон существительного).
- **Страж** (0–1 на уровень): пост/караулка; на указание идёт по открытому маршруту,
  60 px/с; дошёл — арест; маршрут перекрыт — ждёт у закрытой двери 2 с и
  возвращается на пост (указание продолжает гореть, пока подозрение не ушло).
- **Улица**: выходная дверь; подозрение, выведенное наружу, — дело закрыто
  (единственная допустимая потеря).
- **Таймер** уровня: L1 60 с, L2–L4 90 с, L5 120 с; истёк без дела — поражение.

## Правила (вся матрица v1)
| Событие | Правило |
|---------|---------|
| Клик по свободной двери | тоггл открытости для ВСЕХ: подозрения, стражей |
| Развилка | из открытых выходов — комната с меньшим числом открытых дверей; равенство — по часовой от направления входа |
| Комната с тенью ≥ 3 | для подозрения считается глухой: вход = остановка (указание) |
| Остановка (тупик / тень) | указание: маячок + вызов стража |
| Приход стража к указанию | арест жильца; на тебе — провал; на своём — +1/2; на враге — дело закрыто |
| Выход открыт до прихода стража | подозрение уходит, маячок гаснет, страж возвращается — срыв |
| Маршрут стража перекрыт | ждёт 2 с, возвращается; маячок горит |
| Арест на своём | караулка впускает подозрение снова через 3 с |
| Клик по занятой двери | не срабатывает, полотно дрожит |
| Выведено на улицу | дело закрыто, победа задачи |

## Петли
- **P1 маршрут (КАКИЕ)**: тоггл двери меняет, какая сторона «глухая», — подозрение
  свернёт там, где ты закрыл/открыл; план цепочки перекрытий впереди бегущего —
  главная петля решения.
- **P2 страж-окно (КОГДА)**: указание запускает часы прибытия; успеть сорвать
  (открыть выход) или дать арест (держать стражу коридор) — таймер решения.
- **N1 открытость общая (№11)**: дверь, открытая как маршрут подозрению, — тот же
  маршрут для ареста; твоя комната в графе — открыл ок к себе: приедут к тебе.
  Твоя приманка — твоя же ловушка.
- **N2 тень (№14)**: кольцо — инструмент с бюджетом (3 прохода на комнату), не
  парковка; накрутить тень комнате врага и заставить подозрение остановиться —
  альтернативный путь подставы, но тот же приём против тебя.
- **№10 двусторонний спрос одной величиной**: движение (идёт — чисто; встал — беда,
  но встал НА ВРАГЕ — цель) и открытость (открыта — заманить/выпустить/дать стражу;
  закрыта — отрезать/спрятать/сорвать арест).
- **Структура против доминирующих стратегий**: «не трогать двери» — дефолтный
  маршрут уровней кончается тупиком своего (2 ареста = провал); «закрыть всё
  подряд» — указание на текущего твоими же кликами; «кольцо навсегда» — тень;
  «вывести любой ценой» — на уровнях L2/L3/L5 победа только арестом врага.

## Цель и проигрыш
- **Цель**: закрыть дело уровня — вывести подозрение на улицу (L1, L4) или отдать
  под арест врага (L2, L3, L5; в L3 сначала сорвать арест своего).
- **Звёзды**: 3 — кликов ≤ par и 0 арестов своих; 2 — ≤ par; 1 — победа.
- **Проигрыш**: арест на тебе; второй арест на своих (счётчик 2/2); таймер.
  Рестарт уровня (~1–2 мин). par {2, 4, 3, 3, 6} — подтвердить перебором при сборке.

## Вопрос прототипа (один)
Рождает ли «адресата выбирает глухота графа, а не рука» решения про топологию и
тайминг — перекрытия впереди бегущего, окно срыва ареста, бюджет кольца, выбор
между вывести/подставить/удержать, — или игрок мысленно «ведёт» подозрение и
двери становятся декорацией? Прототип обязан содержать: правило глухоты на
развилках, занятые двери, стража только по открытым дверям, тень с порогом 3 и
счётчик арестов своих — иначе вопрос решён заранее в пользу «темы».

## Три ситуации (№15, из эскиза — проверены на разносность)
1. **Вывести**: перекрыть глухую ветку, открыть маршрут к выходной двери — улица
   глухая (0 дверей), подозрение уйдёт само (L1, L4).
2. **Подставить**: закрыть выходные двери комнаты врага, впустить, оставить стражу
   коридор до прихода (L2; в L5 — после срыва ареста своего).
3. **Удержать**: кольцо открытых дверей без тупиков — крутится, никого не трогая,
   но тень копится; держать до смены поста, потом выпустить (L4).
   Бонус-ситуация L3: **сорвать** — указание уже на друге, страж в пути; открыть
   выход до прихода — окно решения реактивное, не плановое.

## Уровни (5, обучение одним намёком; графы — данные)
- **L1 «Прямой путь»** — прихожая → зал соседа (тупик) → кабинет с выходной дверью;
  стартовая конфигурация ведёт подозрение к соседу. Учит: тоггл + правило глухоты:
  закрой тупик, открой выход. Провал пассивом по построению. Par 2.
- **L2 «Тупик для врага»** — враг в комнате с двумя дверями, пост у караулки.
  Учит: указание + арест; маршрут стража = те же двери, держи коридор. Par 4.
- **L3 «Сорвать арест»** — старт: подозрение уже указало на друга, страж в пути
  (ETA 8 с). Учит: окно срыва (КОГДА), потом вывести наружу. Par 3.
- **L4 «Кольцо на смену»** — страж на посту у выходной двери, смена через 30 с.
  Учит: кольцо = инструмент с бюджетом тени (2 полных круга на кольце из 3 комнат),
  после смены — открыть выход. Par 3.
- **L5 «Экзамен»** — старт: указание на друге; сорвать → подставить врага арестом,
  держа коридор стражу и не подставив своих. Вся цепочка петель. Par 6.

## Стартовые константы (числа для HTML, править при балансировке)
Один экран 960×640; уровень — данные (rooms с координатами и жильцами, doors с
open/closed, guard/пост, par, timer, solution-цепочка тогглов с моментами).
Подозрение 120 px/с между центрами комнат; страж 60 px/с; ожидание у закрытой
двери 2 с; ре-энтри после ареста 3 с; тень-порог 3; бюджет арестов своих 2;
ETA стража в L3 — 8 с; смена поста в L4 — 30 с. Таймеры 60/90/90/90/120 с.
Все константы вверху прототипа в одном объекте CONFIG. Читаемость без текста:
бледный хвост пройденного, маячок-фонарь над указанием, затемнение и зарубки
тени, ghost-стрелка следующего поворота при наведении на дверь, дрожь занятого
полотна, счётчик арестов своих — две фигурки. Без аудио.

## Риски баланса
- **«Мысленное ведение» (двери-декорация)** — главный риск: если правило глухоты
  легко обходится, игрок просто «ведёт» сгусток. Противоядия структурой: развилки
  с равной глухотой, занятые двери, ghost-стрелка как единственный канал прогноза.
  Первая проверка: бот-«ведун» (кликает по комнатам, куда «хочет вести») обязан
  давать 0 эффектов — у него нет глагола.
- **«Закрыл всё и забыл»** — само-указание наказывает мгновенно, но следить, чтобы
  на уровнях не существовало конфигурации «закрыл 3 двери — дело закрыто» без
  риска для своих; бот-свалка обязан ловить арест на текущем (≥ 8/10).
- **«Кольцо-парковка»** — тень-порог 3 даёт кольцу из 3 комнат ровно 2 полных
  круга; если на L4 держать легче, чем решать, — резать порог до 2, не вводить
  кулдаун тоггла (кулдаун = «сколько можно», ломает №12).
- **«Страж-телепорт»** — страж обязан пересчитывать маршрут по текущей открытости
  каждый шаг; перекрытие пути в любой момент = ожидание 2 с и возврат (не отмена
  маячка). Проверяется инвариантом бота-честности.
- **«Ре-энтри непонятна»** — караулка подсвечивается пульсом при впуске; если
  игрок не связывает арест с новым входом — рисовать бледный след от караулки
  (читаемость, не новое правило).
- Все константы вверху файла прототипа в один объект CONFIG; уровни — данные
  (включая solution-цепочки для бота-решателя).

## Что НЕ входит в v1 (осознанно вырезано)
- **Несколько подозрений** на дом и вторая волна из караулки — v2.
- **Патрульные стражи** (v1 — один вызываемый на указание) и страж-носитель — v2.
- **Аватар/ходьба игрока** — дом рулится дверями; тело игрока — v2-кандидат.
- **Переклейка дверей, новые двери, туннели** — граф фиксирован уровнем.
- Слухи-соседи, донос, второй враг, процедурные дома, сохранения, тач, арт/аудио.

## Новизна (проверка вебом 2026-11-16, 4 запроса)
Прямого аналога формулы «автономное подозрение идёт по графу открытых дверей к
тупику и обвиняет жильца остановки; игрок рулит только открытостью» не найдено.
Ближайшие соседи и чем отличаемся: **Suspicion (Wonder Forge, 2016)** — игроки
воруют в особняке и подозрение падает на ИГРОКА (кого видели), подозрение не
существо и не маршрутизируется; **Cluedo/Clue** — комнаты и обвинение, но токены
двигают игроки и обвинение — декларация, а не остановка ходока; **стелс-системы
(suspicion meter + last known position, Entry Point: открытые двери вызывают
подозрение стражей)** — подозрение это СОСТОЯНИЕ на страже об игроке, а не
адресная сущность, идущая сама; игрок не маршрутизирует её дверями и она не
обвиняет жильцов; **Among Us / Werewolf** — обвинение социальное, тела-ходока нет.
Сверка с занятыми слотами (№16): «Занести фокус» — порыв несётся по струйке от
ТОЧКИ КЛИКА и прилипает к первому встречному (адресата назначает течение, носитель —
объект в коридоре; тут точки запуска и встречи нет: рулится только открытость
проходов, путь выбирает глухота графа, носитель — комната, обвинение = остановка,
стражи идут тем же маршрутом); «След» — беда приварена к следу игрока и копирует
его шаги непрерывно (тут аватара нет и следить не за кем); «Отрицать тропу» —
признанность земли словами, ходят сами по протоптанному (тут путь не признаётся, а
открывается полотном, и ходок один и адресен); «Слухогон» — молву несёт ГОНЕЦ в
выбранный рукой дом (тут гонца и выбора дома нет); «Объезд» — посты на дорогах,
двери = дороги под постом (там закон дороги и колеи, тут — закон прохода и
адресного обвинения); «Предположим» — вера игрока становится истиной (тут
подозрение внешнее, игрока не слушается); «Пальпация строя» — рука провоцирует
переброс раны (тут рука не провоцирует, только перекрывает); «Застать» — страж
застукивает готовый замысел патрулём (там патруль игрока ловит, тут стража
игрок кормит маршрутом). Отличающее ядром: ГЛУХОТА ГРАФА назначает адресата,
открытость двери общая подозрению и стражу, обвинение = остановка.

## Критерии приёмки (боты)
Экспорт `window.COURTYARD = { CONFIG, LEVELS, state(), toggleDoor(id),
tick(seconds), restart(level), log }` — headless-тесты без рендера. `state()` →
{ t, level, timer, suspicion:{room, phase:'walk'|'pointed'|'gone', nextRoom,
entryDir}, doors:[{id, a, b, open, busy}], rooms:[{id, occupant:'you'|'friend'|
'enemy'|'none', shadow, openDoors}], guards:[{mode:'post'|'walk'|'wait'|'return',
targetRoom, eta}], friendsArrested, clicks, par, won, lost, stars }. Резолв
детерминированный пошаговый (шаг 0.1 с, seed 7); развилки по правилу глухоты,
равенство — по часовой от entryDir; уровни — данные, боты решают без пикселей.
Приёмка: 5 уровней × 10 сидов.
- **Бот-решатель** (исполняет solution-цепочку зала: тогглы и моменты) — победа на
  всех 5 уровнях, кликов ≤ par, на L2/L5 враг арестован стражем, на L3 срыв
  состоялся до ETA; ≥ 9/10 сидированных забегов.
- **Бот-пассив** (ни одного клика) — 0 побед на всех уровнях; на L1–L3 два ареста
  своих до таймера (провал бюджетом, не таймером): проверка правки №14 по
  построению.
- **Бот-свалка** (жадно закрывает двери подряд) — ≥ 8/10 уровней с само-указанием
  (арест на текущем жильце), 0 побед: проверка «закрыть всё = обвинить текущего».
- **Бот-кольцо** (на L4 строит кольцо и держит сверх бюджета) — тень доезжает до
  порога, остановка в кольце и арест на своём ≥ 8/10: проверка правки №14
  (кольцо не парковка).
- **Бот-«ведун»** (кликает по комнатам, «куда хочет вести») — 0 эффектов и 0
  побед на всех уровнях: у него нет глагола, проверка формулы «рука не выбирает
  адресата».
- **Рандом-бот** — < 50 % побед на L2+; инварианты в каждом прогоне: подозрение
  ровно одно и всегда в фазе walk/pointed/gone; все перемещения подозрения и
  стража — только через открытые двери; указание только в комнате с жильцом;
  клик по занятой двери не меняет открытость. Экспорт итога уровня одной строкой:
  победа, кликов/par, арестов своих, время.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей, без аудио. Заголовок
страницы — вопрос прототипа. HUD одной строкой: таймер, кликов X/par, арестов
своих 0/2, фаза дела (идёт / указано / закрыто). В мире: комнаты с именами-табличками
жильцов, полотна дверей, бледный сгусток подозрения с хвостом, маячок-фонарь
указания, страж с фонарём и круг поста, затемнение тени с зарубками, ghost-стрелка
следующего поворота при наведении на дверь. Управление: только мышь (клик по двери).
Итог уровня — строка лога (см. боты). `window.COURTYARD` — экспорт для ботов,
приёмка до визуальной сборки.
