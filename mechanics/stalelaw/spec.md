## Пара-источник

которое жизнь приняла бы без руки, кого бы жизнь ни принесла» / «законодательство
сохраняет прирост: каждые N тактов следующая статья отрывается сама, и ни одна
не гаснет; жизнь ходит волнами сама и неравномерно». Конфликт: игрок подводит
жизнь под отживший закон — а закон всё равно отрывается дальше, и его требования
стоят в будущем, куда жизнь без руки не успевает.

## Правки фильтра (шесть; сырой эскиз недоговоривал арифметику отмота и давал
## вырождающуюся формовку — закрывают №9/№10/№14/№15 одной ревизией)
1. **Мороз по нетронутому ходу (№9/№10, главная правка).** X статьи = занятие её
   клетки на такте t_отрыва + s ПО НЕТРОНУТОМУ ХОДУ от старта уровня (как если бы
   руки не было ни разу): X — константа данных уровня, твойими отмотами не
   корректируется никогда. «Закон оторвался от жизни» дословно: он морозит жизнь,
   какой та была бы без вмешательства. Отсюда вся игра: клетка, отставшая на r
   отступов, доходит до Х на r битов позже — отставание есть ЗАДЕРЖКА прихода
   требования (инструмент), и одновременно цена (простой до прихода). В сыром
   чтении (X от текущей фазы) отмот до отрыва лишь вращал бы требуемый глиф —
   формовки не было бы вовсе.
2. **Арифметика отмота против волны (№9, шов эскиза).** Порядок такта: клики
   (зазор) → волна (бит: все клетки +1 по циклу) → отрыв статьи (по расписанию) →
   счёт. Клик в такт бита = нетто 0 (держание: ступил назад — волна вернула);
   клик в паузе между битами = −1 (отступ). В плотной серии битов отступ
   невозможен физически — только держание одной клетки (рука одна). Такт один —
   клик один.
3. **Счётная форма провала и счёта (№9/№14).** Простой за такт = число АКТИВНЫХ
   статей, чьи клетки не стоят в их Х (две статьи на одной клетке — до +2).
   Σ простоя > L в любой такт — немедленный провал (уровень продолжаться не
   может). Счёт = Σ доходов клеток за такты соответствия. Победа — дожить до K
   с Σ простоя ≤ L. Звёзды: 3 — счёт ≥ par (par = максимум BFS); 2 — ≥ par − 2;
   1 — победа. Клики не тарифицируются: рука одна (клик за зазор) — сама валюта.
4. **Полная видимость расписаний (детерминизм, читаемость).** Лента битов волны и
   лента будущих отрывов видны с первого такта ЦЕЛИКОМ (сырое «видно на 2 такта»
   резало бумажную решаемость и BFS par). На гряде — призраки будущих статей
   (метка отрыва на ленте); после отрыва статья показывает глиф Х и счётчик
   «приход через j» — j пересчитывается с учётом отставания клетки.
5. **Три сущности задач вместо «одиночная → две» (№15).** Эскизная первая ситуация
   — вводная, не сущность; сырая «формовка» не существовала (вырождалась).
   Заменено: (a) РОТАЦИЯ — две статьи, чьи держания сталкиваются в одной серии
   битов: руку некуда развести, простой неизбежен — вопрос КОГО отпустить и
   КОГДА вернуть; (b) ФОРМОВКА-ЗАДЕРЖКА — приход требования по нетронутому ходу
   падает в неудобную серию: заранее отстать клетку в паузе, чтобы приход уехал
   в паузу, где держание бесплатное (стоишь в Х без кликов); (c) ВЫГОДНЫЙ
   ПРОСТОЙ — статья на дешёвой клетке: отпустить сознательно и кормить руку
   дорогой, платя простоем.
6. **Обязательства данных уровней против лени (№14).** На каждом уровне: (а)
   пассив (0 кликов) проваливает на T2+ — L ниже его естественного простоя;
   (б) камп-фарм одной статьи проваливает T2+ (остальные статьи долбят L);
   (в) наив-райдер (никогда не отстаются до отрыва) проваливает T3 — формовка
   обязательна; (г) всё-держу (жадная ротация без жертв) проваливает T4–T5;
   (д) на каждом уровне ≥ 2 обязательных переключения руки; (е) вводный T1
   безопасен для план-бота, рандом < 50% побед на всех уровнях.

## Правило (одно предложение)
По гряде города катят неравномерные волны: в такт бита каждое дело шагает к
следующему занятию общего цикла, и рука не умеет вперёд — только отступать, одного
дела на один такт; статьи законодательства отрываются сами по расписанию и каждая
навсегда морозит требование «на этой клетке должно стоять занятие Х» — то, которое
жизнь приняла бы без руки (нетронутый ход), — пока клетка стоит в Х, дело даёт
доход, вне Х — каплет простой, а отставшая клетка доходит до своего Х только через
лишние биты: держать — клик в такт бита (волна вернёт), отступать — клик в паузе,
задержать приход — отступами заранее, отпустить — платить простоем, — доживи до
конца уровня, не утопив гряду в простое, набрав счёт соответствий против par.

## Глаголы игрока
- **Клик по клетке** (единственный глагол): ОТСТУП — занятие клетки на 1 шаг назад
  по общему циклу (мгновенно, в зазоре перед тактом). Один клик за зазор — рука
  одна. Вперёд рука не шагает никогда: только время. Клик по клетке без статей
  легален (иногда нужен — формовка до отрыва), цены кроме самого шага нет.
- **Такт** (пробел/кнопка или автоплей 0.8 с): клики → волна → отрыв → счёт.
  Между тактами планирование; пошаговость — для ботов и par.
- **R** — уровень заново (всё детерминировано). Наведение — превью: глиф Х статьи,
  счётчик прихода с учётом отставания, где ближайший бит — читаемость, не действие.

## Токены
- **Гряда** — 3–8 клеток-дел в ряд; у клетки: доход (монеты за такт соответствия,
  глиф-монета), текущее занятие (глиф цикла), отставание r (тонкое кольцо, +1 за
  каждый отступ от нетронутого хода).
- **Цикл** — общий на все клетки, C = 4: мельница → рынок → купальня → кузня →
  мельница. Значения по модулю C.
- **Волна/бит** — такты из расписания уровня: в бит ВСЕ клетки +1. Паузы между
  битами — когда отступать. Серии битов — когда можно только держать.
- **Статья** — свиток на клетке после отрыва: глиф требуемого занятия Х, метка
  прихода «через j» (j = биты до нетронутого прихода минус отставание), перечёркнутый
  глиф «не отзывается». До отрыва — призрак на ленте отрывов.
- **Х** — замороженное требование: занятие клетки на t_отрыва + s по нетронутому
  ходу. Константа; ассерт: клики не меняют X.
- **Простой** — счётчик провала: +1 за каждую активную статью вне Х за такт;
  Σ > L — немедленный провал.
- **Счёт** — Σ доходов клеток за такты соответствия; валюта звёзд против par.
- **Ленты** — расписание битов и будущих отрывов снизу, видны целиком с такта 0;
  ближайший бит подсвечен.

## Инварианты (№9–№12)
- (а) Состав клеток, цикл C, доходы, расписания битов и отрывов, X статей —
  константы уровня; статьи только активируются, не гаснут и не изменяются (№9).
- (б) Бит двигает все клетки ровно на +1; разности фаз клеток меняются только
  кликами; кликов ≤ 1 за зазор (№9).
- (в) X = (φ_старта + битов до t_отрыва + s) mod C — не зависит от кликов ни до,
  ни после отрыва (правка 1; ассерт).
- (г) Счёт: простой такта = Σ активных статей вне Х; счёт такта = Σ доходов
  клеток в Х; Σ > L — провал немедленно (правка 3).
- (д) **Двусторонний спрос (№10)**: до отрыва клетку хочется ЕХАТЬ (каждый отступ
  = +1 бит к ожиданию прихода), после отрыва хочется ОТСТУПАТЬ (догнать Х, держать);
  отставание — инструмент задержки (увести приход из чужой серии в паузу) и цена
  (простой до прихода); руку хочется и тратить (держание = доход), и беречь
  (пока держишь одну, вторая каплет).
- (е) **Обоюдоострость (№11)**: закон бьёт по подстроившемуся — держание занимает
  руку, сосредоточенность на одной статье топит остальные; каждое отставание
  клетки задерживает приход ЕЁ требования: твои прошлые отступы пишут твоё будущее
  простое.
- (ж) **Выбор (№12)**: которую клетку отступить, когда держать/отпустить, кого
  задержать формовкой, кем пожертвовать — «сколько» не возникает нигде.

## Петли
- **P1 отрыв → приход → держание**: статья оторвалась — глиф Х и счётчик прихода;
  клетка едет или отступает к приходу; с прихода держание = клик в каждый бит
  серии, пауза — бесплатное стояние. Решение — раскладка руки по битам.
  +/конструктивное/высокое/отложенная/средняя/серия/средняя.
- **P2 отступ против серии**: в плотной серии отступ невозможен (нетто 0) —
  отставание делается только в паузах и стоит тактов; догон отставшей — паузами.
  +/конструктивное/среднее/немедленная/узкая/пауза/короткая.
- **P3 формовка-задержка**: отступы ДО отрыва уводят приход требования в паузу —
  держание бесплатно; но клетка всё это время не в Х — если статья уже активна,
  задержка капает простоем. −+/двойственное/высокое/отложенная/узкая/уровень/долгая.
- **N1 каскад руки**: держал чужое — своё скатилось с Х; вернулся — чужое уехало;
  серии длиннее руки — простой неизбежен, вопрос кого. −/destructive/высокое/
  немедленная/средняя/серия/короткая.
- **N2 запоздавшая формовка**: отступил ради задержки, а статья уже активна —
  задержка чистым простоем; отступ от Х ради формовки после отрыва = разрушить
  готовое соответствие. −/destructive/среднее/немедленная/узкая/такт/короткая.
- **Против доминирующих стратегий (№14)**: «не трогать» — волны уводят клетки,
  активные статьи капают простоем сверх L (T2+); «камп-фарм первой статьи» —
  остальные статьи долбят L; «всё-держу» — серии длиннее руки, переходные такты
  дороже выигрыша (T4–T5); «спам-отступы» — сбивают клетки с Х, сами капают;
  «никогда не формовать» — T3 не проходит (приход в чужой серии).

## Скелет и линзы (Адамс/Дорманс)
- **Паттерн-скелет**: диспетчер одной руки против расписания — решаешь не «куда
  идти», а «какую фазу удерживать и какую отпустить» (ср. «Трон на фазе»: поза на
  одном сиденье; здесь — отступы по многим клеткам).
- **Инновация в ДИСКРЕТНОЙ части** (гл. 1): фазы mod C, биты и отрывы — целые
  такты, доходы и простой — счёт; партия решается на бумаге и BFS — то, что нужно
  ботам и par. Непрерывного нет (анимация волны — presentation).
- **7-профиль петли**: тип — диспетчирование соответствий; эффект — отложенный
  (формовка до отрыва — доход позже); вложение — клик за зазор, рука одна;
  отдача — немедленная в держании, слепая в формовке (приход уедет — увидишь);
  скорость — тактовая, под дыхание игрока; дальность — серии битов длиннее руки;
  долговечность — статьи вечны (ошибка простоя не прощается пересчётом).
- **Выигрышные действия** (гл. 12): чтение ленты против руки (кого держать в какой
  серии); формовка-задержка отступами до отрыва; сознательная жертва дешёвой
  статьи; экономия отступов (каждый = бит ожидания).

## Цель и проигрыш
- **Победа уровня**: дожить до такта K с Σ простоя ≤ L.
- **Звёзды**: 3 — победа и счёт ≥ par (par = BFS-максимум счёта, подтвердить
  перебором живых состояний скелета до HTML); 2 — ≥ par − 2; 1 — победа.
- **Проигрыш**: Σ простоя > L в любой такт. R — рестарт уровня (~1 мин).

## Вопрос прототипа (один)
Рождает ли закон «статья морозит нетронутое грядущее, волны катят всех, а рука
отступает пофазно (клик в бит = держание, в паузе = отступ)» настоящее планирование
одной руки — формовку задержкой, ротацию держаний, сознательную жертву, — или игрок
просто тычет отступы в клетку с горящим простоем? Прототип обязан содержать: приход
требования по нетронутому ходу, видимый и сдвигаемый отставанием; серии битов
длиннее руки (держать всех нельзя); уровень, не проходимый без формовки до отрыва;
статью-жертву; счёт против par — иначе вопрос решён заранее в пользу «тыканья
отступов под горящий простой».

## подтвердить BFS живых состояний скелета до HTML; двигать данными (сдвиг битов),
## не правилами)
- **T1 «Первая статья»** — гряда 3 клетки (доходы 1/1/1, старт фаз 0/0/0); биты
  {4,8,12,16,20}; K=20; статья A: клетка 0, отрыв t=2, s=2 → Х = 1 (рынок),
  приход t=4. L=15. Учит: отрыв морозит нетронутое грядущее; клик в бит = держание,
  клик в паузе = отступ; простой капает вне Х. Эталон: клики на 8/12/16/20 —
  соответствие t4–t20 = 17 тактов, par 17 (больше не бывает: до прихода t4
  соответствий нет). Пассив: простой 12 ≤ 15 — жив, счёт 5 (вводный).
- **T2 «Ротация»** — гряда 4 клетки (доходы 2/2/1/1); биты сериями {3,4,5},

  Гипотеза: L≈12 (камп-фарм умирает: брошенная статья простаивает ~1 серию на

- **T3 «Формовка»** — гряда 4 клетки (доходы 2/3/1/1); серии {3,4,5,6,7} и

- **T5 «Экзамен»** — гряда 6 клеток, 4 статьи + вторая статья на отставшей клетке

## Риски баланса
- **«Держать всегда возможно»** — с одной статьёй да (T1 вводный); противоядие —
  данные: серии битов длиннее руки и ≥ 2 статьи с T2. Если какой-то уровень
  решается вечным держанием одной статьи — сдвинуть приход второй (уровень).
- **«Формовка непонятна»** — счётчик прихода «через j» пересчитывается на глазах
  при отступе до отрыва (превью «уедет в паузу»); T3 учит одним намёком. Если
  теряется — НЕ текст: глиф-призрак будущего прихода на ленте.
- **«Отставание кажется багом»** — кольцо отставания на клетке + счётчик прихода
  статьи: цена каждого отступа видна до клика.
- **«Простой обиден»** — провал называет счёт: статьи вне Х + цифра против L.
- **«Клеркость» (посчитал ленту — жми по списку)** — давят: серии длиннее руки
  (выбор жертвы), формовка (решение до видимости требования), T5 со второй статьёй
  на отставшей. Если всё равно скучно — ужесточать серии данными, не правилами.
- Все константы вверху прототипа в один объект CONFIG; уровни — данные.

## Что НЕ входит в v1 (осознанно вырезано)
- **Шаг вперёд рукой** — против пары: вперёд живёт только волна; кандидат v2
  (отдельная механика, не здесь).
- **Отзыв статьи / второй глагол** (жалоба, перерыв закона) — против закона
  прироста; «статья не отзывается».
- **Случайные волны, скрытые расписания** — против детерминизма и BFS par.
- **Несколько рук, аватар, ходьба** — рука одна = закон пары.
- Доход как расходуемый ресурс (тратить монеты) — v2; в v1 счёт только для звёзд.
- Сохранения, тач, арт/аудио, генерация уровней.

## Новизна (проверка вебом 2026-11-23, 4 англ. запроса; три через DuckDuckGo HTML —
## WebSearch был под rate limit, четвёртый — WebSearch)
Запросы: «outdated law still enforced puzzle game mechanic freeze requirement»;
«stale statute game mechanic frozen requirement schedule puzzle rewind phase»;
«puzzle game keep entity aligned with required phase against advancing cycle one
action per turn»; «puzzle game hold position against conveyor schedule one worker
multiple machines». Прямого аналога правила «статья отрывается сама и морозит
нетронутое грядущее занятие клетки, волны катят всех, рука отступает пофазно»
не найдено. Ближайшие соседи и чем отличаемся:
- **Unenforced law / desuetude / sunset laws** ([Wikipedia](https://en.wikipedia.org/wiki/Unenforced_law),
  [Vox](https://www.vox.com/the-highlight/2019/11/18/20963411/weird-old-laws-historical-obsolete-laws),
  [HistoryCollection](https://historycollection.com/arrested-for-what-39-outrageous-american-laws-still-on-the-books-today/))
  — реальное явление «закон остался, жизнь ушла», списки курьёзных статей: не игра,
  нет поля, волн, руки и соответствия; мы делаем из бытового явления головоломку
  момента (прецедент «Отработки»: бытовое правило → механика).
- **Time-rewind жанр** (Braid, Prince of Persia; обсуждения r/gamedev о rewind) —
  отмот там = откат СОСТОЯНИЯ мира на секунды; здесь отмот = единичный шаг ОДНОЙ
  клетки назад по циклу против потока, мир не откатывается никогда, а будущее уже
  заморожено законом и от твоих отмотов не меняется.
- **Frostpunk (Book of Laws) / Reigns / 9 Kings** — законы как решения игрока с
  дельтами; здесь статьи приходят САМИ по расписанию, ничего не требуют от казны —
  требуют стояния жизни в мороженом значении, и рука не издаёт ничего.
- **Синхронизационные паззлы** (Align — словесная; Sovereign Tower — кампанийный
  откат циклов; [Conveyor Con-fusion](https://thinkycollective.itch.io/) и
  worker-placement — стройка конвейеров и расстановка рабочих, рука не ограничена
  одним отступом и ничего не морозит) — правила «держи фазу против цикла одной
  рукой с морозом грядущего» нет нигде.
Разводы по своим слотам (№16): **Трон на фазе** (восседать × фаза) — ближайший
скелет: там пин телом останавливает СВОЮ фазу, цена — пробка порядка (чужие
ВСТАЮТ), проверка — поза на знаке в такт звона, одно сиденье; здесь никто никого
не пинит — клетка катится всегда, рука ОТМАТЫВАЕТ назад (движение, не поза),
требований несколько и все живут одновременно, проверка непрерывная (соответствие
значению каждый такт, доход/простой), и требование морозит БУДУЩЕЕ нетронутого
хода (у «Трона» знак стоит на знамени). **Отработка** (покинуть × тариф): там
заморозка = ЦЕНА ухода (хвост ставки за ушедшим до границы, платится деньгами);
здесь заморозка = сам источник требований, платится соответствием фазы; там хвост
следует за телом, здесь требование приколото к клетке. **Судный день** (карать ×
день): там день приговаривается РУКОЙ навсегда и отбыт прожитием с потерей тепла;
здесь статьи отрываются САМИ, а «отбытие» = стоять в значении — соответствие
ПРИНОСИТ доход. **Долгий ящик** (класть × история): там кладка морозит СРОК
истории, и рост продолжается в замороженном (страницы густеют скрыто) — ящик есть
убежище и выгода; здесь морозит ТРЕБОВАНИЕ, время не останавливается никогда,
отступ гонит клетку НАЗАД по циклу, и оторвавшаяся статья — давление, а не спасение;
там знание рождается выниманием, здесь приход виден заранее и сдвигается только
отставанием. **Пережим** (сужаться × деньги): там сечения сдерживают идущую среду,
скоп с берегом сносит ниже; здесь среду сдержать нельзя вовсе — только пофазно
отступать; ни скопов, ни берегов, ни сноса. **Летопись** (записывать × деспот):
там рука записью узаконяет каприз навсегда (триаж потока, дельты казне); здесь рука
не пишет ничего — статьи отрываются сами, рука только удерживает и задерживает
жизнь под чужой волей. **Воцарение** (царить × наказ): там наказ — растущее поле,
исполняют все в зоне; здесь поля нет — точечные требования (клетка × значение),
отрыв = заморозка, а не рост. **Приписной** (прописывать × богатырь): там адрес
пишет рука; здесь рука адрес не пишет — статья сама морозит нетронутое грядущее.
**Самотёк** (отпускать × отросток): там отпускание выпускает ползти по тяге;
здесь отпущенная клетка катится по волне цикла, и возврат — отступами по одному.
**Контактка** (сыграть × троллейбус): там расписание пауз веры пассажира-роли;
здесь расписание волн и мороженых требований — веры и ролей нет. **Постой**
(впустить × война): там постой утяжеляет каждого следующего (накопление цены);
здесь отступ ничего не копит — цена только простое покинутого. **Покров**
(покрыть × партия): там полотно-зона над самодвижным; здесь ни зон, ни полотна —
фазовые соответствия. **Щепка / Обстановка / Жалованная грамота**: там рука
предписывает/обставляет/жалует носитель; здесь носитель отрывается сам, рука —
жизнь. Пара «оторвать × законодательство» и слот stalelaw среди занятых нет
(rg); носитель «законодательство» также числится в драфте «Подзаконный» (утонуть ×
законодательство, волна 60, спеки нет) — пары разные, механики разведены: там акты
поднимают уровень и под водой бесплатно/невидимо, здесь статьи морозят грядущее
значение на клетке. Комбинация «отрыв по расписанию ∧ мороз нетронутого грядущего ∧
волны катят всех ∧ клик в бит = держание, в паузе = отступ ∧ приход сдвигается
только отставанием ∧ простой/доход по соответствию ∧ одна рука» новизну держит.

## Критерии приёмки (боты)
Экспорт **window.STALELAW** = `{ CONFIG, LEVELS, loadLevel(i), state(), click(cellId),
tick(), articles(), score() }` для headless-тестов; `click` → `{ok, reason}`
(reason: `'locked'` — партия кончена); один клик за зазор; `tick()` — синхронный
шаг (клики → волна → отрыв → счёт). `state()` — сериализуемое `{ level, tick, K,
phases:[…], lag:[…], articles:[{id, cell, X, active, since}], idle, L, score, par,
won, lost }`. Ассерты в каждом такте каждого бота: X статей не меняется ни при
каких кликах (пересчёт по нетронутому ходу обязан совпадать); бит двигает все
клетки ровно +1; разности фаз меняются только кликами; кликов ≤ 1 за зазор;
простой такта = Σ активных статей вне Х; RNG нет.
- **План-бот** (BFS по живым состояниям; par и L подтвердить перебором ДО HTML):
  5/5 побед на T1–T5, счёт ≥ par.
- **Диагностический «пассив»** (0 кликов): T1 — жив (вводный), T2+ — провал по L.
- **Диагностический «камп-фарм»** (держит только первую активную статью): T2+ —
  провал по L (остальные статьи долбят).
- **Диагностический «наив-райдер»** (держит и ротирует, но никогда не отстаются
  до отрыва): T3 — провал (формовка обязательна), T4–T5 — провал.
- **Диагностический «всё-держу»** (жадная ротация без жертв): T4–T5 — провал.
- **Диагностический «спам-отступ»** (клик по случайной клетке каждый зазор):
  провал на T2+ (сбивает клетки с Х).
- **Случайный бот**: < 50% побед на каждом уровне (T1 допускает чаще — вводный).
Любая правка констант/раскладов — перепрогон всех ботов и BFS заново.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Заголовок страницы —
вопрос прототипа. HUD одной строкой: такт k/K, простой Σ/L, счёт vs par, статьи.
Сцена: гряда клеток (глиф занятия, монета дохода, кольцо отставания, свиток статьи
