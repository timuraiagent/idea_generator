# «Смехощит» — спецификация v1 (после фильтра, GO* 15/16)

## Название
Смехощит (рабочее; слот comedy).

## Пара-источник
защищать_VERB × комедия_NOUN (этап 1 Σ7). Формула пары:
**можно защитить комедию, но тогда охраняемый смех перестаёт смешить**.

## Правка фильтра (одна, закрывает №14)
Эскиз проваливал №14: иммунитет строго per-enemy делает гибрид вечным оружием против
всех, кто его ещё не слышал, — «один гибрид на весь зал» не наказан (правило «босс иммунен
к трём последним применённым» покрывало только босса). Правка одна — **зал-память +
предслышанные теги**: правило босса обобщено на всех (каждый враг иммунен к последним 2
шуткам, прозвучавшим в зале, пока их не вытеснили новые; у босса порог 3), и каждый враг
приходит с 1–2 ПРЕДСЛЫШАННЫМИ приёмами (иконки над головой) — «одна и та же пара на всех»
и «один гибрид по очереди» больше не проходят. Формула не тронута.

## Правило (одно предложение)
Хулители маршируют на сцену, и оружие на них не действует: обезоружить врага можно только
смехом — выбранной шуткой (клик по врагу), причём услышанная шутка не смешит ЭТОГО врага
уже никогда, а зал помнит последние две прозвучавшие шутки, — так что живой арсенал конечен,
шутки комбинируются в гибриды (две шутки, услышанные одним врагом подряд, дают новый тип
смеха, к которому иммунитет к компонентам не наследуется), и каждую шутку хочется и потратить,
и сберечь одновременно.

## Глаголы игрока
- **Шутить** (клик по врагу = применить ВЫБРАННЫЙ приём; выбор приёма — панель снизу или
  клавиши 1–8). Если враг слышал приём или приём в зале-памяти — клик заранее подсвечен
  красным и ничего не делает (всё детерминировано, попыток вслепую нет).
- **Связать** (клик по иконке-верёвке над СМЕЮЩИМСЯ врагом) — враг выведен навсегда.
- **Толкнуть** (клик по иконке-руке над смеющимся врагом) — отбросить на 120 px от рампы.
Один глагол — КЛИК. Дозировки нет: «сколько держать» не выбирается — выбираются КОМУ
(матрица враг×приём по тегам), ЧТО (какую пару сжечь в гибрид) и КОГДА (окно смеха 8–12 с,
зал-память, очередь перед боссом).

## Токены
- **Приёмы** (8 базовых, иконки): Карач, Укол, Гипербола, Каламбур, Гротеск, Пародия,
  Абсурд, Нелепость. Библиотека на уровень конечна.
- **Теги услышанного** — иконки над врагом: предслышанные при спавне (1–2) + всё, что ты
  ему рассказал. Набор только растёт.
- **Зал-память** — лента последних ТРЁХ шуток, прозвучавших в зале (HUD, 3 слота):
  обычный враг иммунен к двум последним, босс — ко всем трём; вытесняются новыми.
- **Гибрид** — после двух успешных шуток подряд по одному врагу в библиотеке навсегда
  появляется пара (Карач+Укол = «Карач-укол»): новый тип смеха. Враг, слышавший оба
  компонента, свеж для гибрида. На одном враге крафтится максимум один гибрид (после двух
  шуток его свежесть кончилась для обеих компонент).
- **Смех-окно** — дуга-таймер над головой: смеющийся враг стоит и обезоружен; обычный 8 с,
  толстяк 12 с, босс 10 с. Окно кончилось — враг снова идёт.
- **Рампа** — линия сцены слева; враг на рампе срывает номер. Двое на рампе — провал.
- **Связка** — единственное удаление врага; толчок только отодвигает.

## Ход времени (вся матрица v1)
1. Враги идут вправо→налево со спавна (обычный 24 px/с, толстяк 14, босс 18) без пауз.
2. Успешная шутка: враг останавливается на окно смеха; приём навсегда в его тегах; приём
   становится зал-памятью (вытесняет старейший из трёх слотов).
3. В окно смеха: связать (выведен) или толкнуть (−120 px, анимация 300 мс).
4. Неудачный клик (иммунен/зал-память) — ничего не происходит, приём не тратится.
5. Двое на рампе → проигрыш; все связаны → победа. Часов на уровень нет — только рампа.

## Петли
- **P1 арсенал-самоед**: каждая шутка мертвит себя навсегда (личный тег) и закрывает все
  пары с собой на этом враге; лучший инструмент съедается применением — «защитил» = «часть
  щита сгорела».
- **P2 зал-память**: шутка звучит для всего зала — после неё двое следующих врагов к ней
  иммунны. Порядок шуток важнее их выбора: перед боссом (порог 3) последние три звука
  зала обязаны не включать его убойную.
- **P3 крафт-экономика**: гибрид стоит две шутки на расходном враге (которые могли быть
  двумя связками) — окупается только против врага, слышавшего компоненты; на одном враге
  крафтится не больше одного гибрида.
- **N1 против доминирующих стратегий**: «один гибрид на всех» — зал-память (после гибрида
  двое к нему иммунны); «одна пара на всех» — предслышанные теги разные; «никогда не
  шутить» — связать не-смеющегося нельзя; «толкать всех вечно» — толчок не выводит, победа
  требует связок, пар давит на минимум шуток.

## Цель и проигрыш
- **Цель**: связать всех врагов зала. Партия = 5 уровней по 2–3 минуты.
- **Победа со звёздами**: 3 — шуток ≤ par; 2 — ≤ par+1; 1 — победа. Толчки и связки
  бесплатны — экономятся только ПРИЁМЫ.
- **Проигрыш**: двое на рампе → рестарт уровня. Таймера нет — только марши врагов.

## Вопрос прототипа (один)
Рождает ли вечный иммунитет к услышанному настоящую матрицу враг×шутка с экономикой
гибридов — чтение тегов, порядок перед боссом, осознанное сжигание пары на крафт, — или
игрок бьёт одной шуткой по очереди (зал-память его не держит?) или толкает всех без шуток?
Прототип обязан содержать зал-память, предслышанные теги и пар по приёмам — иначе вопрос
решён заранее в пользу спама.

## Уровни-залы (5, обучение одним намёком)
- **L1 «Первый смех»** — 3 обычных врага без тегов, библиотека 3 приёма. Учит: шутка →
  окно 8 с → связать; повтор шутки тому же врагу — красный (услышанное не смешит). Пар 3.
- **L2 «Бородатые»** — 4 врага, у каждого 1 предслышанный (иконки), библиотека 4. Учит:
  читай теги, бери свежий; первый толчок — сбереги приём, отодвинь у рампы. Пар 4.
- **L3 «Дуэт»** — толстяк (12-с окно) слышал ВСЕ 4 приёма библиотеки + 2 свежих расходных врага.
  Учит: крафт — две шутки на свежего → гибрид; гибрид бьёт толстяка (иммунитет к
  компонентам не наследуется). Пар 5.
- **L4 «Зал помнит»** — 5 врагов с тегами по 1–2, библиотека 6. Учит: зал-память (лента
  в HUD) — чередуй и планируй порядок, а не только выбор. Пар 6.
- **L5 «Экзамен»** — босс (порог зал-памяти 3, 4 предслышанных) + 4 свиты, все 8 приёмов.
  Экзамен: порядок шуток перед боссом, 1–2 крафта, толчки у рампы в окнах между крафтами.
  Пар 9.

## Стартовые константы (числа для HTML, править при балансировке)
Один экран 960×640: рампа на x=120, спавн x=940, враги 64 px. Скорости: обычный 24 px/с,
толстяк 14, босс 18. Окна смеха: 8/12/10 с. Толчок −120 px (300 мс). Зал-память 3 слота
(обычные враги проверяют 2 последние, босс — все 3). Библиотека: L1=3, L2–L3=4, L4=6,
L5=8 приёмов; теги при спавне: L1=0, L2=1, L3: толстяк 4 (все базовые), L4=1–2,
L5: босс 4, свита 1–2. Врагов: 3/4/3/5/5. Пар: 3/4/5/6/9. Провал: 2 на рампе.
Звёзды: 3 = шуток ≤ par, 2 = ≤ par+1, 1 = победа. Смертелей нет; уровни — данные
(enemies/library/tags/par) в объекте CONFIG.

## Риски баланса
- **«Один гибрид по очереди»** (главный): зал-память (2 для обычных) держит, только если игрок не может
  вставить две нейтральные шутки между гибридами — у него может хватать свежих базовых.
  Первая проверка прототипа: проходится ли L4 чередованием «гибрид–база–гибрид–база» без
  чтения тегов? Если да — предслышанных тегов больше на L4–L5, не трогая зал-память.
- **«Толкай всех вечно»**: толчок не выводит врага, победа = все связаны, шутки считаются
  паром — застой не побеждает. Проверить, что толчком нельзя удерживать рампу бесконечно
  при 8 врагах (24 px/с против −120 px за клик — можно; это осознанная отсрочка, звёзды
  её не поощряют).
- **«Клерковость»**: матрица обязана читаться мгновенно — теги на врагах, красная подсветка
  мёртвых приёмов на панели, лента зал-памяти. Если выбор тривиален — добавлять врагу тег,
  а не рандом.
- **«Крафт не нужен»**: если базовых хватает на все теги, гибриды мертвы. Противоядие: на
  L3+ сумма тегов сильного врага = библиотеке — свежей базовой для него не остаётся.
- **Читаемость смеха**: дуга-таймер над головой и остановка врага должны говорить «окно
  открыто» без текста; зал-память — лентой слотов с иконками.

## Что НЕ входит в v1 (осознанно вырезано)
- Ответный смех врага над игроком (закон, действующий на игрока буквально) — кандидат v2.
- Враги с оружием/ударами, бой — угроза только маршем к рампе.
- Тройные гибриды (крафт из гибрида + приёма), индивидуальные пороги зал-памяти у свиты,
  несколько залов, мета-прогресс, сохранения, мобильное управление, арт/аудио.

## Новизна (проверка вебом 2026-11-15, 4 англ. запроса)
Прямого аналога правила «услышанная шутка иммунизирует врага навсегда, зал помнит последние
шутки, компоненты комбинируются в новые шутки без наследования иммунитета» не найдено.
Запросы: «joke immunity combat game mechanic enemy becomes immune to repeated taunt»,
«laughter shield mechanic video game comedy disarms enemies», «"South Park" "Stick of
Truth" taunt ability combat spam or laughter attack limitation», «game design comedy as
weapon diminishing returns repeated joke stops being funny». Ближайшие соседи и отличия:
ESO Over-Taunt/Taunt Immunity — иммунитет к провокации после 3 таунтов за 12 с, НО
временный анти-спам одного агро-глагола, без перманентности, идентичности шуток и
комбинаторики; South Park: The Stick of Truth — смех/провокация как урон/агро, лимит
только PP-ресурсом, повторы свободны (вопрос спец-чека: «иммунитет к услышанному навсегда»
+ гибриды — отличие подтверждено); Kingdom of Loathing chortle — монстры смеются
случайным процом до потери головы, не игрокова шутка и не память врага; Divinity OS2
Chicken — трансформ-статус без идентичности приёма; обзор «Mechanical Comedy in Games»
(Polaris, 2025) и Extra Credits — фреймворки механической комедии, «diminishing returns на
повтор шутки» как принцип не назван. Слот comedy свободен (44 слота библиотеки проверены;
grep смех/joke/laugh/taunt — только новизноведческие упоминания в чужих спеках).

## Бот-приёмка (window.COMEDY)
- `window.COMEDY.CONFIG` — все константы; `loadLevel(n)` — загрузить зал.
- `state()` → {level, library:[ids], hybrids:[ids], selected, jokesUsed, par,
  hall:[последние ≤3 шутки зала], enemies:[{id,x,y,strength,speed,heard:[ids],laughLeft,
  bound,atLine}], phase:'play'|'win'|'lose', stars}.
- `select(id)`; `joke(enemyId)` → true/false (false, если id в heard врага или в его окне
  зал-памяти — последние 2 для обычных, все 3 для босса; при false ничего не меняется);
  `bind(enemyId)` / `push(enemyId)` → true только при laughLeft>0;
  `tick(seconds)` — синхронный шаг мира для бота.
- Сценарий: (1) joke(T,E) успех → T навсегда в E.heard; при любых действиях |E.heard| не
  убывает (монотонность, инвариант №9); (2) повтор joke(T,E) → false; (3) T в последних 2
  hall → joke(T, обычному) → false; T где-то в hall (3 слота) → joke(T, боссу) → false;
  hall — ровно последние 3 шутки зала; (4) успех A
  затем B на одном свежем враге → hybrids содержит A+B; joke(A+B, враг с {A,B} в heard) →
  true (иммунитет к компонентам не наследуется); после A и B этот враг не крафтит второй
  гибрид; (5) bind не-смеющегося → false; после истечения laughLeft враг снова идёт (tick);
  (6) push смеющегося → x −= 120; не-смеющегося → false; (7) толчок не выводит: bound
  ставится только bind; все bound → 'win'; двое atLine → 'lose'; (8) звёзды: шуток ≤ par →
  3, ≤ par+1 → 2, иначе 1; (9) L3: у толстяка все базовые мертвы — победа уровня без
  гибрида невозможна (крафт обязателен).

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. HUD: панель приёмов (иконки,
клавиши 1–8, красная подсветка мёртвых), лента зал-памяти на 3 слота, счёт «шуток X / par»,
теги услышанного над врагами, дуга смеха с таймером. Управление: мышь (клик по врагу =
шутка выбранным, клик по иконке-верёвке/руке = связать/толкнуть). Марш врагов —
реального времени; окно смеха и теги должны читаться без текста.
