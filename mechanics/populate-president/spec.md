# Заселить президента — спецификация v1 (после фильтра, GO* 16/16)

## Название
Заселить президента (рабочее; слот `populate-president`).

## Пара-источник
заселять_VERB × президент_NOUN (этап 1 — Σ8, потолок пары 16: №1 = 2, №4 = 2 — мост
«в голове поселилась мысль», №5 = 2 — подсел в руке игрока, институт больше человека
и живёт сам, №8 = 2 — перенос состава в речь). Формула пары: **можно заселять президента,
но тогда говорит он одним голосом — и не обязательно голосом того, кого подселили последним**.

## Правки фильтра (№9–16; три, закрывают №10/№14 и материализуют №11)
1. **Двусторонний спрос — арифметикой, не декларацией (№10).** В эскизе §10 повторял §11
   («управляешь составом, звучит должность»), а спрос «больше/меньше» не был показан.
   Спека: комнат 3, доминанта = 2 жильца одного нрава — ДВЕ разные доминанты одновременно
   невозможны структурно (2+2 > 3), значит каждое доминантное окно либо удовлетворено,
   либо оплачивается перестановкой: веса нужного нрава хочется БОЛЬШЕ (подселяй), чужой
   нрав занимает комнату и разжижает голос — его хочется УБРАТЬ (выдавляй). Разнообразие
   против чистоты — основная ось спроса.
2. **Анти-лень: уволенный недоступен + очередь конечна (№14).** «Никогда не подселять»
   падает на стартах от противного (ни один стартовый состав не закрывает все окна
   уровня); «один состав навсегда» падает на доминантных окнах разных тонов; «спам
   подселениями» жжёт очередь (кандидаты не возвращаются) и ломает свои же окна —
   выдавленный уходит в уволенные до конца уровня.
3. **Обоюдоострость мгновенная и видимая (№11).** Окно проверяется КАЖДЫЙ ТИК, пока
   открыто: собственный подсел внутри чужого окна рвёт тон и роняет пипс немедленно
   (ловушка L4/L5), а длинное окно-«речь» делает носителя тона неприкосновенным до
   закрытия. Читаемость без текста: голос = цвет-бленд и доли-полоски; ползунков весов
   нет — СОСТАВ и ЕСТЬ голос (№12: выбор кого/кого/когда, не «сколько держать»).

## Правило (одно предложение)
Президент — институт, у которого наружу звучит ровно один голос: три комнаты дворца
заселены жильцами четырёх нравов, клик по кандидату и клик по комнате вселяет нового
и выдавливает прежнего в уволенные — вернуть нельзя, — голос звучит как весовой микс
всех жильцов (тон нрава громкостью по числу его жильцов; два жильца одного нрава —
доминанта в два голоса), и каждое окно дипломатии требует, чтобы нужный тон держался
каждую секунду окна: состав и есть речь — ты не выбираешь реплику.

## Глаголы игрока (единственный ввод — клик; аватара и ходьбы нет)
- **Подселить** (клик по кандидату в очереди — он «берёт чемодан», комнаты подсвечены;
  клик по комнате — въезд): прежний жилец комнаты уходит в уволенные (серая полоса,
  до конца уровня недоступен), голос пересчитывается мгновенно, moves +1. Клик мимо
  комнат отменяет выбор. Выдавить без подселения нельзя — инвариант перестановки.
- Ждать — легальное действие: тон держится сам, пока состав не тронут.

## Токены
- **Комнаты** (3, одинаковые): конечное число — в v1 всегда ровно 3 занятых комнаты.
- **Жильцы** (4 нрава): воин (алый, меч), торгаш (золотой, монета), мудрец (синий,
  свиток), поэт (лиловый, лира). Нрав = тон голоса.
- **Очередь кандидатов**: полная и видна с начала уровня (честный перебор); конечна.
- **Уволенные**: серая полоса с иконкой «потерян»; недоступны до конца уровня.
- **Голос**: речевой пузырь президента — цвет-бленд по долям нравов + полоски долей;
  доминанта (2 из 3) рисуется двойной толщиной. Никаких ползунков.
- **Окна дипломатии**: иконка нрава + число точек = порог (1 или 2), отрезок на ленте
  времени; статус виден цветом (открыто/закрыто штампом/сорвано серым).
- **Пипсы двора** (3): доверие; срыв окна −1; 0 → рестарт уровня.

## Правила резолва
1. **Подселение**: мгновенно в тик клика; жилац выдавленной комнаты → уволенные
   (помечается моментом потери), очереди опустошаются навсегда.
2. **Голос**: voice(X) = число жильцов нрава X (0..3); окно с порогом p живо, пока
   voice(его нрава) ≥ p.
3. **Окно**: pending до a; с a — открыто, проверка каждый тик 0.5 с: первое нарушение
   порога → failed немедленно (−1 пипс, иконка серым); держало порог до b → done
   (штамп в момент закрытия). Проваленное не спасти.
4. **Уровень** завершается сразу после резолва последнего окна (таймер стоп).
5. **Полная информация**: лента окон и вся очередь видны с 0-й секунды.

## Петли (7-профиль)
- **P1 состав → голос → окна перечитаны**: + конструктивная / выбор подселения /
  мгновенная / короткая (до конца окна) / весь дворец / до следующего подселения.
- **P2 доминанта против доминанты** (№9 — перестановка): 3 комнаты не дают двух
  доминант сразу — между окнами состав качается: какой нрав доминирует в каждом окне
  и где платить сменой: + конструктивная / планирование фазы / отложенная / уровень.
- **P3 жертва**: каждое подселение — выбор, ЧЬЯ комната; уволенный недоступен, а
  очередь читается вперёд (нужно два воина — береги тора): + напряжённая / среднее /
  уровень.
- **N1 срыв посреди окна**: собственный подсел рвёт собственное открытое окно
  (воина трогать нельзя, пока идёт «речь»): − destructive / низкое / мгновенно.
- **N2 сгоревшая очередь**: спам жжёт кандидатов и пипсы: − destructive / среднее /
  уровень.
- **Против доминаторов (№14)**: «не подселять» — старты от противного (первое же
  окно с недостающим тоном/порогом срывается); «один состав навсегда» — доминантные
  окна разных тонов при 3 комнатах несовместимы; «спам» — очередь конечна, уволенные
  недоступны; «подсел в последнюю секунду» — легален в зазорах между окнами (это
  чтение ленты), но окна со стыком внутри (L5 @50 внутри C) наказывают поздний старт.

## Цель и проигрыш
- **Цель уровня (60 с)**: закрыть все окна дипломатии.
- **Звёзды**: 3★ = все окна ∧ пипсы 3 ∧ подселений ≤ par; 2★ = все окна ∧ пипсы ≥ 2;
  1★ = все окна. Par посчитан план-линиями, подтвердить перебором: L1=1, L2=2, L3=3,
  L4=2, L5=4.
- **Проигрыш**: пипсы 0 → рестарт уровня. Партия 5 уровней ≈ 5–6 мин.

## Вопрос прототипа (один)
Рождает ли правило «состав = речь» настоящий план перестановок — кого выдавить, чтобы
не оборвать чужое окно, когда жечь очередь, где держать тон сквозь собственный подсел, —
или игрок ставит один удобный состав / подселяет подряд первого кандидата / ждёт у
окна? Прототип обязан содержать: доминантные окна разных тонов (иначе один состав
навсегда), уволенных-недоступных и конечную очередь (иначе спам бесплатен), проверку
тона каждый тик внутри окна (иначе окна закрываются «задним числом») и полную ленту
с очередью (иначе планирование нечестно).

## Уровни (5, обучение одним намёком; все план-линии считаны на бумаге)
Обозначения: комнаты r1–r3, состав в порядке комнат; «X → rY» = кандидат X выдавливает
жильца rY. Все окна от противного: стартовый состав и спам-ритм не закрывают уровень.

- **L1 «Первый голос»** — старт [тор, муд, поэ], очередь [воин, тор2]. Окно: воин ≥ 1
  [25,55]. Par 1. План: @0 воин → r2 (выдавить мудреца) — [тор, воин, поэ], окно ✓.
  Учит: клик-кандидат → клик-комната; голос перекрасился; выдавленный ушёл навсегда.
  Пипсы двора не убивают (обучение), провал партии невозможен.
- **L2 «Две доминанты»** — старт [воин, тор, поэ], очередь [воин2, тор2]. Окна: воин ≥ 2
  [18,32]; тор ≥ 2 [40,54]. Par 2. План: @0 воин2 → r3 (выдавить поэта) — [воин, тор,
  воин2], A ✓; @33 тор2 → r1 (выдавить воина1) — [тор2, тор, воин2], B ✓. Учит: качание
  доминант и КОГО выдавить. Ловушка: @0 воин2 → r2 — тор1 уволен, тор2 один → B срыв
  @40, пипс: жертва выбирается под будущие окна.
- **L3 «Кто лишний»** — старт [муд, тор, поэ], очередь [поэ2, воин2, воин3]. Окна:
  поэ ≥ 2 [14,26]; воин ≥ 2 [34,46]; тор ≥ 1 [48,60]. Par 3. План: @0 поэ2 → r1
  (выдавить мудреца) — A ✓; @28 воин2 → r3 (выдавить поэ1); @32 воин3 → r1 (выдавить
  поэ2) — [воин3, тор, воин2], B ✓; C ✓ (тора не трогали). Учит: очередь читается
  вперёд — воин нужен ДВАЖДЫ, планируй; ловушка: выдавил тора — C мертво.
- **L4 «Долгая речь»** — старт [воин, тор, муд], очередь [муд2, поэ, воин2]. Окна:
  воин ≥ 1 [10,50]; муд ≥ 2 [30,44]; поэ ≥ 1 [48,60]. Par 2. План: @30 муд2 → r2
  (выдавить тора) — [воин, муд, муд2]: A ✓ (воина не тронули), B ✓; @46 поэ → r2
  (выдавить муд1) — [воин, муд2, поэ]: C ✓. Учит: длинное окно = носитель тона
  неприкосновенен; пересечение окон A×B. Ловушка: @30 муд2 → r1 (выдавить воина) —
  A рвётся мгновенно на 30-й, пипс: обоюдоострость стала материальной.
- **L5 «Посольство»** (экзамен) — старт [муд, тор, поэ], очередь [воин, поэ2, тор2,
  муд2]. Окна: воин ≥ 1 [8,20]; поэ ≥ 2 [26,38]; тор ≥ 2 [44,56]; муд ≥ 1 [52,60].
  Par 4. План: @0 воин → r1 (выдавить муд1 — единственная жертва: тор и поэт нужны
  ниже) — A ✓; @21 поэ2 → r1 (выдавить воина, A уже закрыто) — B ✓; @40 тор2 → r3
  (выдавить поэ1, B уже закрыто) — [поэ2, тор, тор2]: C ✓; @50 муд2 → r1 (выдавить
  поэ2, торов не трогаем — подселение ВНУТРИ окна C) — [муд2, тор, тор2]: C ✓ до 56,
  D ✓. Учит: тон держится сквозь собственный подсел; жертва = «кого дальше не надо»;
  окно со стыком внутри наказывает поздний старт. Ловушка: @0 выдавить тора —
  C недостижимо (тор2 один).

## Стартовые константы (числа для HTML, править при балансировке)
Один экран 960×640: слева-центр дворец в разрезе — президент (силуэт, речевой пузырь
≥ 140 px: цвет-бленд + полоски долей) и 3 комнаты ≥ 180×140; справа колонка очереди
(карточки ≥ 96 px) и серые уволенные; лента времени 940×36 внизу с окнами (иконка
нрава + точки порога). Тик игры 0.5 с (дискрет для ботов), рендер 60 fps. Уровень 60 с.
Подселение мгновенно, анимация въезда 0.3 с; выдавленный уезжает в уволенные за 0.5 с.
Пипсы 3 (L1 — не убивают); срыв окна −1; 0 → рестарт уровня. Порог окон: 1 или 2.
Всё в CONFIG; уровни — данные (start, queue, tasks, par).

## Риски баланса
- **«Один удобный состав навсегда»** — главный риск вырождения в тему. Противоядие:
  доминантные окна разных тонов (2+2 > 3). Первая проверка прототипа: закрывает ли
  стартовый состав все окна? На всех пяти — нет (пороги/тона от противного).
- **«Спам подселениями»** — очередь конечна и уволенный недоступен; проверка спам-ботом.
  Если спам-3★ где-то случится — двигать окна от противного ритма, не вводить случайность.
- **«Подсел в последнюю секунду»** — легальный навык чтения ленты; стыки окон внутри
  (L4 @30, L5 @50) делают поздний старт дороже. Если станет доминантой — уплотнять стыки,
  не наказывать таймером.
- **«Ловушка выдавливания бьёт незаслуженно»** — потери видны сразу (уволенные с
  иконкой «потерян»), лента и очередь полны с нулевой секунды: потеря планируема,
  не случайна.
- **«Микс не читается»** — пузырь: цвет-бленд + доли + двойная толщина доминанты;
  если игрок путается — укрупнить пузырь и дублировать иконки нравов над комнатами
  (текста не добавлять).
- Все константы вверху прототипа в один объект CONFIG; уровни — данные. Любая правка
  окон — пересчёт пар и ботов заново (планы на бумаге, считаются мгновенно).

## Что НЕ входит в v1 (осознанно вырезано)
- **Комнаты с индивидуальными свойствами** (трибунная, архивная) — в v1 комнаты
  одинаковы: выбор только «кого выдавить», не «куда»; кандидат v2.
- **Возврат уволенных за плату, выбор реплики и ползунки весов** — противоречат
  правилу и №12: состав и есть речь.
- **Случайные кандидаты и приходы по расписанию** — очередь полная и видна (честный
  перебор), «когда» решает игрок.
- **Двери-локации и аватар** из эскиза — заменены окнами на ленте (урок «Подписи»:
  один глагол); кандидат v2.
- **Переизбрание, сроки, несколько президентов, экономика** — v2 и дальше.
- Сохранения, мобильное управление, арт/аудио.

## Новизна (проверка вебом 2026-11-15, 4 запроса + слоты репо №16)
Прямого аналога «институт с одним наружным голосом = весовой микс заселённых жильцов,
вытеснение только новым подселением, окна под тон с проверкой каждый тик» не найдено.
Ближайшие соседи и чем отличаемся:
- **The King is Watching** — конечные слоты советников (6 из 36), каждый даёт свою
  утилиту; голоса наружу, микса и вытеснения-только-подселением нет: советники
  назначаются и снимаются свободно, эффект аддитивный, не «речь».
- **Shadow Empire** (и кластер advisor-slots) — слоты советников растут с территорией,
  утилиты; тот же класс «назначил — получил бафф», без единого голоса.
- **Disco Elysium / Slay the Princess / Inside Out** — внутренние голоса и личности:
  нарратив и диалоги, игрок не собирает состав ради одного наружного тона и не
  управляет перестановкой комнат.
- **The Tenants** (лендлорд-сим) — заселение комнат есть, но это менеджмент аренды:
  ни голоса, ни окон под тон.
Занятые слоты репо: **«Знаменовать»** — гость меняет закон ВСЕГО места целиком, один
активный носитель, цикл-очередь с терпением и форс-стампом; здесь закона-носителя нет:
закон один и постоянен (один голос), дробится составом, перестановка вытеснением,
терпения нет. **«Подпись»** — обязательство на завтра с подготовкой мира под свою
подпись; здесь состав = речь сейчас, готовить нечего. **«Жалованная грамота»** —
жалование области вечным законом с аппетитом; здесь институт и его голос, жалованья
нет. **«Вскрыть»** — тайна-печать и рукопожатие тайн; тайн здесь нет. **«Опросить
хоромы»** — стены-свидетели и утечка вопросов; здесь комнаты молчат, звучит только
наружный микс. Grep по слотам (мажоритар/весовой/один голос/жильцы) — пусто.

## Критерии приёмки (боты)
- **Экспорт `window.POPULATE_PRESIDENT`** для headless-тестов: `{ CONFIG, LEVELS,
  startLevel(i), moveIn(queueIdx, roomId), tick(dt), state() }`; `state()` отдаёт
  сериализуемый объект `{ t, level, rooms:[{id, tenant}], queue:[{idx, kind}],
  retired:[{kind, outAt}], voice:{warrior,merchant,sage,poet}, tasks:[{kind, min,
  window:[a,b], status: pending|open|done|failed}], pips, moves, par, over, won,
  stars }`. Все решения ботов — через API, без пикселей.
- **План-бот** (линии уровней выше, клики секунда в секунду) — **5/5 побед**, moves ≤
  par (1/2/3/2/4), **3★ на всех пяти**, 0 срывов. Обязательно.
- **Бот «никогда не кликает»** — теряет 3★ на всех уровнях и проваливает ≥ 1 уровень
  целиком (прикидка: L5 — срывы A @8, B @26, C @44 → пипсы 0 → рестарт). Обязательно.
- **Спам-бот** (moveIn первого из очереди в r1 каждые 8 с) — 3★ недостижимы нигде;
  провал минимум на L5 (прикидка: очередь сгорает за 24 с, срывы A @8, B @26, C @44 →
  пипсы 0; на L4 спам падает тоже: срывы A @10, B @30, C @48). Если перебор покажет
  спам-3★ где-то — окна от противного, не случайность. Обязательно.
- **Рандом-бот** (равновероятно {ждать, moveIn(случайный кандидат, случайная комната)}
  на каждом тике 1 с) — **<50% побед на L2–L5** (≥ 20000 headless-партий); L1 —
  высокий процент (обучение), подтвердить замером.
- **Перебор-бот** (DFS по последовательностям moveIn с моментами шагом 0.5 с, глубина
  ≤ par): (i) маршрута с moves < par не существует ни на одном уровне; (ii) ни один
  статичный состав (без подселений) не закрывает все окна L2–L5; (iii) на L2/L5 ветки
  с ранним выдавливанием тора (на L5 — и поэта до B) не достигают par-результата.
  Обязательно.
- **Детерминизм**: та же последовательность кликов → тот же лог событий. Обязательно.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. CONFIG вверху, уровни —
данные. Вопрос прототипа — в заголовке страницы. HUD: лента времени с окнами, пузырь
голоса (цвет-бленд + доли-полоски), пипсы двора и счёт «подселений X/par» одной строкой
— ответ на вопрос прототипа. Управление: только мышь (клик по кандидату → клик по
комнате). Въезд/выезд — анимации 0.3/0.5 с; срыв окна — серая вспышка иконки.
