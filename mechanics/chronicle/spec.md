# Летопись — спецификация v1 (после фильтра, GO*)

## Название
Летопись (рабочее).

## Пара-источник
записывать_VERB × деспот_NOUN (word2vec RusVectores, sim −0.177; архетип «перенос»; этап 1: Σ7).

## Правило (одно предложение)
Капризы деспота приходят сами и испаряются сами: клик по капризу вписывает его в летопись
НАВСЕГДА (3 слота на партию, отмены нет) — записанный каприз застывает законом, который
каждую ночь исполняют стража, народ и сам деспот, оплачивая содержание из своей казны,
а незаписанный исчезает с приходом следующего каприза.

## Скелет и линзы (Адамс/Дорманс)
- **Паттерн-скелет**: триаж потока с вечными последствиями — решаешь не «что сделать», а
  «что из приходящего мимо узаконить навсегда».
- **Инновация в ДИСКРЕТНОЙ части** (гл. 1): дельты законов — целые числа на карточках;
  ночи — дискретный резолв (законы → распад → проверка); окна-дедлайны выводимы из
  констант, партия решается на бумаге. Непрерывны только 12-секундный drip-таймер каприза
  и 2-секундная ночь — presentation, не механика.
- **Выигрышные действия** (гл. 12): чтение расписания смертей трёх полос (голод, бунт,
  разорение умирают в разные ночи); выбор МОМЕНТА записи внутри окна; сознательная запись
  закона с минусом («необходимое зло»); сбережение слота вопреки соблазну.

## Глаголы игрока
- **Клик по карточке каприза** — запись в летопись (если есть свободный слот; слоты заняты —
  карточка трясётся, запись невозможна). Необратимо: карточка уходит в летопись с печатью,
  её дельты действуют КАЖДУЮ ночь до конца партии.
- **Не-клик** — пропуск: каприз уходит с приходом следующего (12 с на решение). Решения —
  только «какой / когда / писать ли», никаких «сколько держать». Единственный глагол — КЛИК;
  аватара и ходьбы нет.

## Токены
- **Каприз** — карточка с именем и тремя иконками дельт (хлеб/покой/казна, красные и зелёные).
  Приходит сам, живёт 12 с, исчезает сам. 2 каприза в день.
- **Летопись** — 3 слота на партию; вписанное исполняют ВСЕ (стража, народ, деспот) и оно
  кровоточит казной каждую ночь.
- **Три полосы** (старт 6, максимум 10): **Хлеб** (сытость народа), **Покой** (спокойствие),
  **Казна** (добро деспота). Полоса 0 = проигрыш: голод / бунт / разорение.
- **Ночь** (2 с): законы применяют дельты в порядке записи, затем распад: хлеб −2; покой −2,
  но **−1, пока хлеб ≥ 4** («сытый народ терпит»); полоса ≤ 0 — конец.
- **Праздник** — ночь 8 пройдена со всеми полосами > 0 = победа.

## Петли (7-профиль)
- **P1 запись → каждую ночь**: записал — закон тикает до конца партии; решение сегодня,
  последствие вечное. +/конструктивное/среднее/отложенная (ночь)/широкая (все полосы)/партия/долгая.
- **P2 три расписания смертей**: хлеб умирает к ночи 3, покой — к ночи 5, казна — к ночи 4–6;
  порядок записей = план под три дедлайна. +/конструктивное/высокое/отложенная/средняя/марш/долгая.
- **P3 сытый народ терпит**: закон сытости меняет РАСПАД покоя (−2 → −1) — законы
  взаимодействуют каскадом, а не складываются тупо. +/конструктивное/среднее/отложенная/широкая/партия/долгая.
- **N1 необратимость**: слот занят навсегда — вписал мусор, не впишешь спасение (оброк на D5
  уже не влезет). −/destructive/среднее/отложенная/средняя/партия/долгая.
- **N2 ловушки-капризы**: «Позорный столб», «Комендантский час», «Хлеб и камень», «Грабёж» —
  соблазн по одной полосе ценой другой. −/destructive/среднее/немедленная/средняя/день/короткая.
- **N3 необходимое зло**: оброк несёт минус по покою, но без него разорение — перепроходит
  «все минусы не трогать». −+/destructive-конструктивное/высокое/отложенная/средняя/марш/долгая.
- **Против доминаторов** (все проверены перебором, см. боты): «ничего не писать» — голод ночью 3;
  «писать всё подряд» — разорение ночью 4 (содержание законов); «только кормовые» — разорение
  ночью 4; «только бесплатные» — голод ночью 3; «копить и сливать» (джекпоты D7–D8) — голод
  ночью 3; «яд-пилюля вместо оброка» («Грабёж») — голод ночью 7.

## Глубина (гейт)
- **Оси рекомбинации (≥2)**: набор трёх законов (697 протоколов — 4 победных набора);
  тайминг записи внутри окна (тот же набор — разные маргины 1–4); состояние полос как
  функция прошлых записей (каскад P1).
- **Дерево навыков из ядра**: чтение дедлайна полосы (D2 голод, D4 покой, D5 казна — каждый
  навык на своём дне); распознавание ловушек по дельтам (D2 «Столб», D4 «Час», D3 «Камень»);
  сбережение слота (D1-карты, D7-джекпоты). Каждый ≥ 2 применений.
- **Замок/ключ из механики**: замок = дефицит вечности (3 слота на 16 капризов) + три
  расписания смертей; ключ = чтение дельт и окон; динамический замок — необходимое зло:
  ключ производит минус (оброк портит покой), которым надо успеть заплатить.
- **Тип прогресса**: выживание (марш 8 дней) + качество (минимальная полоса на празднике = звёзды).
- **Доминаторы сломаны наборами**: каждая ленивая стратегия умирает своей смертью в свою ночь.

## Цель и проигрыш
- **Цель**: провести народ 8 дней до праздника — все три полосы > 0 после ночи 8.
- **Победа со звёздами** (минимальная полоса после ночи 8): 3 — ≥ 4; 2 — ≥ 2; 1 — победа.
- **Проигрыш**: любая полоса ≤ 0 в ночном резолве → рестарт марша (партия ~3,5 мин).
  Причина видна: голод / бунт / разорение.

## Вопрос прототипа (один)
Рождает ли триаж испаряющихся капризов с вечными последствиями настоящее планирование —
окна-дедлайны по трём полосам, сознательное необходимое зло, сбережение слота вопреки
соблазну, — или игрок пишет всё подряд / ничего не пишет? Прототип обязан содержать: три
полосы с независимыми смертями, дельты на карточках, 3 слота и испарение по таймеру —
иначе вопрос решён заранее в пользу «темы».

## Уровни-дни (8, один марш; обучение одним намёком; решения проверены полным перебором)
- **D1 «Первый каприз»** — «По лому хлебу» и «Сказ о празднике». Провал невозможен (первая
  смерть физически ночью 3). Учит: клик = печать навсегда; вписанное тикает каждую ночь;
  ПРОПУСТИТЬ — тоже решение (обе карты — приманка для слота; исключение: «Сказ» открывает
  запасной маршрут 2★).
- **D2 «Голод»** — «Каждому по хлебу» (спасение) и «Позорный столб» (покой ценой хлеба).
  Пассив-бот умирает этой ночью. Учит: у хлеба есть дедлайн, и он СЕГОДНЯ; ловушки уже пошли.
- **D3 «Платный покой»** — «Копья страже» (+2 покоя за казну каждый день) и «Хлеб и камень»
  (жирный корм с двойным ядом). Учит: законы покоя стоят казны; дельты читаются ДО записи.
- **D4 «Срок бунта»** — «Ночные дозоры» (бесплатный покой — последний срок) и «Комендантский
  час» (классическая ловушка формулы). Без закона покоя к этой ночи — бунт ночью 5.
- **D5 «Необходимое зло»** — «Хлебные раздачи» и «Чрезвычайный оброк» (минус покоя, плюс
  казна). Срок разорения: без дохода казна умирает ночью 5–6. Учит: иногда закон пишут
  вопреки его минусу.
- **D6 «Яд-пилюля»** — «Грабёж» (покой и деньги ценой голода) и «Оброк непокорным» (доход
  жёстче, двойной минус покоя). Учит: поздние спасения платят чужими полосами.
- **D7 «Цена слота»** — «Королевский пир» и «Народное ополчение» (джекпоты). Слот свободен —
  роскошь; занят — не отменишь. Учит: сбережение слота — накопленный навык, не жадность.
- **D8 «Экзамен на сдержанность»** — аварийные «Хлеб из резерва» и «Прощение долгов»:
  последняя ночь; писать надо только чтобы НЕ умереть этой ночью. Учит: летопись — не список
  желаний, а инструмент выживания.

**Эталон-маршрут 3★ (проверен перебором, ночь за ночью)**: старт 6/6/6 → N1: 4/5/6 (ничего)
→ «Каждому по хлебу» (D2) → N2: 4/4/5, N3: 4/3/4 → «Ночные дозоры» (D4) → N4: 4/4/3 →
«Чрезвычайный оброк» (D5) → N5: 4/4/4 → N6: 4/4/5 → N7: 4/4/6 → N8: 4/4/7 = ПОБЕДА,
минимум 4 → 3★. Три клика за партию = par (побед меньшей ценой не существует).

**Все победные наборы** (полный перебор 697 протоколов, ≤ 3 записей): «Хлеб»+«Дозоры»+«Оброк»
(3★, маргин 4); «Сказ»+«Хлеб»+«Оброк» (2★, 2); «Хлеб»+«Дозоры»+«Оброк непокорным» (2★, 2);
«Хлеб»+«Копья»+«Оброк» (1★, 1). par = 3 записи; окно-дедлайны без закона: голод N3,
бунт N5, разорение N5–6.

## Стартовые константы (числа для HTML, править при балансировке)
Один экран 960×640: сверху три полосы (иконка + полоса + суммарные дельты законов рядом,
≥ 48 px), центр — карточка каприза (имя + 3 иконки дельт + 12-секундное кольцо-таймер),
справа летопись: 3 слота с вписанными мини-картами и их дельтами. HUD строкой: «День X/8».
День = 2 каприза по 12 с; ночь-резолв 2 с (полосы тикают по одной); партия ≈ 3,5 мин.
Клик по карточке = запись (анимация печати 0,5 с); слоты заняты — тряска карточки 0,3 с.
Старт полос 6/6/6, максимум 10. Распад: хлеб −2; покой −2 (−1 при хлебе ≥ 4 — иконка на
полосе покоя мигает, правило видно без текста). Проигрыш: полоса 0 — экран причины.
Победа: после N8 — экран праздника и звёзды по минимальной полосе (4 → 3★, 2 → 2★).

## Риски баланса
- **«Побед 0,6% при случайной игре — жёстко»**: партия 3,5 мин, три смерти-урока (голод N3,
  бунт N5, разорение N5) показывают все три окна. Если игроки тупят: хлеб старт 7 — и сразу
  перебор заново (не откроет ли 2-записные победы); не послаблять ловушки.
- **«D1-карты бесполезны»**: «Сказ» открывает маршрут 2★ (проверено); «Лом» — честная ловушка
  кровотечения. Оставить.
- **«Оброк кажется ошибкой»**: дельты иконками прямо на карточке; первая проверка сборки —
  план-бот пишет оброк на D5 и побеждает; человек, потерявший казну на N5, читает смерть
  «разорение» и на следующем марше ищет плюс-казну.
- **«12 с мало читать карточку»**: карточка = имя + 3 иконки; план-бот играет без таймера по
  протоколу. Если люди не успевают — 16 с, не отмена испарения.
- **«Каскад „сытый терпит" невидим»**: мигающая иконка на полосе покоя при хлебе ≥ 4; если
  не читается — стрелка «−2/−1» рядом с полосой.
- **Решения дней на бумаге** — эталон выше; любое изменение дельт перепроверяется перебором
  (697 протоколов считаются мгновенно).

## Что НЕ входит в v1 (осознанно вырезано)
- **Случайный порядок колоды из эскиза** — заменён фиксированным марш-раскладом: детерминизм
  для бумажных решений и ботов (урок «Меридиана»/«Зодчего»); seed-варианты — v2.
- **«Провал дважды» из эскиза** — убрано: одна смерть = конец марша, рестарт дешевле повтора.
- **Стража и народ как фигуры на экране** — полосы вместо токенов; сцена дворца не рисуется.
- **Отмена/поправка законов** — противоречит формуле («записанная воля перестаёт быть капризом»).
- **Звёзды за число записей из эскиза** — вырождены (слоты и так кап = 3, par = 3 у любой
  победы); заменены звёздами по минимальной полосе.
- 4-й слот, разные деспоты/марши, торговля, звук, мобильное управление, сохранения — v2.

## Новизна (проверка вебом 2026-11-14, 3 запроса + кластерная сверка №16)
Прямого аналога «каприз испаряется сам → запись навсегда связывает издавшего → 3 слота
вечности на партию» не найдено. Ближайшие соседи и чем отличаемся:
- **Reigns** (монарх, свайп-карты, 4 полосы) — решения мгновенные и беззвучные: ничего не
  застывает, ничего не испаряется по таймеру, выбор не занимает вечный слот и не стоит
  короне ежедневной платы. У нас решение = вечный закон с содержанием из казны издавшего.
- **Frostpunk, Book of Laws** (ближайший сосед: необратимые законы с плюсами и минусами) —
  законы ждут игрока в меню-дереве (TTL нет), их можно принять десятки, личной цены
  издающему нет. У нас — 3 слота, каприз умирает через 12 с, казна деспота кровоточит
  каждую ночь, и «сытый народ терпит» связывает законы каскадом.
- **9 Kings / Royal Decree! / Empire Clash (edicts)** — декреты = постоянные БОНУСЫ руну;
  не связывают подписавшего, не испаряются, дефицита слотов нет.
- **Кластер «слово» (наш репо, №16)**: Подпись — игрок сам сочиняет обязательство и мир
  исполняет его завтра; здесь авторства ноль (текст приходит капризом) и ничего не
  откладывается на завтра — оно тикает каждую ночь. Гиря слова — чужое обещание = вес на
  плече, ЕСТЬ разрыв (сброс); здесь отмены нет в принципе. Ложь-замок — своя ложь и откат
  признанием; здесь нет ни лжи, ни отката. Недомолвка — ЧУЖАЯ достройка твоего пропуска,
  груз ложится на получателя и есть окно прощения; здесь груз (содержание закона) платит
  сам издавший, чужая воля лишь приходит капризом, и прощения не бывает — испарение
  незаписанного и есть «право передумать», которое запись уничтожает.
Комбинация «испарение каприза + вечная запись + бремя издавшего + дефицит вечности»
новизну держит.

## Критерии приёмки (боты)
- **План-бот** (эталон-маршрут: «Каждому по хлебу» D2 → «Ночные дозоры» D4 → «Чрезвычайный
  оброк» D5): победа, 3 записи (par), минимальная полоса ≥ 4 → 3★. Обязательный порог.
- **Пассив-бот** (не пишет ничего): проигрыш — голод ночью 3. Обязательно.
- **Всё-подряд-бот** (пишет первые три пришедших каприза): проигрыш — разорение ночью 4. Обязательно.
- **Только-корм-бот** (пишет все кормовые: «Хлеб», «Камень», «Раздачи»): проигрыш — разорение
  ночью 4. Обязательно.
- **Копить-и-сливать-бот** (пишет только джекпоты D7–D8): проигрыш — голод ночью 3. Обязательно.
- **Перебор-бот** (DFS по 697 протоколам): ровно 4 победных набора, все по 3 записи; побед
  менее чем за 3 записи не существует; 3★-маршрут единственный. Обязательно.
- **Рандом-бот** (пишет с вероятностью 0,5 при свободном слоте): < 5% побед. Обязательно.
- **Экспорт** `window.CHRONICLE` для headless-тестов: `{CONFIG, DECK, startParty(), card(i),
  write(i), night(), state()}` — таймеры отключаемы (`CONFIG.CARD_TIME = 0` — каприз живёт,
  пока бот не вызовет `card(i+1)`); `state()` отдаёт полосы, слоты, записанные законы, день
  и исход.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Полосы и дельты читаются
иконками (хлеб/щит/монета, зелёное/красное); летопись справа с печатями. Ночь: 2-секундный
резолв с тиканием полос; причина проигрыша — экраном (голод / бунт / разорение); победа —
праздник и звёзды. Вопрос прототипа — в заголовке страницы.
