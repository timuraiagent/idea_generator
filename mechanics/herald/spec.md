# Знаменовать — спецификация v1 (после фильтра, GO*)

## Название
Знаменовать (рабочее).

## Пара-источник
знаменовать_VERB × приезжий_NOUN (word2vec RusVectores, sim −0.166; архетип «связь» — приезд
связывает локацию с правом гостя).

## Правка фильтра (одна, закрывает №14)
Эскиз заявлял «впуск обязателен», но механизма обязательности не было: «никогда не впускать»
и «держать один удобный закон» бесплатны, а выбор «кого следующего дождаться» отсутствует —
дерево решений сжималось к «кликнуть когда-нибудь». Правка одна — **терпение гостя**:
гость на пороге ждёт ограниченно и с истечением входит САМ (форс-стамп), значит смену закона
невозможно остановить — можно только выбрать её момент; «впуск обязателен» становится
правилом, а не декларацией. Та же правка закрывает антидоминатор: окна задач спроектированы
«от противного» — ни один закон не закрывает все окна, а минусы каждого закона тикают по
пипсам амбара. №12/№15 усиливаются той же правкой: форс-стамп делает «когда» вынужденным
решением, а «мёртвые зазоры» (впустить вредный закон там, где он безвреден) — новой сутью
задач L2/L4. Формула не тронута.

## Правило (одно предложение)
Гость на пороге — это закон всей локации: впустить его (клик) — закон меняется НЕМЕДЛЕННО,
а прежний носитель уезжает на дорогу в конец очереди — законы не отменяются, а переставляются
по кругу из четырёх; впуск обязателен — у гостя на пороге тикает терпение, и с истечением он
входит сам, — при этом каждое окно задачи открывается ровно под один из законов, и у каждого
закона есть минус, тикающий по твоему амбару: ты не управляешь законом — ты выбираешь, под
каким жить и когда его сдавать.

## Глаголы игрока (единственный ввод — клик; WASD нет)
- **Впустить** (клик по гостю на пороге): закон меняется мгновенно; прежний уезжает в хвост
  очереди; следующий дойдёт до порога за 7 с — эти 7 с сменить закон нельзя (ворота пусты).
- **Идти** (клик по станции): герой-курьер идёт сам; скорость зависит от закона.
- **Взять/сдать** (клик по станции, где стоит герой): поле — взять зрелый плод; сундук/дом/
  амбар — сдать груз или письмо. Плод — тяжёлый груз, письмо — лёгкий.

## Токены
- **Гость на пороге** (иконка закона + полоса терпения) и **очередь на дороге**: полный
  порядок всех четырёх законов виден с начала уровня — полная информация для планирования.
- **Активный закон**: палитра/виньетка всего экрана + иконка в углу, без текста.
- **Законы (4, фиксированный цикл)**: ночь → скользкое → огонь → пусто → ночь → …
- **Герой-курьер** (с грузом / пустой), **плод** (полоска зрелости), **письмо** (лёгкий груз).
- **Страж** у мостков: глаз бодр / спит / убежал; досмотр — задержка 2 с (конфискаций в v1 нет).
- **Караван**: полоса на мостках, закрывает переход на своё окно (кроме закона «пусто»).
- **Сундук-ночник** (открывается только под «ночь») и **сундук-пустотник** (только под «пусто»).
- **Амбар: 3 пипса** — здоровье хозяйства; тикают от минусов законов и срывов окон.
- **Лента времени** внизу: 90 с уровня с окнами задач и каравана — планирование полным
  перебором честно: вся партия детерминирована.

## Законы (вся матрица v1; активный закон перекрашивает весь экран)
| Закон | Плюс | Минус (тикает) |
|---|---|---|
| **Ночь длинная** | страж спит (досмотра нет); сундук-ночник открыт | рост плода стоит |
| **Дороги скользкие** | пустой герой ×1.6 скорость | с грузом мостки запрещены (рассыплется) |
| **Всё горит** | страж убегает (досмотра нет); мостки целы | −1 пипс на каждой 8-й секунде непрерывного горения |
| **Карманы пусты** | мостки открыты даже при караване | тяжёлое (плод) взять/сдать нельзя; письмо — можно |

Перенос через мостки с грузом возможен только под «ночь» или «огонь» (под «скользкое» —
рассыплется, под «пусто» — нечего нести). Уже несомый груз при смене на «пусто» сохраняется,
но сдать нельзя, пока закон не сменился. Зрелость растёт под всеми законами, кроме «ночь».

## Петли (7-профиль: тип / эффект / вложение / отдача / скорость / дальность / долговечность)
- **P1 впуск → закон всего места → окна перечитаны**: + конструктивная / выбор момента впуска
  (1 клик) / немедленная / короткая / вся локация / до следующего впуска. «Что я впустил, тем
  живёт всё — и моя ферма, и мои задачи».
- **P2 фаза цикла против окон**: + конструктивная / планирование ТОГО, какой закон активен в
  каждом окне и через какие вредные законы платить / отложенная / уровень. Законы не
  выбираются — планируется ФАЗА перестановки (№9: инвариант — набор законов сохраняется).
- **P3 терпение против выдержки**: − напряжённая / среднее / уровень. Держать вредный закон в
  «мёртвом зазоре» и поймать форс-стамп так, чтобы нужный закон встал ровно к окну; лучшие
  линии ставят смену за 1–2 с до выноса (L2).
- **N1 обоюдоострость (№11)**: − destructive на самого игрока / низкое / перманентно, пока
  закон активен: рост стоит, мостки закрыты, амбар тлеет, тяжёлое нельзя — каждый закон бьёт
  по твоему хозяйству, а не только по задачам.
- **N2 впритык**: − напряжённая / высокое (расчёт riding огня ≤ 7 с = 0 тиков; смена за 1–2 с
  до форс-стампа) / уровень. Все план-линии стоят на пределах терпения и горения.

## Цель и проигрыш
- **Цель уровня (90 с)**: закрыть все окна задач уровня. Уровень завершается успехом сразу
  после последней задачи (таймер и тики стоп).
- **Пипсы амбара 3**: срыв окна −1, тик огня −1; 0 → рестарт уровня. Партия 5 уровней ≈ 6 мин.
- **Звёзды**: 3★ = все задачи ∧ пипсы 3 ∧ смен закона ≤ par; 2★ = все задачи ∧ пипсы ≥ 2;
  1★ = все задачи. Par (минимум смен, посчитан план-линиями, подтвердить перебором):
  L1=1, L2=2, L3=4, L4=4, L5=7.

## Вопрос прототипа (один)
Рождает ли обязательный впуск носителя закона с терпением и циклом-перестановкой настоящее
планирование ФАЗЫ — какой закон активен в каждом окне, где у вредного закона «мёртвый зазор»,
сколько платить за возврат нужного, — или игрок спамит впуск / держит один закон / впускает
наугад? Прототип обязан содержать: терпение с форс-стампом (иначе «не впускать никогда»
бесплатно), тикающие минусы каждого закона (иначе лучший закон доминирует), полный порядок
очереди и ленту окон (иначе планирование фазы нечестно), и окна, непроходимые одним законом,
— иначе вопрос решён заранее в пользу «темы».

## Риски баланса
- **«Спам цикла к нужному закону»** (если spinning бесплатен) — противоядие: R=7 и окна от
  противного ритма. Первая проверка прототипа: проходит ли спам-бот уровни? Если да — двигать
  окна (спроектированы так, что ни 7-секундный ритм, ни T-форс не закрывают все окна), не
  вводить случайность.
- **«Один удобный закон навсегда»** — противоядие: терпение с форс-стампом (держание
  невозможно), минусы, тикающие пипсами, и окна под разные законы. Проверка: бот «никогда
  не кликает» обязан терять 3★ везде.
- **«Держать огонь ради убежавшего стража»** — тик каждые 8 с; в план-линиях держание огня
  дольше 7 с всегда дороже альтернативы.
- **«Тайминг вырождается в секундомер»** — окна с внутренними событиями (караван, сундук-
  ночник, мёртвые зазоры) и впуск по ориентиру (L3/L5) требуют читать мир, а не таймер.
- **«Гость = закон» не читается** — иконка закона у гостя дублирует иконку активного закона
  в углу; смена = вспышка перекраски экрана 0.4 с; если игрок путается — подсветить носителя
  активного закона в очереди рамкой.
- Все константы вверху файла прототипа в один объект CONFIG; уровни — данные
  (окна, старт-фаза, T, пар).

## Что НЕ входит в v1 (осознанно вырезано)
- **Отказ гостю и выбор кандидата** — ядро механики: впуск обязателен, законы не выбираются.
- **5-й закон и нестандартные циклы**, отмена/выкуп закона, конфискации стража (только
  задержка), несколько стражей и патрулей.
- **День-ночь как время суток** — «ночь» только закон-состояние от гостя; нескольких
  локаций, экономики, денег, наград между уровнями.
- WASD-аватар (герой ходит сам по клику-цели), аудио, сохранения, мобильное управление, арт.

## Новизна (проверка вебом 2026-11-15, 4 запроса + сверка занятых слотов)
Прямого аналога «приезд носителя = обязательная немедленная смена закона всего места +
перестановка в очередь» не найдено. Ближайшие соседи и чем отличаемся: **Baba Is You** —
правила как сдвигаемые плитки-слова: игрок меняет их произвольно сам, носителя-гостя,
обязательности и цикла-перестановки нет. **Papers, Please** — порог и приезжие есть, но
законы приходят бюллетенями Министерства, приезжие законов не несут, а решение — инспекция
с правом отказа; у нас отказа нет, гость и есть закон, смена немедленна и бьёт по самому
игроку. **Visitor in Blackwood Grove** — «Visiter» создаёт скрытое pass-rule для дедукции
соперников, не смену закона места по приезду. **That's Not My Neighbor** и клон-кластер —
допуск как инспекция имитаторов, гость ничего не приносит. Микроигры со «сменой правил на
лету» (WarioWare-стиль) — правила меняет игра таймером, без носителя и цены перестановки.
Занятые слоты: **«Подпись»** — обязательство на завтра с подготовкой мира под свою подпись;
здесь — немедленный закон и перестановка, готовить нечего. **«Летопись»** — выбор, какой
каприз увековечить навсегда (3 слота, экономика содержания); здесь — выбора кого нет, законы
не отменяются, а циклятся немедленной сменой. **«Ночь-переклейка»** — тьма как ресурс
площади в руках игрока; здесь ночь — чей-то закон, приезжающий сам. **«Обмен тенями»** —
обмен пакетами «способность+страх» при встрече; здесь обмена нет: гость въезжает, прежний
вытесняется в очередь.

## Критерии приёмки (боты)
- **Экспорт `window.HERALD`** для headless-тестов: `{ CONFIG, LEVELS, state(), admit(),
  goto(stationId), act(), restart(), step(dt) }`; `state()` отдаёт сериализуемый объект
  `{ t, law, queuePhase, patienceLeft, walkLeft, hero:{station, moving, cargo}, tasks:[{id,
  window:[a,b], done, failed}], pips, changes, over, won, stars }`. Все решения ботов —
  через этот API, без пикселей.
- **План-бот** (перебор/BFS по тикам 0.5 с; действия: ждать / впустить / идти на станцию /
  взять-сдать) — **5/5 побед**, смен ≤ par, **3★ на всех пяти** (пар: 1/2/4/4/7).
- **Спам-бот** («впуск немедленно, как порог занят» + герой по жадной эвристике «ближайшая
  доступная цель») — обязан ПАДАТЬ минимум на L2, L3, L4 (срыв окна или пипсы 0); бумажная
  прикидка: L2 — его сдача раньше окна, L3/L4 — срыв B. L1 спам совпадает с планом
  (обучение), L5 допустим проход без 3★.
- **Бот «никогда не кликает»** (только ходьба; законы входят по T-форсам) — обязан терять
  3★ на всех уровнях и проваливать ≥ 1 уровень целиком (прикидка: L4 — форс-огонь даёт 3
  тика и срыв B). Если перебор покажет выживание везде — перекомпоновать окна от противного
  T-ритму, не вводить случайность.
- **Рандом-бот** (равновероятно {ждать, впустить, идти на станцию i}) — **<50% побед на
  L2–L5** (≥ 20000 headless-партий). Бумажные оценки: L1 ≈ 100% (провал невозможен),
  L2 ≈ 12%, L3 ≈ 6%, L4 ≈ 3%, L5 ≈ 1% — прототип обязан подтвердить замером.
- **3★-бот** = план-бот обязан добирать 3★ везде без тиков огня (все riding ≤ 7 с) — иначе
  экономика «впритык» не работает.
- **Антидоминатор**: план-бот обязан использовать ≥ 2 разных закона активными в окнах на
  каждом уровне L2–L5; перебор обязан показать, что с ≤ 1 сменой закрывается только L1.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. CONFIG вверху, уровни — данные.
HUD: лента времени 90 с с окнами задач и каравана (планирование!), полоса терпения над
гостем, пипсы амбара, счёт смен/par — ответ на вопрос прототипа. Активный закон — палитра
всего экрана + иконка без текста: ночь — тёмная виньетка и спящий глаз стража, скользкое —
капли на мостках, огонь — рыжая кайма и дым амбара, пусто — распахнутые ворота мостков и
вывернутые карманы героя. Управление: только мышь (клик по гостю / станции).
