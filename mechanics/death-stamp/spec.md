# Оттиск смерти — спецификация v1 (после фильтра, GO* 16/16)

## Название
Оттиск смерти (рабочее; слот death-stamp).

## Пара-источник
впечатлять_VERB × смерть_NOUN (этап 1 — Σ8 из 8: №1=2, №4=2 — «печать смерти на лице»,
«в-печат-ать», №5=2, №8=2; №3/№6/№7 пройдены, стоп-листа нет). Потолок пары 16.

## Правки фильтра (одна совмещённая + три уточнения, внесены в спеку)
1. **Правка №10+№14 одним изменением — экономика темноты.** Эскиз проваливал обе: спрос
   на оттиск был «культурный» (траур, страх — не величина), а цель «цепь из 4 снимков»
   достигалась спамом кликов. Правка одна, в три хода закона: (а) **смерть идёт на самый
   тёмный живой оттиск** (глубина ≤ терпимости 2) и, дойдя, **изымает его вместе с
   носителем** — «у слепков права нет» начинает действовать: близкая к оригиналу подделка
   изымается по праву оригинала; (б) **врата зала открываются только носителем темнее
   своего порога** — темнота стала востребованной величиной; (в) **носители одноразовы**
   («оттиск остаётся в человеке» — значит, навсегда, второй не впечатывается). Итог:
   тёмное ХОЧЕТСЯ (врата) и НЕ ХОЧЕТСЯ (маяк смерти, сожжённые носители) — одна величина,
   спрос в обе стороны (№10); все четыре ленивые линии наказаны по построению (№14).
   Цель «цепь из 4 снимков» заменена вратами; цепь остаётся в игре как релей (P2).
2. **Уточнение — источник не выбирается (формализация «снимается с ближнего слепка»).**
   Источник оттиска = БЛИЖАЙШИЙ к кликнутой фигурке носитель; сама смерть — носитель
   нулевой глубины, единственный фонтан точного слепка. Игрок выбирает только КОГО
   кликнуть; какой глубины выйдет оттиск — решает закон близости. Отсюда вся тактика
   окон жатвы и релеев.
3. **Уточнение — инвариант №9 закреплён в правилах, а не в честном слове:** клик по
   носящему оттиск — пуст (переснятий нет), клик по смерти — пуст (оригинал один и не
   штампуется), глубина нового оттиска строго = глубина источника + 1, «чей снимок» не
   переписывается никогда.
4. **Уточнение — читаемость:** глубина оттиска видна бледностью штампа, «чей снимок» —
   ниткой к источнику по наведению, текущая цель смерти — пунктиром. Без текста.

## Правило (одно предложение)
Смерть ходит по залу, и её можно в-печатать в пустую фигурку кликом: оттиск снимается с
БЛИЖАЙШЕГО носителя — сама смерть носит нулевую глубину и одна не штампуется — и ложится
ровно на один шаг бледнее его, остаётся в фигурке навсегда и виден всем; самый тёмный
живой оттиск зала притягивает смерть — она идёт к нему и, дойдя, изымает оттиск вместе с
носителем (право оригинала: у слепков права нет, бледные её права не задевают), — а врата
зала открываются навсегда только носителем темнее своего порога.

## Глаголы игрока
- **Впечатать** (клик по пустой фигурке): оттиск от ближайшего носителя, анимация 0.4 с.
- Других глаголов нет: источник не выбирается, оттиск не стирается и не переснимается,
  смерть не командуется — только приманивается. Один глагол — КЛИК; дозировки нет:
  выбираются КОГО (фигурки разные позициями), КОГДА (смерть ходит — точный слепок
  существует только в окне её близости) и В КАКОМ ПОРЯДКЕ (порядок кликов = маршрут
  смерти и глубины всей ветки).

## Токены
- **Фигурка** (гость зала): без оттиска (белая, одноразовый носитель — годен ровно один
  клик) / с оттиском глубины k. Штамп виден всем: 1 — «точный слепок», сплошная чернота;
  2 — «тёмный», тёмно-серый; 3 — «бледный», серый контур; 4+ — едва заметный. Наведение —
  нитка-пунктир к источнику (к мёртвому — серая: история снимка не переписывается).
- **Смерть** (оригинал, r 18): глубина 0; ходит 45 px/с (L5 60) по прямой к цели; цель =
  самый тёмный живой оттиск глубины ≤ терпимости 2 (при изъятии — следующий самый тёмный,
  при равенстве — ближайший к ней); переключается только на СТРОГО более тёмный; целей
  нет — патруль по waypoints уровня. Цель видна пунктиром.
- **Врата** (64×12, радиус действия 70 px): порог T ∈ {1,2,3} — открываются НАВСЕГДА,
  когда живой носитель глубины ≤ T стоит в радиусе; порог показан образцом черноты
  (чёрный/тёмно-серый/серый), радиус подсвечен при наведении.
- **Терпимость K=2**: смерть преследует только глубины 1–2 («близкая подделка»); глубина
  3+ её права не задевает — бледный экземпляр безопасен и потому хранит форму ветки,
  когда тёмные изъяты.
- **Потери** — фигурки, изъятые смертью; **par** уровня — минимум потерь на победной
  линии (подтверждается перебором при сборке, как в «Отводе»/«Объезде»).

## Правила (вся матрица v1)
| Событие | Правило |
|---------|---------|
| Клик по пустой фигурке | оттиск: глубина = глубина ближайшего живого носителя (смерть = 0) + 1; источник фиксируется навсегда |
| Клик по носящему / по смерти | пуст; оттиск не переснимается, оригинал не штампуется |
| Новый оттиск СТРОГО темнее цели смерти | цель переключается немедленно |
| Смерть дошла до цели | носитель умирает (потеря), оттиск изъят; цель = следующий самый тёмный ≤ 2 |
| Целей (глубина ≤ 2) нет | смерть патрулирует waypoints по кругу |
| Носитель глубины ≤ T в 70 px от врат | врата открыты навсегда (автоматически, мгновенно) |
| Все врата открыты | победа уровня (потери после победы не существуют — мир стоп) |
| Пустых фигурок 0 и остались закрытые врата | провал (достижимость: открыть больше нечем — фигурки не ходят, оттиск не переснимается) |

## Петли
- **P1 «маяк → жатва»**: тёмный оттиск ведёт смерть твоим же маршрутом — печать строит её
  дорогу к вратам, и в окне её хода рядом можно снимать точные слепки у неё за спиной и
  открывать тёмные врата раньше, чем она придёт изымать. Печатающий сам чертит охоту.
- **P2 «деградация дистанции»**: темнота не переносится — каждый хоп релея −1 ступень,
  бледный мост из трёх фигурок доносит до дальних врат только глубину 3+. Расстояние
  платится либо носителями (цепь), либо доставкой смерти (маяк-приманка).
- **P3 «форма для следующего»**: твой оттиск — ближайший источник для чужих кликов:
  штамп посреди толпы «сжигает» соседей бледностью навсегда. Порядок и место кликов
  меняют глубины всей ветки — печатаешь и себе.
- **N1 «жадина»**: штамповать всех подряд — одноразовые носители сожжены бледным,
  тёмные врата закрываются навсегда → провал достижимости.
- **N2 «трус»**: не печатать тёмного — тёмные врата (T1) не открываются никогда → 0 побед.
- **N3 «копилка»**: держать самый тёмный про запас — смерть его изымает (тёмное не
  хранится, тёмное тратится в окне).

## Цель и проигрыш
- **Цель**: открыть все врата зала.
- **Звёзды по потерям**: 3★ = потерь = par; 2★ = ≤ par+1; 1★ = победа.
- **Провал**: пустых фигурок нет, закрытые врата остались. Рестарт уровня мгновенный;
  таймера нет — смерть и деградация делают время дорогим без крана (паззл, как в «Следе»).

## Вопрос прототипа (один)
Рождает ли закон «копия всегда бледнее ближайшего носителя, а оригинал изымает самое
тёмное» планирование кампании — маяки, окна жатвы у хода смерти, релеи с потерей ступени,
триаж одноразовых носителей — или игрок штампует всех подряд / прячется в бледном углу?
Прототип обязан содержать: терпимость и охоту на самое тёмное (иначе тёмное хранится),
одноразовость носителей (иначе спам бесплатен), врата с порогами темноты (иначе цель =
спам цепи), ретаргет «строго темнее» (иначе смерть дёргается и план невозможен). Мерило:
план-бот проходит с par, рандом и жадина — нет.

## Уровни (5, обучение одним намёком)
- **L1 «Точный слепок»** — 6 фигурок, 2 врата: T1 у кольца патруля смерти, T2 в стороне
  от её маршрута. Учит: клик у самой смерти = точный слепок; врата открывает носитель
  темнее порога; тёмное — приманка и жертва (первое изъятие видно безопасно). par 1.
- **L2 «Релей»** — 7 фигурок, врата T3 у патруля и T2 у дальнего края. Учит: темнота не
  переносится — бледная цепь до T2 не доносит, только доставка смерти маяком. par 1.
- **L3 «Одноразовые»** — 5 фигурок, врата T3 у старта и T1 в дальнем углу, у T1 всего
  две пустые фигурки, патруль проходит мимо обоих. Учит: оттиск остаётся навсегда —
  сожжёшь соседей бледным, точного у T1 нести некому; триаж носителей. par 0.
- **L4 «Строго темнее»** — 8 фигурок, 3 врата (T1 в двух противоположных углах, T2 в
  центре), патруль-восьмёрка. Учит ретаргет: оттиск темнее текущей цели уводит смерть с
  полдороги — порядок кликов и есть маршрут смерти. par 2.
- **L5 «Экзамен»** — 9 фигурок, 4 врата (T3, T2, T2, T1 по углам), смерть 60 px/с.
  Экзамен кампании: маяки, окна жатвы, экономия носителей, порядок врат. par 3.
  par всех уровней подтверждается полным перебором живых состояний при сборке; если
  план-бот находит линию дешевле заявленной — par пересчитывается, уровни не трогаются.

## Стартовые константы (числа для HTML, править при балансировке)
Один экран 960×640, без камеры. Фигурка r=14, смерть r=18, скорость смерти 45 px/с
(L5: 60). Терпимость K=2. Врата 64×12, радиус действия 70 px, пороги 1–3. Анимация
штампа 0.4 с; кликов без лимита, но носитель одноразов. Потери и счёт «врата X/N,
потери/par» одной строкой. Уровни — данные в CONFIG: figures[{x,y}], gates[{x,y,T}],
patrol[{x,y}], deathSpeed, par. Детерминированы (без рандома) — боты до визуальной
сборки.

## Риски баланса
- **«Все врата у патруля»** (смерть случайно обслуживает всё) — разносить врата и
  патруль; первая проверка прототипа: на L2/L4/L5 план без маяков обязан проваливать
  тёмные врата. Если проходит — раздвигать врата, не менять деградацию.
- **«Провал-софтлок незаметен»** — счётчик пустых фигурок; при нулевом запасе закрытые
  врата подсвечиваются сразу. Чинить подсветкой, не правилами.
- **«Смерть дёргается»** — ретаргет только «строго темнее», при равенстве держит цель;
  если всё равно мечется — очередь целей, рандом не вводить.
- **«Бледный бесполезен»** — T3-врата и релеи дают бледности работу; если на плейтесте
  бледный всегда мусор — добавить врат T3, не ослаблять деградацию.
- **«Изъятие фрустрирует»** — изъятая ветка живёт дальше (дети покойного нести свои
  глубины не меняют), нитка к мёртвому источнику серым; рестарт мгновенный.
- Все константы вверху прототипа в один объект CONFIG; уровни — данные.

## Что НЕ входит в v1 (осознанно вырезано)
- Несколько смертей-оригиналов — запрещено формулой (оригинал один).
- Стирание, переснятие, «осветление» оттисков — «остаётся навсегда».
- Движущиеся фигурки, стены/колонны зала, цена клика, таймер уровня, сохранения,
  тач/свайп, арт/аудио. Командование смертью — её нельзя командовать, только приманить.

## Новизна (проверка вебом 2026-11-15, 4 англ. запроса)
Прямого аналога правила («оттиск смерти виден всем, снимается касанием с ближайшего
носителя, бледнеет на поколение за снятие, а оригинал изымает самый тёмный экземпляр»)
не найдено. Запросы: «death imprint stamp on characters copies degrade each generation
game mechanic», «game mechanic copying an artifact degrades each duplicate generation
photocopy puzzle», «puzzle game curse spreads by touch carriers fade weakest copied from
nearest bearer original hunts strongest copy», «indie game mechanic relay message chain
villagers each retelling loses detail telephone game puzzle». Ближайшие соседи и чем
отличаемся: **generation loss** (Wikipedia) — принцип данных о потере качества копий,
не правило игры; **clone degeneration** (TV Tropes) — нарративный троп без цепи снятий,
носителей-источников и охоты оригинала; **Tibia Grimvale «The Curse Spreads»** — RPG-
квест: проклятие распространяется, но без деградации поколений и изъятия самого тёмного;
**Ludipe «I heard a rumor»** — распространение слухов соединением точек, без поколений
копии; **Minecraft gossip** — репутация расползается, без деградации и охотника;
**Artifact decay** (OP2) — случайная порча предметов, не тираж. Развод по флагу семейства
«состояние передаётся людям» (обязателен по этапу 2–3): **Паника** — усвоенная повадка
с автотриггером, заражение толпы страхом излечимо и без копий; **Вакцина** — звук-носитель,
две дозы ОДНОЙ передачи (вполсилы/полная), иммунитет в цепи не деградирует и переболевший
не становится источником для следующего; **След** — беда повторяет траекторию одного тела,
никого не тиражирует. Оттиск держит новизну на трёх признаках, которых нет ни у одного
соседа: (1) цепь копий с потерей ступени на каждом снятии, (2) носитель = форма/источник
следующего снимка, (3) оригинал-охотник на самый тёмный экземпляр. Занятые слоты проверены:
death-stamp свободен; «Судный день» (печать на днях календаря, без тиража), «Полароид»
(снимок = титул собственности, сила кадра РАСТЁТ и оспаривается — тут тираж по людям и
сила ПАДАЕТ с каждым снятием), «Знаменовать», «Царапина» — не пересекаются.

## Бот-приёмка (window.DEATH_STAMP)
- `window.DEATH_STAMP.CONFIG` — все константы; `loadLevel(n)` — уровень 1–5.
- `state()` → {t, level, figures:[{id,x,y,depth,alive,sourceId}], death:{x,y,targetId,
  speed}, gates:[{id,x,y,T,open}], empties, losses, par, phase:'play'|'win'|'lose', stars}.
- `click(id)` → true/false (false: носящий, мёртвый, не фигурка); `tick(seconds)` —
  синхронный шаг мира для бота. API стирания/переснятия/команды смертью не существует.
- Сценарий: (1) инвариант №9: click по носящему → false, глубины и sourceId неизменны;
  смерть не является фигуркой (в figures её нет) — оригинал один во всех прогонах;
  глубина нового оттиска = глубина ближайшего живого носителя + 1 при любом порядке
  кликов; множество глубин никогда не уменьшается, источник не переписывается; (2)
  источник = ближайший: два носителя на 60 и 200 px → глубина по ближнему, «выбрать
  дальний» невозможно API-ски; (3) врата: носитель depth ≤ T в 70 px → open=true
  навсегда (tick не закрывает), depth > T в 50 px не открывает; граница 69/71 px;
  (4) охота: появление depth1 вдали → death.targetId меняется немедленно; появление
  depth2 при цели depth1 — НЕ меняет; по прибытии alive=false, losses+1, цель =
  следующая самая тёмная ≤ 2 (при равенстве — ближайшая к смерти); (5) целей нет —
  смерть идёт по waypoints по кругу, врата при этом открываются её близостью обычным
  правилом; (6) провал достижимости: L3 — сжечь все фигурки бледным у дальних врат →
  empties=0 при закрытых вратах → phase='lose' (достижимость, не таймер); (7) ленивые
  боты: «не штамповать» 300 с → 0 побед на всех уровнях; «штампуй всех подряд»
  (случайный порядок) — на L3 провал достижимости или потери > par; «только бледное
  вдали от смерти» → врата T1 не открыты → 0 побед; «копилка» (сделать depth1 и не
  открывать) → изъятие за время хода смерти; (8) план-бот: победа с потерями = par на
  всех 5 уровнях, 10/10 прогонов; par подтверждён полным перебором живых состояний на
  скелете до HTML; (9) рандом-бот (равновероятный клик по пустым) — < 50 % побед на
  каждом уровне (≥ 200 партий); (10) звёзды: win с losses=par → 3, ≤ par+1 → 2,
  иначе 1; победа в момент последнего врата, потери после победы невозможны.

## Формат прототипа
Один HTML-файл, canvas 960×640, без сборки и зависимостей. Заголовок страницы — вопрос
прототипа. Состояние читается без текста: бледность штампа = глубина, нитка к источнику
по наведению, пунктир цели смерти, образец черноты над вратами, радиус врат при
наведении. HUD одной строкой: врата X/N, потери/par, пустых фигурок. Итог уровня одной
строкой (потери, звёзды) — ответ на вопрос прототипа. Управление: только мышь (клик по
фигурке). window.DEATH_STAMP — приёмка ботами до визуальной сборки.
