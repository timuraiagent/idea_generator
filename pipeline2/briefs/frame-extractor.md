# Бриф: каркасник (этап 4.5 и разбор старых спек)

| | |
|---|---|
| Кому | свежему субагенту |
| Получает | правило одной фразой, действие, «что движется само», «что не меняется», цель; словари каркаса |
| Не получает | баллы, карту библиотеки, название механики |
| Подстановки | `{{rule}}`, `{{action}}`, `{{mover_text}}`, `{{invariant_text}}`, `{{goal}}`, `{{vocab}}` |

## Задание (передаётся субагенту целиком)

Ты раскладываешь игровую механику по пяти полям, чтобы её можно было сравнить с другими. Оценивать не надо.
Файлы не меняй, в сеть не ходи.

Что известно о механике:
- Правило: {{rule}}
- Действие игрока: {{action}}
- Что движется само: {{mover_text}}
- Что не меняется: {{invariant_text}}
- Цель: {{goal}}

Для каждого поля выбери ровно одно значение из словаря. Значение «другое» бери, только если ни одно не
подходит, и тогда предложи своё слово.

```
{{vocab}}
```

Пояснения к полям.
- **action** — что делает ход игрока по сути: переносит что-то с места на место; связывает два предмета;
  создаёт поле вокруг точки; ставит преграду; превращает предмет в другой; меняет порядок.
- **mover** — что меняется в мире без игрока: фронт (расползается во все стороны), поток (идёт по пути),
  часы (срок, такты, расписание), носитель (один предмет ходит или носит), толпа (много самостоятельных
  предметов), ничего.
- **invariant** — что игрок не может изменить: сумму, набор предметов, их порядок, длину или площадь,
  связность, ничего.
- **lock** — чем открывается цель: состоянием клетки (свет, цвет, заполненность), совпадением по времени,
  порогом величины, доставкой предмета, перекрытием пути.
- **win** — условие победы: дойти, доставить всё, удержать до срока, разложить по местам.

## Формат ответа

Последним в ответе — один блок JSON:

```json
{"action": "перенос", "mover": "носитель", "invariant": "длина", "lock": "состояние-клетки", "win": "дойти",
 "proposed": {},
 "why": {"action": "…", "mover": "…", "invariant": "…", "lock": "…", "win": "…"}}
```

В `proposed` — предложенные слова для полей, где выбрано «другое», например `{"mover": "маятник"}`.
