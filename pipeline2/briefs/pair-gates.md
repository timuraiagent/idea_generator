# Бриф: оценщик пар (этап 1)

| | |
|---|---|
| Кому | свежему субагенту без контекста поиска |
| Получает | путь к файлу волны |
| Не получает | библиотеку механик, прошлые вердикты, пожелания ведущего |
| Подстановки | `{{wave_path}}`, `{{good_archetypes}}` |

## Задание (передаётся субагенту целиком)

Ты проверяешь пары слов «глагол × существительное» — годятся ли они как основа игровой механики. Саму
механику придумывать не надо. Ничего в файлах не меняй, в сеть не ходи.

Прочитай файл `{{wave_path}}`. В нём список пар; у каждого слова есть три ближайших соседа — по ним пойми, в
каком значении слово взято.

Для каждой пары ответь на пять вопросов по порядку. Первый же «отказ» останавливает проверку пары.

1. **Разрыв (№3).** Можно ли сделать это буквально — в жизни или в привычной игре? Если можно, метафоры нет:
   отказ.
2. **Рука и закон (№5).** Одна сторона берётся рукой (её можно взять, поставить, сдвинуть), другая живёт
   сама и больше человека (время, тьма, толпа, долг, погода)? Если обе физические или обе абстрактные: отказ.
3. **Два закона (№6).** Заполни две строки: «глагол привносит …» и «существительное сохраняет …». Назови
   конфликт между ними. Если строка не заполняется содержательно или конфликта нет: отказ.
4. **Формула (№7).** Заполни «можно [глагол] [существительное], но тогда …» без третьего понятия. Концовки
   «станет меньше» и «со временем пропадёт» не считаются. Не получается: отказ.
5. **Архетип по формуле (№8).** Что делает глагол в твоей формуле? Допустимые роли: {{good_archetypes}}
   (переносит что-то с места на место; связывает два предмета; создаёт поле вокруг точки). Если он работает
   как ручка (крутить, тереть), накопление, расход или общий толчок: отказ. Оценивай по формуле, а не по
   словарному значению.

Отдельно, без отказа: **мост (№4)** — есть ли в языке готовая метафора, где это существительное мыслится
объектом такого глагола («время течёт», «покров ночи»)? 2 — есть устойчивое выражение, 1 — близкое есть,
0 — нет.

Будь строг: при сомнении — отказ. Обычно из шестнадцати пар проходит одна-две; ноль — нормальный исход.

## Формат ответа

Последним в ответе — один блок JSON, по записи на каждую пару, в порядке файла:

```json
[
  {"verb": "…", "noun": "…", "decision": "reject", "reason": "№3: это делается буквально — …"},
  {"verb": "…", "noun": "…", "decision": "pass",
   "verb_law": "глагол привносит …", "noun_law": "существительное сохраняет …", "conflict": "…",
   "formula": "можно … …, но тогда …", "archetype_by_formula": "перенос", "bridge": 1,
   "reason": "почему прошла, одной фразой"}
]
```
