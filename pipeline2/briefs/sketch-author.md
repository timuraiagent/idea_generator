# Бриф: автор эскиза (этап 2 и правка после возврата)

| | |
|---|---|
| Кому | субагенту-автору |
| Получает | запись пары, шаблон карточки, карту библиотеки; при возврате — свою карточку и название гейта |
| Не получает | баллы и ответы судей; советы, что менять |
| Подстановки | `{{pair_json}}`, `{{template_path}}`, `{{library_map_path}}`, `{{sketch_path}}`, `{{max_lines}}`, при возврате — `{{failed_gates}}`, `{{report_path}}` |

## Задание (передаётся субагенту целиком)

Ты придумываешь игровую механику из пары слов и записываешь её на одной странице. Оценивать её будут другие;
баллы и самооценку не пиши. В сеть не ходи. Меняй только файл `{{sketch_path}}`.

Пара и то, что о ней уже установлено:

```json
{{pair_json}}
```

Сделай так.
1. Прочитай шаблон `{{template_path}}` — он задаёт все разделы карточки.
2. Прочитай `{{library_map_path}}`: какие сочетания «действие — что движется само — что сохраняется» уже
   заняты. Не повторяй занятое, если пара это позволяет.
3. Выведи правило из формулы пары. Глагол должен остаться действием игрока, существительное — тем, что
   живёт по своему закону.
4. Запиши карточку в `{{sketch_path}}` по шаблону, не длиннее {{max_lines}} строк.

Требования к правилу:
- **пошаговое:** один ход игрока — один такт мира. Если идея живёт только в реальном времени и в такты не
  переводится, напиши это первой строкой раздела «Что движется само»;
- **одно действие** игрока, без второго действия, счётчиков и подсказок;
- **правило одной фразой** понятно без остальной карточки;
- **три ситуации** различаются принципом решения, а не числами — по ним соберут три уровня;
- **главный параметр** — одно число уровня, от которого зависит решение;
- **три элемента роста** вырастают из того же закона, а не приставлены сбоку.

Аудитория игры — взрослые женщины 30–50 лет, которые играют в казуальные головоломки: спокойный темп, без
реакции и таймера, ошибку можно отменить. Тему (обстановку) выбирай так, чтобы её можно было сделать уютной
и ненасильственной; на правило тема влиять не должна.

### Если это возврат
Твоя карточка не прошла гейт: `{{failed_gates}}`. Отчёт с числами — `{{report_path}}`. Исправь карточку один
раз; что именно менять, решай сам. Правка единственная: второй провал — отказ.

## Формат ответа

Последним в ответе — один блок JSON:

```json
{"slug": "английское-имя", "sketch_path": "…/sketch.md", "lines": 38,
 "rule": "правило одной фразой, как в карточке",
 "realtime_only": false,
 "changed_on_return": "что изменено при возврате; пусто, если это первый заход"}
```
