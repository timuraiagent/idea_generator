# Бриф: автор спеки (этап 6)

| | |
|---|---|
| Кому | субагенту-автору (можно тому же, кто писал карточку) |
| Получает | карточку, скелет, отчёт ботов, вердикт, шаблон спеки |
| Подстановки | `{{sketch_path}}`, `{{skeleton_path}}`, `{{report_path}}`, `{{verdict_path}}`, `{{template_path}}`, `{{spec_path}}`, `{{max_lines}}`, `{{check_command}}` |

## Задание (передаётся субагенту целиком)

Ты пишешь спеку механики для сборщика прототипа. Всё главное уже проверено: правило — в карточке, его код —
в скелете, числа — в отчёте ботов. Твоя работа — свести это на две страницы, ничего не придумывая заново.
Меняй только `{{spec_path}}` и, если добавляешь уровни, `{{skeleton_path}}`. В сеть не ходи.

1. Прочитай `{{sketch_path}}`, `{{skeleton_path}}`, `{{report_path}}`, `{{verdict_path}}` и шаблон
   `{{template_path}}`.
2. Напиши `{{spec_path}}` по шаблону, не длиннее {{max_lines}} строк.
   - Правило одной фразой — дословно из карточки.
   - Порядок хода — по функции `apply` скелета. Если карточка и скелет расходятся, верен скелет: он прошёл
     проверку. Расхождение назови в ответе.
   - Все числа (par, доли побед ботов, число состояний) — из отчёта ботов. Чисел «по прикидке» в спеке быть
     не должно.
   - Вопрос прототипа — один: что должно подтвердиться игрой людей и чего боты проверить не могли.
   - Раздел «Что видно на экране»: какие состояния обязаны различаться с одного взгляда и что игрок должен
     видеть до хода.
3. Можно добавить до семи уровней сверх трёх. Каждый — данными в конец `levels` скелета, по одной новой идее
   на уровень; после этого запусти `{{check_command}}` и убедись, что все гейты по-прежнему пройдены. Числа
   новых уровней бери из свежего отчёта.
4. Обращение к игроку в текстах для прототипа — на «вы». Аудитория — взрослые женщины 30–50 лет, казуальные
   игроки.

Не пиши в спеку: разбор по линзам, сравнение с соседями по библиотеке, историю правок, оценки.

## Формат ответа

Последним в ответе — один блок JSON:

```json
{"spec_path": "…/spec.md", "lines": 104,
 "levels_total": 8, "levels_added": 5,
 "check": {"command": "…", "verdict": "pass"},
 "deviations": "расхождения карточки и скелета, если были; иначе пусто",
 "prototype_question": "вопрос прототипа одной фразой"}
```
