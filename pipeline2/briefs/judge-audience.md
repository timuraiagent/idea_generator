# Бриф: судья аудитории (этап 4.2)

| | |
|---|---|
| Кому | свежему субагенту, другой моделью, чем автор |
| Получает | только карточку `sketch.md` |
| Не получает | скелет, отчёт ботов, баллы, имя автора |
| Подстановки | `{{sketch_path}}`, `{{audience}}` |

## Задание (передаётся субагенту целиком)

Ты оцениваешь, подходит ли игровая механика аудитории: {{audience}}. Эти игроки играют, чтобы отдохнуть:
спокойно, короткими заходами, на телефоне одной рукой. Твоя задача — найти причину сказать «не подходит».
При сомнении отвечай «нет». Ничего не чини и не советуй. Файлы не меняй, в сеть не ходи.

Прочитай карточку `{{sketch_path}}` и ответь на шесть вопросов «да» или «нет», к каждому — причина одной
фразой со ссылкой на то, что написано в карточке.

1. Ход делается без спешки: в ядре правила нет ни реакции, ни таймера?
2. Действие одно и выполняется одним пальцем?
3. Ошибку можно отменить, и она не стоит накопленного прогресса?
4. Тему можно сделать уютной и ненасильственной, не меняя правил?
5. Уровень проходится за одну–три минуты?
6. Прогресс виден как завершение: уровень закрыт, глава закрыта?

Оценивай правило, а не обстановку из карточки: обстановку можно заменить, правило — нет.
Для вопросов 3, 5 и 6 в карточке есть раздел «Отмена, длина, прогресс». Если раздел пуст или отвечает
уклончиво — «нет».

## Формат ответа

Последним в ответе — один блок JSON:

```json
{"answers": [
   {"q": 1, "yes": true,  "why": "…"},
   {"q": 2, "yes": true,  "why": "…"},
   {"q": 3, "yes": false, "why": "…"},
   {"q": 4, "yes": true,  "why": "…"},
   {"q": 5, "yes": true,  "why": "…"},
   {"q": 6, "yes": true,  "why": "…"}],
 "yes_count": 5,
 "main_objection": "главная причина, по которой аудитории это может не подойти; одной фразой"}
```
