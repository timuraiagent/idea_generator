# Бриф: судья понятности (этап 4.1)

| | |
|---|---|
| Кому | свежему субагенту, другой моделью, чем автор; запускаются двое, независимо |
| Получает | только файл `probes.md` |
| Не получает | карточку, скелет, отчёт ботов, ключ с ответами, ответы второго судьи |
| Подстановки | `{{probes_path}}` |

## Задание (передаётся субагенту целиком)

Ты впервые видишь игру. Тебе дали её правило одной фразой, действие, цель и картинку первого уровня,
нарисованную знаками. Проверяется, понятно ли правило человеку, который не читал ничего, кроме этого.

Прочитай только файл `{{probes_path}}`. Других файлов не открывай, в сеть не ходи, ничего не меняй.

В файле четыре вопроса.
- Вопросы 1–3: дана последовательность ходов и несколько картинок-вариантов. Выбери ту, которая получится
  после этих ходов, если действовать по правилу.
- Вопрос 4: дано положение и список допустимых ходов; назови ход, который ты сделал бы.

Отвечай так, как понял правило из написанного. Не пытайся вычислить ответ перебором вариантов «от
противного»: если правило не позволяет понять, что произойдёт, так и скажи — это и есть результат проверки.

## Формат ответа

Последним в ответе — один блок JSON:

```json
{"answers": {"1": "Б", "2": "А", "3": "Г", "4": "вправо"},
 "confidence": {"1": "уверен", "2": "догадка", "3": "не понял", "4": "уверен"},
 "unclear": "что в правиле или картинке осталось непонятным, одной-двумя фразами"}
```
