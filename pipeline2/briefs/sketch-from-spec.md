# Бриф: карточка по старой спеке (разбор первой версии, `backlog.md`)

| | |
|---|---|
| Кому | субагенту; не тому, кто писал эту спеку |
| Получает | старую спеку механики, шаблон карточки |
| Не получает | баллы первой версии, карту библиотеки, советы |
| Подстановки | `{{old_spec_path}}`, `{{template_path}}`, `{{sketch_path}}`, `{{max_lines}}` |

## Задание (передаётся субагенту целиком)

Ты сжимаешь длинную спеку игровой механики в карточку на одну страницу. Придумывать ничего не надо: правило,
действие и ситуации берутся из спеки. Оценок не ставь. В сеть не ходи. Меняй только файл `{{sketch_path}}`.

1. Прочитай спеку `{{old_spec_path}}` и шаблон `{{template_path}}`.
2. Запиши карточку в `{{sketch_path}}` по шаблону, не длиннее {{max_lines}} строк.
   - «Правило одной фразой» — из раздела спеки «Правило (одно предложение)». Если там несколько предложений
     или фраза непонятна без остального текста, перепиши её одной фразой, не меняя смысла.
   - «Действие» — одно. Если в спеке действий несколько, оставь главное и назови остальные в ответе.
   - «Три ситуации» — из уровней или примеров спеки: три задачи с разным принципом решения. Если в спеке
     их меньше трёх, напиши столько, сколько есть, и скажи об этом в ответе: новых не придумывай.
   - «Главный параметр», «Что движется само», «Что не меняется», «Три элемента роста» — из спеки.
   - «Отмена, длина, прогресс» — из спеки. Старые спеки часто об этом молчат; тогда выведи ответ из правила
     (например: «ход отменяется без потерь — в правиле нет необратимых случайных событий»; «уровень —
     около пятнадцати ходов») и пометь строку словом «выведено».
3. Числа ботов и par из спеки в карточку не переноси: их посчитают заново.

Если правило спеки не пошаговое (живёт только в реальном времени), напиши это первой строкой раздела «Что
движется само».

## Формат ответа

Последним в ответе — один блок JSON:

```json
{"sketch_path": "…/sketch.md", "lines": 41,
 "rule": "правило одной фразой, как в карточке",
 "rule_rewritten": false,
 "realtime_only": false,
 "situations": 3,
 "missing": ["чего в спеке не нашлось: например, третьей ситуации"],
 "derived": ["что выведено из правила, а не взято из спеки"],
 "dropped": ["что из спеки в карточку не вошло: вторые действия, счётчики"]}
```
